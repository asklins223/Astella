# 伴星声音表达验收 · 2026-10-07

用户决定：让回复生成模型选择情绪与富语言声音，移除正文关键词判情绪。实现合同见 [方案 45](../../../../../docs/plans/learning-companion/45-model-authored-voice-expression-2026-10-07.md)。

## 自动回归范围

- shared：标签全表、显式控制投影、半标签/未知标签、代码排除、支持模型能力闸、现役人格与需求版本。
- worker：相同正文由不同显式标签决定声音；包含“棒”“原因”等词但没有标记时仍为自然语气；语气切换、分段继承、neutral 复位、拟声绝对位置、事实替换、Markdown/代码、长回复、增量跨标记与缓冲尾部。对话、Agent 放行阈值和知识审校均走真实装配函数。
- API：检查实际 WebSocket 外发事件。每个任务一次完整 `continue-task`；支持模型保留官方标签，其他模型剥标签，未知和宿主复位标记不外发；取消信号与现有层边界回归。
- desktop：播放开始才采用片段 cue，进度 tick 不重复触发表情，旧计划迟到的停止不清除新计划，停止/范围切换/隐藏/正式作答/总静音释放播放表达。已有播放与人格页回归。

最终相关自动回归为 shared 32、worker 214、API 28、desktop 35，共 309 项通过，无失败。对应包的 `npm run typecheck` 覆盖 shared、api、desktop-client、ai-worker，均通过；`git diff --check` 通过。自动回归与窗口证据各自记录，不以类型通过推断听感。

回合审计的版本与哈希已改为同一现役人格版本；PostgreSQL 编排测试中的预期同步更新，本次没有重跑该完整集成测试文件。数据库交付与播放证据来自下方的真实窗口回合。

## 真实模型与音频

使用当前 `agent_turn` 路由的 `deepseek-v4.1-flash`，以真实人格、首步请求和流式执行器生成四条合成测试话语；没有账号历史，也没有额外情绪分类调用。运行入口：

```sh
cd workers/ai-worker
REAL_MODEL_BATCH=1 node --import tsx src/live-tests/voice-expression-probe.ts
```

这一批产物位于仓库忽略的 `outputs/audits/2026-10-07-live/voice-expression.json`。这是加入“历史已剥标签”提示前的样本，不冒充最终全部对话的通过率。

| 情境 | 模型实际标记 | 观察 |
| --- | --- | --- |
| 已经做到了但疲倦，不想庆祝 | `[empathetic]`、`[sighing]` | 没因“做到了”改成祝贺 |
| 收到通过通知，很开心 | `[excited]` | 祝贺表达 |
| 认真解释变量初始化 | `[serious]` | 认真表达；回答长度仍明显超过用户要求，不在这次声音验收中算作内容体验通过 |

其中安慰、祝贺、轻笑三条通过生产 Qwen provider 实际合成，使用 `qwen-audio-3.1-tts-flash` 与当前 `longhua_v3.1` 音色。音频文件在 `outputs/audits/2026-10-07-live/voice-expression-audio/`：

## 验收边界

真实样本已经证明模型标记、位置保留、Qwen 合成、干净正文和客户端播放连通。样本数量有限；旧长对话仍观察到漏标，补充历史剥标提示后的单次成功不能证明已消除。漏标按合同保持自然语气，不关键词补猜、不追加分类调用或自动重试。

Live2D 是现有有界情绪集上的段级投影，音频开始时采用该段 cue；没有音素级或同段内拟声时刻对齐。模型语气标签比形象情绪集更丰富，多个声音标签可能映射为同一个表情。自然程度、叹息/笑声的强弱与持续多轮听感尚未经过真人评阅。
