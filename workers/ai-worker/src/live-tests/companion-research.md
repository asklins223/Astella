# 伴星自然对话：研究依据与本次调整（2026-10-07）

用户要求查论文与开源实现后再优化；此前 32 轮普通输入仍未通过自然度验收。下面区分原始研究、适用于本项目的判断和本次实际实现。论文或测试数量不构成产品体验已通过的证据。

## 实际改动

1. 历史 SQL 读取与近期/更早会话的读工具都保留 `companion_messages.created_at`；当前消息同样从数据库取时间。`loadHereAndNow` 在同一读事务提供 UTC 时钟和实际采用的账号时区。
2. 下方原生 user/assistant 消息保持完整原文；独立 `conversation_timeline` 数据块通过位置、说话者、UTC 发送时间和与读取时钟的间隔关联。缺失或无效时间标为未知，未来时间不生成负的“已过去”间隔。消息之间的间隔不是持续在线时长，消息中的“昨天”也不被改写成发送时间。
3. 修复近期 `companion_read_history` 与 `readPastConversationMessages` 的单条 1000 字静默截断。近期工具返回完整原文与时间；更早记录按整条消息分页，首条超过软页预算也完整返回，后续消息通过 seq 续读并明确还有未读消息。跨会话检索的空结果同时给出“仅检索其他会话的索引来源”的范围，不将它当成当前聊天不存在的证据。
4. 时间证据与实际模型消息一起进入不可变交接快照；重试沿用首次提交的时钟。新块与既有内部数据块一样，不能泄露为可见正文。没有增加生成前自检、额外模型调用或原文字符截断。
5. 修复环境统计预取：`assistance_consequence` 是恒定可用的作答影响目录键，不是统计请求；旧 `factSpanKeys.length > 0` 因它恒真而把每轮对话当成要学习统计。现在只按真实统计问法或消费统计的键读取；连续学习天数仍由独立读取负责。
6. 给账号表达示例标明来源：没有对应用户问题的回复只能说明风格，不能作为当前求助、实际经历或已接受建议的证据。

曾尝试按分享、情绪、求助和纠正组织新的闲聊策略，并调整活跃人格对建议的描述；真实对照仍出现提前认定交差、指导和角色经历虚构，没有证明收益，已撤回这两项候选改动。仅在 `live-tests/research-dialogue-policies.ts` 留可复现的实验文本，生产不导入。

## 评测方法

普通输入不附“别反问、别建议、短一点、只说一句”等约束，也不附理想答案。模型/配置一致的旧策略对照与新策略分别建空会话，沿生产历史读取、时钟、agent 循环、调用预算和真实流式交付运行；本脚本的 ReadContext 夹具仍绕过 HTTP/turn-service，不能称完整用户端端到端验收。

追问由编码代理读到实际回复后选择。相同前缀可对照；后续分支因真实回复而变化时，不能当作严格配对。编码代理的评阅不是独立人类研究。

完整回复按以下维度单独记录，以原文引句定位问题，不按长度、问号或第一人称打分：

| 维度 | 检查什么 |
| --- | --- |
| 事实与来源 | 用户说写完时不补成已交；风格、比喻和口味不等于实际活动；无记录不编经历。 |
| 时间 | 近期、跨日和断续交流不混为今天持续活动；不知道就保留未知。 |
| 更新与纠正 | 新的明确纠正成为后续状态，承认具体错误，不辩解或催促。 |
| 对话用途 | 闲聊、疲惫和放松不自动接成指导；明确求办法时仍能给有用帮助。 |
| 人格与交流 | 有具体反应和看法，允许贴题提问；不介绍接话策略，不套通用邀请或角色签名。 |
| 交付与成本 | 完整可见正文与落库正文一致；实际请求数、思考档和等待单列，不与自然度混成“通过”。 |

本次真实样本与逐项结论见 `outputs/audits/2026-10-07-live/research-dialogue-report.md`。任何仍出现的失误保留在原始 JSON，不能以成功交付覆盖它。


## 后续单变量试验

另以普通输入做闲聊 none/low 思考档、语音格式示例有/无、成对示例有/无的对照。思考档试验保持同模型、温度和文字策略；语音试验只改格式示例；成对示例是其他话题的完整用户/伴星轮次，未把理想答案加进测试用户消息。均未证明足以默认采用的稳定收益，保留失败。还有已配置同平台另一模型的独立复验，模型档案决定其最低档，不能将它称为关闭思考。

独立用量诊断中，low 请求确实返回 145 个 reasoning tokens。它不替先前缺 SSE 用量的六轮补证，也不代表低档改善了自然度。生产日志现在记录 requestedDisableThinking、providerId、modelId 和判定依据；类型注释同步说明支持 none 才能关闭，否则只降档。状态显示表达处理阶段，不宣称读到了内部思考。
