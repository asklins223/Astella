全文读取没有取消显式输入校验、分页、完整记录选择或可恢复压缩。用户输入与伴星选区分别 20,000 字、回复 text block 200,000 字、system 装配 100,000 字符等仍是显式合同；超限拒绝、可选来源整块遗漏、历史窗口和工具续读各有独立机制。回想问题的 500 字生成合同、短 UI 标签、预览和 SSE 分块仍保留；事件总线不再另裁标题或回想问题。这些不是“所有上下文永久全量发送”，也不是把文本后半段默默切掉。未做 200,000 字输出的真实模型生成或全窗口压力验收。

## 2. 当前平台、自动思考和额度

正式 capability 路由保持原模型选择。临时 Luna 档案已经移除。DeepSeek Go 的输出档案由 131,072 对齐到 OpenCode 当前模型目录的 **384,000**，思考开启时省略不会生效的 temperature。完整请求已实际接受 384,000 的声明额度；没有生成 384,000 token 来冒充最大长度验收。

| 现役档案 | 声明上下文 / 输出 | 思考说明 |
| --- | --- | --- |
| Go / DeepSeek V4.1 Flash（agent_turn） | 1,000,000 / 384,000 | none 真关闭，默认 high；minimal→low，medium/xhigh→high，max→max，因此可接受的七个参数名不等于七个独立推理强度 |
| Go / Muse Spark 1.3 Contributor（备选档案） | 1,048,576 / 131,072 | 档案最低 minimal，不能把请求关闭称为零推理；本轮没有设为默认 |
| TokenRhythm / Qwen3.8 Flash（备选档案） | 1,000,000 / 131,072 | 此网关路径发送思考开/关，不能只凭本地 high 字段证明上游强度 |
| SiliconFlow / GLM-4-9B-0414（文字/伴星兜底） | 32,768 / 8,192 | 不支持思考 |
| BigModel / GLM-4.1V-Thinking-Flash（专用识图） | 65,536 / 16,384 | none/high；配置的 disableMaxTokens 要按供应方实际限制处理，不能按未下发额度减输出预留 |

依据：[OpenCode Go 官方端点与使用范围](https://opencode.ai/docs/go/)、[Go 模型列表](https://opencode.ai/zen/go/v1/models)、[OpenCode 维护的模型目录](https://models.dev/api.json)、[DeepSeek 官方思考映射](https://api-docs.deepseek.com/guides/thinking_mode/)、[DeepSeek 最大输出](https://api-docs.deepseek.com/quick_start/pricing/)。Go 的模型列表只返回 id，没有输出上限；额度来自模型目录。DeepSeek 原生接口另写 393,216 最大值，未把它直接替换成 Go 的声明。备选档案的其他能力沿当前配置保留，不把本轮只读目录核对当作全部上限实测。

当前 DeepSeek 每轮预留完整 384,000 输出和 2,048 协议余量后，输入硬预算为 **613,952 token**，软触发 **491,161**，目标 **368,371**；最近真实 HTTP 回合已把这些值存入 context_pressure。1M 是总窗口，不是可输入 1M 后再任意输出。前阶段大容量探针只预留 512 输出，不能与当前业务预留混用。此前 1,030,129 输入 token 的五标记读取成功、1.06M 探针被拒，是特定探针证据，不据此放大正式声明窗口。[原探针](../../../../outputs/audits/2026-10-07-live/context.json)、[本地 tokenizer 对照](../../../../outputs/audits/2026-10-07-live/context-exact.json)、[超限拒绝](../../../../outputs/audits/2026-10-07-live/context-upper.json)。

真实窗口的两次普通聊天请求都是 none、推理用量 0；后台记忆抽取独立使用 high，不能算作正文审校。此前两次 HTTP 的分类调用约 30 秒内未完成，保存的解释回退为 question/uncertain，因此按既有安全决策使用 high；对应实际推理用量 154/350。最新长选区回合的分类约 2.011 秒，正常提交 question/none，没有回退。三者并存，不能用一条快样本宣称等待已修复。

分类器固定版本升为 v6，只使用当前协议与完整选中历史；正式调用输出预算 900、关闭思考，未为偶发等待盲目缩短 30 秒期限。新增日志回执只保存结果、失败类别、HTTP 状态、耗时、调用计数与模型身份，不保存输入正文、原始错误或明文思考。历史 `turn_interpretation.dialogueFrame` 读取后剥离；模型新提案不允许这个字段。上一轮声称已清理的分类、思考、策略和 attention 残留此次一并去掉，诊断模块的来源绑定与错误类型也已迁出生产目录。解释生成的内部事实核对指导仍是原生成的一部分，不是新增审校调用。

平台适用性也有未确认项：Go 官方定位是 coding agent 请求，要求客户端标识与稳定 session；本客户端字段已接入，但普通陪伴服务是否符合供应方使用范围仍需确认。Muse Contributor 官方注明可用于训练且有地域限制；本轮仅用合成试验材料，未把它设为真实账号默认。没有通过伪装 coding 请求或绕过平台限制继续优化。

轻度思考候选在设计话题中有较少劝休的例子，但隔离话题仍出现：

- rain：补出昨天雨急、今天更沉，或“是有点不一样”，没有对应观察来源。
- time：把“昨天买了两根玉米”改说成“玉米还在家里等着”，当前状态未确认。
- clay：把“杯身还没修”说成“有把手，但没杯子”，完成范围和对象状态被改写。
- film-switch：把电影话题绑定到“刚才整理抽屉”，补了未给出的时间关系。
- tea：出现可见 `[ curious]` 标记；camera-help 默认手机而输入未说明设备。结构合法没有覆盖这些失败。

因此没有采用 Luna、轻度思考、完整语境示例或此前删示例候选。原人格和正式模型选择保留，活跃度文案只修正“参与交流”与“未经邀请推进”的内部冲突，不将其宣传为自然度解决方案。[80 条原始对照](../../../../outputs/audits/2026-10-07-live/dialogue-matrix-luna-light-heldout-v10.json) 与 [匿名空白评阅表](../../../../outputs/audits/2026-10-07-live/dialogue-review-luna-light-heldout-v10.json) 分开保存；表仍 unrated，没有独立人类盲评。该隔离组已消费，后续不可继续把它称为未见验收集。

实验条件已在调度命令与工作说明中确定，未读隔离输出后修改候选；但 selection JSON 的首次写入因 cwd 错误失败，实际保存发生在调度之后、读取结果之前。它是过程记录，不能冒充事前注册时间戳。低思考只在测试候选 helper 中克隆档案，不改生产自动思考。

收益不足的用途/阶段额外生成和发布前审校已从生产循环删除，纯诊断 helpers/tests 移到 live-tests 下。旧开关不能重新启用；生产探针会在建夹具与出网前拒绝。离线批次和旧失败材料保留，不维护无人采用的生产兼容分支。方案 46 的训练只在可训练模型、合法材料、预算与校准偏好均具备时成立；本轮没有这些条件，也没有把训练、记忆图或再加一轮审校列成待发布功能。

## 4. 真实调用链与窗口

从实际 API 创建回合、生产队列、受限 worker、SSE、保存历史到当前仓库 Electron 做了新检查，账号、空间、对话和内容都是本次合成测试夹具。

- 前阶段三次 HTTP 普通对话保存了实际历史；没有用固定前缀重放替代它们。
- 当前仓库隔离 Electron 窗口真实发送“我把电脑桌下的线理好了，最后剩一个不知道接哪儿的转接头。”，实际看到回复追加“先拿个袋子装着吧”。这证明未经邀请的收纳建议仍存在。
- 第二次普通接续在此前锁屏后落库，当时没有看到窗口回复。此次解锁后已打开对话手记读回，不能补称此前全过程都在窗口观察。
- 此次在气泡和对话手记粘贴超过 20,000 字的输入，确认草稿尾部保留、原因可见、按钮禁用，Enter 不创建回合；缩短后发送恢复。测试后清除未发送的合成草稿。
- 在真实笔记阅读页选中 2499 字原文，经右键菜单送给伴星，再输入“这里的最后一句改正了什么？”。首次调用暴露 worker 的 selection 2400 字装配上限：尚未调用模型就重试三次，最终窗口显示本地等待超时。数据库原文并未丢失，问题是前端合同与装配合同不一致。原失败材料保留。
- 修复后重新从窗口发送同一选区问题，run `79a053be-9d6f-4980-9f0a-05327a85c2de` 成功。选区、保存历史与模型 messages 快照都包含完整尾句“最后更正：我们只完成了初稿，还没给导师发过去。”；SSE 增量与保存正文逐字一致。对话手记实际可见回复，展开引用并用 Page Up 阅读到原文尾句，确认“初稿完成、未发送”的回答。AX 文本快照有自身 1000 字显示限制，不能把它误当产品原文被裁。
