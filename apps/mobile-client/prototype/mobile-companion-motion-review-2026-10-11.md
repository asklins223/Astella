# 随身伴星：动效与操作复核

2026-10-11，按用户关于 Telegram 手感、点击来源、子面板和 App 操作规范的反馈，重做当前前端 Demo。产品范围仍是 App 先行，伴星负责读取、讲解、创建与修改；本轮没有接入正式移动服务。

| 问题 | 实际改动 |
| --- | --- |
| 更新消息时重建整屏 | 保留应用壳、输入框、消息节点和面板容器；按键值更新内容，草稿、光标与选区不被替换 |
| 所有入口从底部出现 | 菜单、书房、伴星、递材料按触发控件的位置展开并避让屏幕；较长的提问、语音和笔记选择扩展到适合内容的位置，入场仍来自控件或所选行 |
| 子面板没有来路 | 菜单 → 设置 → AI 说明、递材料 → 笔记选择均有真实层级；左侧返回只退一层，右侧关闭与背景关闭整组 |
| 关闭突然消失 | 收回入口；关闭立即恢复底页操作，视觉完成后清理；途中打开另一面板，旧完成回调不能把它藏掉 |
| 页面统一淡入 | 详情推入、返回退出并露出来源纸面；一级页签轻量横移，玻璃选中垫连续滑动；对照和类型选择使用移动选中垫 |
| 拖动像离散按钮 | 阅读左沿可跟手右滑，露出上一页；距离不足或取消则回弹，足够距离或速度则返回。面板标题可下拖退回／关闭 |
| 内容分区仍挂输入 | 对话独立输入玻璃面板；手记和手边只有一级导航，详情只有当前内容操作 |
| 状态更新抢操作 | 新消息就地进入；阅读、任务和输入节点保留；退出副本去掉动作和消息身份，不能成为滚动、定位或点击目标 |
| 焦点不连贯 | 子层退回触发行，整体关闭返回原控件；详情到场聚焦标题，返回聚焦来源；发送后回输入，保留完整文本选区；页签支持方向键 |
| 小屏键盘挤内容 | 键盘占位时隐藏上方重复的 Home 指示，压缩待发送引用；320×640、150% 正文、携图与两行问题仍有约 162.78px 正文、两整行实际回复、横向溢出 0 |
| 关闭动效留下层 | Off／系统减少动态直接到目标状态，并立即清理退出层；支持不使用模糊的实底玻璃 |

动效用浏览器 Web Animations 与可中断的几何变换实现，短按压约 150ms，回弹约 320ms，面板展开约 460ms，详情约 470ms；功能与焦点不等待这些时间。反向操作从当前呈现的位置接续。透明度、明暗渐变、边缘高光、内阴影与真实背景模糊呈现玻璃，正文保留稳定纸面。参考 [Telegram 官方对 iOS 玻璃材质的说明](https://telegram.org/blog/new-design-ai-summaries)；这里使用可实现的 Web 合成效果，没有宣称复刻原生折射。

## 验证

- 14 项自动测试通过：6 项既有数据／回执测试，8 项新几何、节点连续性、选区、面板层级、导航来源、打断、Off 与拖动状态测试。DOM 测试使用 jsdom，不能代替真实合成与手势检查。
- 真实浏览器走查：菜单三级进退；关闭途中转开书房；递材料 → 选择笔记 → 返回；320px 子面板；左沿拖动返回；递图解释 → 创建 → 修改同一篇 → 前后对照 → 原文追问；实际焦点与正文几何。最新截图和逐步检查结果见资产目录。
- 脚本语法检查通过。可复现浏览器脚本已更新，仅做语法检查；本轮没有用它运行浏览器。

最新入口：[Demo](mobile-companion-layout.html)。数据、控制器与动效模块分别是 `mobile-companion-data.js`、`mobile-companion-layout.js`、`mobile-companion-motion.js`。当前仍是本机样例数据、预写讲解、静态人物和浏览器声音；原生系统返回／键盘、真机性能、Live2D、ASR 与真实跨端服务仍需移动宿主验收。
