# 手机伴星设计复核与落实

日期：2026-10-10。2026-10-11 动效与操作修订见 [后续复核](mobile-companion-motion-review-2026-10-11.md)。用户已要求全部落实复核建议，再完成连贯前端 Demo。本文件记录修改后的核对结果；此前原型的行号与截图不再作为现状依据。

| 复核问题 | 本次落实 |
| --- | --- |
| 首页叠欢迎、接续与电脑摘要 | 有历史显示同一份交流，只留当前对象引用；空态才显示欢迎 |
| 手记与手边重复任务 | 手边汇总待处理；手记检索已有笔记、图片、旧对话 |
| 阅读仍套完整聊天底栏 | 详情独立纸面，底部就地问／播放；提问带版本与原文，收起保持位置 |
| 从手记读笔记返回对话 | 跳转保存真实来源与滚动位置，逐层返回 |
| 伴星从大肖像变圆头像 | 完整半身轮廓；见面、工作与内容阅读使用稳定比例，名字／实际状态可见 |
| 玻璃与正文材质混同 | 玻璃承载操作，长正文用暖白纸面，取消蓝绿黄全屏色带与海平线 |
| 画面主要承诺延期能力 | 首版演示已有笔记阅读、图加文字、独立语音短记、创建与修改；移除 PDF／Word、区域圈选、版本撤回和小程序胶囊 |
| 静态页面相互不连贯 | 手机、手记、任务和桌面预览共用一个本机 Store，创建与修改真实更新同一演示对象 |
| 失败恢复不完整 | 停止、失败重试、版本冲突、结果未知核对各有状态；回执重放不重复创建 |
| 已有阅读价值不够明确 | 方案 51 的 P0 增加桌面已有笔记直接检索、打开、就地问与原路返回 |
| 服务端上传与解析被写成全部不存在 | 修正为已有文本／Markdown 私有上传与 worker 解析底座，PDF／Word 二进制解析与聊天附件关联待补 |
| 录音不持久保存被写成不上传／不训练 | 分开用户录音转写、伴星朗读缓存与服务商政策，撤下未经证实的绝对训练承诺 |
| 语音与图片同轮假设 | 明确当前合同限制；Demo 图加文字与独立语音分开，不静默丢材料 |
