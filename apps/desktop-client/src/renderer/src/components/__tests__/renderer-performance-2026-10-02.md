# 客户端切页、目录与灵动岛性能复测（2026-10-02）

本次针对切页停顿、目录收放时图标先向左跳、动效生硬，以及首页灵动岛卡顿，沿真实 Electron 窗口和渲染调用链排查并修改。基线采用任务开始时的工作区构建，保留当时已有的页面改动；没有以 Git HEAD 代替用户正在使用的版本。

## 已确认原因与修复

| 卡顿或轨迹问题 | 实际调用链与修复 |
| --- | --- |
| 切页要等上一个页面退场后才开始挂载、取数，连续操作容易等待旧目标 | `TaskSurface.tsx` 在最新目标变化时立即挂载并交接焦点，过渡从当前呈现继续；取消旧时间线，保留返回书房的退场和超时释放。 |
| 伴星绘制与页面争用主线程 | `WindowLive2DDriver.ts` 取消模型的共享自动 ticker，模型推进和绘制共用私有 ticker，上限 60 FPS；隐藏时暂停，重复尺寸通知不再重建 backing surface。保留 DPR 2 和抗锯齿。 |
| 相机每帧修改根节点 CSS 变量，使整棵页面重复计算样式 | `RoomStage.tsx`、`home-v2-camera.ts` 改为只变换 `.room-camera-rig`；根节点继续发布必要的场景状态。 |
| 伴星几何检测每次事件后持续逐帧测量 1.2 秒，且观察自身写入根样式产生反馈 | 三个 placement / seat hook 将观察通知合并到下一帧的一次测量，移除根 `style` 反馈，保留初始摆位、实际锚点变化与视口事件。 |
| 首页灵动岛同时动画宽高、padding、grid、模糊和内容，反复重排与栅格化 | `HomeV2ObjectLayer.tsx`、`hud/hud-surface.css` 用上下端帽和中段变换背景，文字与操作区域立即采用目标布局；关闭内容上的重复 CSS 入场动效。 |
| 首次进入页面同帧解码大背景图 | `media/task-scene-preload.ts` 顺序在空闲时间预解码当前主题的任务场景图，取消旧主题调度并限制缓存，保留原始画作。 |
| 首次点击同步创建 AudioContext，基线主线程停顿约 186 毫秒 | `HomeV2AudioController.tsx` 在空闲时间准备挂起的音频图，可信手势仅恢复已有图；极早点击也不再同步构造。手势前保持静音，语音与环境声继续共用原音频图。 |
| 场景阶段变化重渲染整套书房；多个页面重复接管根页面 class | `App.tsx` 对 `RoomExperience` 作 memo 隔离；`use-hud-page.ts` 在布局阶段发布页面身份，由持续挂载的 HUD 单点应用根 class。 |
| 目录图标在收放首帧向左跳 | 动画副本丢失 grid 的 `place-items:center`。`directory-rail-motion.ts` 保留 HUD 样式作用域、显式复制对齐样式，按收放前的实际位置冻结图标。 |
| 目录先等待、再收缩，缺少回弹，反向操作重新从端点出发 | 目录背景、图标和按钮共用有阻尼的物理弹簧及动画时钟，Full 有约 5% 的轻微回弹，Lite 单调收敛。反向切换承接当前位置和速度，取消旧回调。图标保持原尺寸，沿纵向收拢；背景只用 transform / opacity 变形。 |
| 目录 FLIP 完成写回旧 inline transform，可能覆盖同时进行的切页入场 | 完成时只释放 WAAPI 覆盖，不提交过时样式；切页或动效偏好变化立即释放目录副本。收起的项目退出焦点路径，展开后功能立即可用。 |

## 同机实测

环境：macOS / Apple Silicon，Electron 43.4.1，144 Hz，1440 × 810 CSS 视口，DPR 2，真实 Live2D 模型，Full 动效。使用独立 QA 应用与克隆的本地配置，连接已有本地 API；没有覆盖原先运行的验证应用。

CPU Profiler、Chromium timeline 和只读探针同时采集。下表的“挂载等待”是点击到目标页面 DOM 出现，包含当次同步工作；不是网络数据加载完毕。单次窗口只说明同机观察结果，不是跨设备性能承诺。

| 指标 | 基线 | 修复后 |
| --- | ---: | ---: |
| 来源页挂载等待 | 736.9 ms | 77.6 ms |
| 笔记页挂载等待 | 357.1 ms | 13.7 ms |
| 设置页挂载等待 | 679.3 ms | 16.4 ms |
| 8 秒静置期间伴星 renderer 调用次数 | 1153 | 470 |
| 上述伴星 renderer 累计耗时 | 2218.7 ms | 951.9 ms（约减少 57%） |
| 首页“今日下一步”展开后 1.1 秒内最大帧间隔 | 590.9 ms | 7.8 ms |
| 目录收起 / 展开后 1.1 秒内最大帧间隔 | 49.4 / 83.2 ms | 14.2 / 14.3 ms |

最终目录弹簧专项采样 25 秒，无超过 25 ms 的帧间隔、无主线程 Long Task；包括间隔约 213 ms 的收起后立刻反向展开。首帧位置探针测到图标 X 从 41.500 变为 41.472 CSS px，约 0.03 px 是正常运动采样，原来的瞬间左移已消失；图标宽度全程保持 19 px。

检查过来源 → 笔记 → 设置 → 首页、目录连续往返与键盘打断、首页今日下一步、右上学习空间控制，以及真实长笔记打开与滚动。Full / Lite / Off 在窗口检查；系统减少动态与中途关闭动效通过状态回归覆盖。最终窗口验证和限制见下文。

最终构建另做 28 秒窗口采样，来源 / 笔记挂载等待为 54.0 / 15.3 ms；在已有长笔记内容的上下文中，目录收起 / 展开后最大帧间隔为 27.9 / 7.9 ms。此轮只记录到操作序列前半段，未将采样结束后的按钮操作计入性能数字。随后通过原生 UI 验证缩小窗口内容后的目录收放、Space 快速反向、切页，最后恢复默认缩放及 Full 动效。收起时 AX 树中的隐藏项目与键盘焦点路径同步消失，展开后立即恢复。

## 自动验证与边界

- 桌面相关回归共 28 个文件、232 项用例通过，涵盖弹簧位置与速度连续性、首帧对齐、旧完成回调隔离、焦点路径、切页期限、伴星推进顺序与摆位、场景预解码、音频手势及清理、HUD 页面合同和样式接入守卫。
- `npm run typecheck` 使用桌面包 node / web 两份实际配置；`npm run build` 包含原有素材与构建产物校验。
- 55 秒切页采样中有窗口后台化造成的约 3.4 秒 rAF 空档，因此不把整段采样的最大值当成前台操作卡顿；比较仅使用实际点击后的对应区间。
- 长笔记挂载约 20.9 ms，点击后前 1.1 秒最大帧间隔 27.9 ms。内容随后到达时仍测到一次约 74 ms 的主线程任务，其中布局约 46 ms；字体首次装载和大正文布局仍可能有一次性停顿。GPU / 系统调度事件也不能从本次采样保证全部消除。
- 取证和日志位于 `/tmp/study-perf-20261002/`，包含基线 / 修复构建及 `baseline-switches.json`、`final-cold-switches.json`、`final-idle.json`、`final-rail-spring.json`、`rail-path-after.json` 等；临时目录可被系统清理，本记录保留关键结论。
