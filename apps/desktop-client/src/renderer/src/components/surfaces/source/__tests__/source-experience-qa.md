# 来源资料链路验收

日期：2026-10-03。对应本次来源 UI 重构，不是全项目验收声明。

## 设计取舍

- 资料架负责找材料和随手收录；文件标记、薄荷承托面、蜜桃操作与浅纸面构成物件感，不使用统计面板或固定半页侧栏。
- 阅读纸面占据主空间，片段与笔记作为按需展开的附页。跳转先立即定位和聚焦原文，关闭运动不阻塞操作。
- 文本、链接和文件在同一张采集纸页完成；收起保留草稿，标题可留空，重复材料给出打开已有、再次采集与返回修改的明确选择。
- 按压和纸页开合复用现有弹簧，反向切换保留当前位置与速度。Full 回弹、Lite 仅淡入淡出、Off 与系统减少动态立即完成。

## 真实窗口

使用独立 Electron 验收应用、独立 profile 与本机独立测试数据库，不改个人账户、默认数据库或现有角色密码。主进程、preload、renderer 与 API 为真实构建；文本解析使用生产 `parse_source` handler 和受限 worker 角色，没有 renderer gateway mock。

- 1440 x 810 内容窗口，100% 缩放：资料架、采集纸页、阅读正文、片段附页、笔记往返与伴星位置已检查。
- 125%、150% 缩放及原生菜单继续放大：长标题换行，阅读工具未互相覆盖，采集纸页内容可独立滚动。随后恢复 100%。
- 约 3.9 KB 的中文 Markdown，含长段落、标题、引用、列表、代码：关闭重开保留正文和标题；键盘提交得到真实待解析索引；解析后自动更新为就绪。
- 手动填写的长标题经过生产解析仍保留，没有被正文标题覆盖。
- 片段 12 定位实际代码块，附页关闭，焦点落在原文；代码不显示重复围栏。
- 从原文创建笔记：真实富文本节点不再出现 `#`、`>`, 重复列表标记或代码围栏，保留来源关联。
- 从笔记返回来源：仍是同一份材料，并恢复到原来的代码阅读位置；返回资料架入口仍正确。
- 原生文件选择器直接选择本次专用 Markdown 文件：正文和去扩展名的文件名进入草稿。读取完成后的焦点、读取中继续填标题的行为另由定向回归覆盖。
- 在设置中实际切换 Full、Lite、Off；Lite/Off 快速打开、收起、重开后正文仍可立即聚焦。最终恢复 Full。

## 自动验证

- 来源与跨页收录：14 个测试文件，99 项通过。覆盖晚到检索、搜索/滚动恢复、重复材料、片段定位、阅读往返、异步失效、文件焦点、工作区切换与弹簧反向运动。
- 样式顺序、类名闭合、死样式、变量解析、可读视图登记与来源样式契约：6 个文件，37 项通过。
- API 来源服务与来源到富文本转换：32 项通过。转换保持原始片段、偏移量及一对一证据关联，版本快照与搜索使用转换后的正文。
- Worker 解析相关：121 项通过。真实 PostgreSQL/RLS 解析回归：5 项通过，包含手动标题与自动标题及搜索索引一致性。
- shared、api、desktop-client、ai-worker 的对应 `npm run typecheck` 通过。
- 桌面生产构建与房间素材输出校验通过。构建和临时测试环境位于忽略的 `outputs/source-experience-2026-10-03/`。

## 未覆盖

本轮没有在操作系统开启“减少动态”，对应路径由动效与样式测试覆盖；没有用真实外部网站验收 URL 抓取，也没有在原生窗口完成批量拖入、归档/恢复和大图片缩放，这些路径由定向测试覆盖。未调用 AI 生成学习卡，不将其计为来源链路已验收。
