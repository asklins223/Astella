# 插入链接弹窗样式 · 2026-10-08

用户指出弹窗与笔记册页风格不一致。真实窗口确认弹窗是 notebook-workspace 的兄弟节点，未读取册页局部配色；控件沿用旧棕边样式。

链接与学习版本确认共用 notebook-dialog，直接读取册页纸面、薄荷和墨色，并复用册页按钮的边框、短阴影与绿色主行动。链接类型复用 HudSegmented；笔记选择保留 radio 语义，由应用绘制圆标与整行选中底色。正文区在空间不足时滚动，操作区保持可见；按压复用 useNotebookTouch。
