# 笔记全屏与选文体验 · 2026-10-08

## 已确认的体验

正文铺满应用视口，奶油纸面替代普通册页装订与书房控件。预览、富文本编辑与源码继续使用同一份工作稿；右下借用固定的小伴星座位，不保存为用户的新位置或比例。右上折签展开浮动工具页，目录、资料与源码设置按需展开，正文不被工具开合挤动。入口是「全屏」或 ⌘/Ctrl+Shift+F。

选句操作、目录、资料、源码查找、伴星交流与更多菜单先处理自己的 Escape；之后收起工具，再合回册页。隐藏工具立即 inert，焦点不等待动效；保存错误单独留在页边。正文编辑器保持挂载，进出时按可见段落和相对位置接续，伴星普通座位重新测量后的布局提交也接住；下一次输入立即释放定位。

用户后续确认：Windows 原生标题按钮不能压住折签；拖选期间不要出现选句操作。Windows/Linux 折签读取标题栏高度（无值时按当前 main 的 40px 合同），再留 12px 间距；工具页与旁页跟随折签位置。普通与全屏阅读共用选择 Hook：按下正文时隐藏旧菜单，selectionchange 在拖选期间只更新浏览器选区，松开后发布最终原句；键盘扩选松键后发布。取消与失焦释放手势，菜单按钮保留原句供实际动作使用。

## 普通页面跟进 · 2026-10-08

用户指出普通页面右上空间控件也可能与 Windows 标题按钮重叠，以及册页上方五个学习标签消失。空间控件改为使用全局已有的 `--native-caption-width`（读取原生 overlay 的当前宽度，默认 138px），再留 12px 间距；右侧默认从 25px 调到 150px，macOS 位置沿用原值。

标签的消失是这次全屏实现引入的问题：为了保留工具节点，将学习导航移进了 `overflow:hidden` 的 spread，再负向放到纸外，结果被截掉。普通模式恢复为册页外侧的正常流导航，全屏模式仍收在浮动工具页内。移除固定 57px 占位，标签高度跟随实际排版与紧凑规则；正文编辑器仍保持相同的挂载位置。

本次类型检查和 3 个相关测试文件（34 项：Desk 焦点、全屏、空间控件）通过。1504×862 真实 macOS 窗口已确认五个标签可见；同一运行页面的 DOM/CSS 隔离检查覆盖 Windows/macOS、1504×862 / 1280×720 / 960×540 / 720×405 与空间控件开合，共 16 组，标题按钮占位无重叠，五个标签中心均可命中按钮。`ordinary-layout-check.json` 是隔离布局证据，不代表原生 Windows 实机验收；最终普通窗口截图为 `12-ordinary-tabs-restored.png`。


## 全屏切篇与返回 · 2026-10-08

用户新决定：跳转到其他笔记时保留全屏，并支持在全屏内返回上一篇笔记。全屏从单篇正文的持有状态改为当前 NotebookSurface 访问期间的显示模式；正文因换篇而卸载、等待投影或读取失败时保留纸面和右下伴星。右上折签旁提供返回箭头，加载状态也可返回或退出；新篇的工具默认收起。

库内链接沿既有 returnTarget 返回链逐篇回退。其他入口直接切换 note identity 时，全屏访问补上相同的返回路径；当前主笔记没有显式路由时使用正在显示的笔记作为来处。返回带回原有正文模式，跳转前记录最后的阅读位置；空间变化、离开 notebook 或主动退出结束全屏。旧返回动作不抢当前路径，晚到的库内链接回执沿既有请求与来源身份守卫处理。

真实 macOS Electron 窗口：在「电功率与电阻」末尾点击真实库内链接进入「欧姆定律的适用条件」，再通过全屏返回箭头退回。渲染帧采样覆盖两次加载纸面，全程 fullscreen 和伴星全屏标记均保持；返回前后 scrollTop 为 2285、可见块为 24、块顶相对偏移为 -27.859375px。过程只读取已有笔记，没有修改内容。证据 `fullscreen-navigation.json` 与 `13-fullscreen-before-link.png` / `14-fullscreen-linked-note.png` / `15-fullscreen-returned.png`。
