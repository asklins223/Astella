# Markdown 编辑体验验证 · 2026-10-08

用户要求图片和其他编辑细节参考 Typora，并明确提出多图并排。此记录区分本轮已经实现、实际验证和仍未覆盖的行为，不作为完整 Typora 等价验收。

## 参考与本轮决定

参考 Typora 官方 [图片](https://support.typora.io/Images/)、[尺寸](https://support.typora.io/Resize-Image/)、[表格](https://support.typora.io/Table-Editing/)、[代码块](https://support.typora.io/Code-Fences/) 和 [即时编辑](https://support.typora.io/Quick-Start/) 说明。

- 图片是正文中的行内节点，独立单图居中；批量插入在前后文之间形成一排，可把相邻图片段合并、加入第三张或拆开。图片属性只在选中时浮在纸面上。
- 缩放直接预览，放手才提交；方向键微调。整排尺寸一起保存，邻图按比例让出空间。尺寸使用可携带的 HTML `img` 属性，单图无尺寸时仍用普通 Markdown 图片语法；保留 alt、title、链接和来源信息。
- 编辑、源码、阅读、Y.Doc 投影和重新解析共用内容。旧 HTML 图片可直接编辑，打开文档不批量改写旧内容。上传占位有本地预览，批次一次插入；换笔记后忽略旧上传结果。
- 表格支持 Tab 换格、末格 Tab 加行、Mod+Enter 加行、行列增删移动与列对齐。任务列表用真实复选框，格式栏反映光标状态并能切换标题、列表与引用。
- 代码块用 CodeMirror 编辑，支持语言搜索、高亮、行号、缩进与复制；代码撤销仍使用共享文档历史。Mermaid 提供现有严格渲染器预览；支持范围内的公式离开光标后预览、点击返回源码。

## 真实窗口检查

使用本机 Electron 临时窗口，加载当前 NotebookDesk、NoteDocumentEditor、格式栏和产品样式，样本保存在隔离 Y.Doc 中。没有写入真实账户笔记，也没有替换已安装应用。

| 操作 | 结果 |
| --- | --- |
| 相邻单图合成两图，再加入第三张 | 三图在同一段并排，前后文保留，属性浮层不进入正文 |
| 手柄拖动与方向键缩放 | 图片框贴合图像，邻图比例连续变化；源码记录尺寸，撤销恢复尺寸 |
| 源码与编辑往返 | 图片顺序、URL、说明和尺寸保留 |
| 表格末格 Tab、Mod+Enter、中文输入、列对齐 | 加行与换格有效，整列对齐生效，正文可继续编辑 |
| 代码语言、代码输入、撤销 | 高亮与控件可用，输入同步正文，撤销只回退对应编辑 |
| 任务复选框、公式和 Mermaid | 显示真实控件和预览，代码编辑入口保留 |
| 并排图片进入全屏 | 图片排版随正文可用宽度变化，仍保留分组与比例 |
| 图片面板打开后连续两次 Esc | 第一次收起图片面板，第二次退出全屏；修复 ProseMirror 对原生 keyCode 27 的默认拦截 |

## 尚未覆盖

- 当前实现保留 Milkdown 的即时富文本编辑方式，尚未实现 Typora 全部 Markdown 标记随光标显隐的精确行为、完整快捷键和所有语法细节。
- 跨多个文本节点/硬换行的多行显示公式尚未实现编辑态预览，源码与阅读通道仍保留原有内容。
- 上传链路用 gateway 桩测试批量与迟到结果，没有在真实对象存储账户执行上传验收。
- 临时窗口没有完整书房、Live2D 或真实多人连接。伴星座位、多人并发修改及已安装应用仍需对应环境验证。
