# 笔记详情快速切篇 · 2026-10-08

用户要求笔记详情增加可收缩笔记列表，全屏也能使用。列表由 NotebookSurface 的访问持有，独立于换篇时的正文加载；数据走现有 note.list、当前空间会话与可见性规则，只列非回收站笔记，不按每一行读取正文。

普通册页与全屏默认都收起列表。普通册页收起后只在顶部页签旁留入口，列表列宽与间距归零，正文获得整列空间；展开后左侧薄荷内页承载列表，可用纸面不超过 760px 时改为浮层。全屏左上按钮与列表都避开原生标题栏；展开不挤动正文，切篇保留全屏与展开状态。两种模式分别记住本次访问的展开选择，共用搜索词与列表阅读位置。查找按标题继续读取后续分页，保留同名笔记；从后页或搜索打开的当前篇在其列表分页未读到时仍显示已知标题，不编造更新时间。

点列表走原有 activeNoteRef 路由，点击当前篇不重复导航；换篇建立带身份与空间守卫的返回路径。正文继续使用既有草稿保存与阅读位置机制。列表读取失败在列表里重试，不遮住正文；刷新与分页各自重试原操作，旧空间迟到的回执不能显示标题。浮动列表在点回正文或转向工具时合起并保留新操作的焦点，键盘打开工具也不会叠在列表下方。显式关闭时列表立即 inert，焦点回入口，动效复用现有可打断纸页弹簧；Off 和减少动态即时就位。
