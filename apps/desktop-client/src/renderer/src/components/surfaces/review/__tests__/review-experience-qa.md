# 复习链路体验核对 · 2026-10-03

本次按「温暖、圆润、有物件感的小卡盒」重做复习队列、从队列进入的作答纸面和结果页。卡片正文优先，后续顺序放在旁边的小口袋，导航留在卡堆之外。长内容可以滚动，提交与返回保持可达。

## 实现与修正

- 卡片位姿由 `use-review-deck-motion.ts` 单独持有。切换目标保留当前位置与速度，抓取接续当前呈现位置，横向拖动跟手，松手把速度交回弹簧。到达静止位置后停止帧循环。
- 复习按钮接入公共 `useTactileSurface`，避免 CSS 与 JavaScript 同时接管同一个位移。Full 保留弹性，Lite 简化运动，Off 与系统减少动态立即呈现。
- 开始或延期请求发出时立即锁住重复命令和翻卡；失败重试绑定原来失败的项；后到的分页响应可以补充数据，但不能覆盖读者刚刚反向选择的位置。
- 延期移走卡片后把焦点交回卡堆，键盘可以继续翻下一张；焦点交接不等待弹簧或动画帧。
- 延期明确写「明天再提醒」，请求为 24 小时后的提醒时间；它不改变正式到期时间，也不代表完成复习。回执进入页眉布局，避免遮挡后续顺序。
- 原文变化时提供核对入口，证据缺口提供补齐入口。题目准备期间的提取线索、原文查看与答案暴露边界保留。
- 窗口核对发现作答区域的高度传递中断、200% 缩放时底部操作被裁切，以及旧房间样式把队列侧栏误当成圆形按钮。已分别修正高度链、底部布局与样式作用范围。

## 窗口覆盖

使用独立 Electron 预览窗口，内容区 1440 × 810。复习命令与学习运行命令使用隔离的 preload fixture，包含三个长标题、长题干和十二条长反馈；没有向真实复习排程或学习记录提交这些测试操作。

| 操作 | 核对结果 |
| --- | --- |
| 100% 比例读取卡盒 | 正文、后续顺序、翻卡按钮可读，伴星留在纸面旁边 |
| 拖动切换与快速左右往返 | 当前项立即变化，回弹追随最后意图，未出现稍后跳回旧项 |
| 选中第二张，离开，再回队列 | 仍选中第二张；预览连接恢复后也保留该位置 |
| 点击「明天再提醒」 | 数量减少，当前位置接上下一项，回执说明正式到期时间未变 |
| 连续延期直到清空 | 展示没有到期项的状态纸和今日学习、写笔记入口，没有显示完成学习的结果 |
| 150% 与 200% 比例作答 | 长题干和输入区可以滚动，提示及提交入口可达 |
| 200% 比例提交 | 实际点击提交后进入结果演出，可以跳过并阅读完整反馈 |
| 长反馈滚动与返回 | 可以读到后部反馈；返回队列按钮保持可达，完成项从测试队列移除 |

提示、答案暴露、暂停、稍后再做及错误边界主要由学习运行组件测试覆盖。本次没有在系统设置中切换减少动态，也没有重新验证真实模型评分或真实排程写入；这两者的合同与实现未改动。

最后的页眉回执布局调整已通过组件回归与构建；重新打开预览时学习服务再次刷新状态，未补拍该调整后的回执截图。延期与队列清空操作本身此前已在窗口中核对。
