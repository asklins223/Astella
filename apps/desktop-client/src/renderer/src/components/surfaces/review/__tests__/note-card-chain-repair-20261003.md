# 笔记 → 制卡 → 候选审核修复验收

2026-10-03 用户要求恢复实际 3D 候选卡、两页直接重新生成、按笔记版本切换入口，并重新设计制卡页面与背景。

## 当前实现

- 用户再次否定旧版的来源便笺、棕色书签、衬线题面和漂浮文案。本次改为一本打开的薄荷卡册：状态与操作在装订侧，实际题面在奶油内页，等待时沿用卡组页的立体卡包物件；字体回到项目的 Noto Sans。取消四段轨道及阶段推算的整体百分比。
- 读数同时依据任务计数与已落地的候选列表，区分已写出与通过核对。两个接口的更新时间不一致时，界面不能一边显示已写出的题面、一边仍报 0 张；状态文案、读数与进度语义使用同一份派生结果。
- 生成中的页面提供停止；服务端确认已取消并重新读取状态后，才提供重新生成。重新生成读取笔记最新已保存版本、另建任务，保留上次选择的生成参数。
- 审核页直接重新生成。先读最新笔记，读失败时保留旧审核；关闭旧审核后启动失败时，仍可再次操作。已保存卡片沿用原有服务端生命周期，不因开始生成而删除。
- 笔记页比较当前版本与任务来源版本，也比较实时正文与已保存版本。自动同步清掉 dirty 后，未定版的新正文仍保持「生成学习卡」入口；方案页阻止使用旧保存版本开跑。保存期间禁用启动，版本回读完成前不会切回旧审核。旧任务另设查看入口；旧版本仍在生成时，引导先停止旧任务。
- 恢复 WebGL 倒角实体卡、厚度、阴影和双面 DOM。DOM 面按窗口尺寸投影，保留文字选择、长题滚动及即时语义焦点；运动可以反向打断，Lite、Off、减少动态使用静态实体卡，WebGL 失败时使用完整 DOM 后备。
- 审核标题、导航、答案提示与练习披露收进同一纸面，收纳盒读数与保存提示有纸面承托。删除「给值得反复想起的知识留一个位置」等装饰文案，继续使用实际 3D 卡作为主物件。
- 制卡页使用独立陶土色桌垫的日夜背景；审核页恢复原有近景木桌。删除后加载的 card-study-scene.css 对 .card-generating 的背景接管；背景回归包含该文件与页面样式的真实加载顺序。

背景文件与完整生成提示词位于 renderer/public/assets/card-making/README.md；两张图片登记在 taskPosters.cardMaking。

- 审核页直接重新生成后进入新的薄荷卡册。独立背景、卡组页的立体卡包、停止按钮与返回笔记均在实际窗口显示；generation-folio-window.jpeg 是已目视核对的原生截图。
