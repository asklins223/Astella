# 理解星空体验验证

2026-10-03。用户明确否定把星空框进圆角卡片，要求沿理解星图整条链路重构，保持圆润、轻快、有弹性的书房体验。

## 结果

- 星空直接铺满窗口，标题、真实星体与标签属于同一场景。奶油纸面用于展开阅读，查找、阅读方式和视野工具浮在边缘；装饰星尘不进入节点计数。
- 目标是圆润恒星，笔记是薄荷星座，来源是桃色行星，证据是小卫星。无标题笔记仍可查找、选中与阅读，总览减少重复标签；完整标题由悬停、搜索和详情承接。
- 搜索定位目标并保留周围关系。状态筛选保留相关来源、笔记与证据；笔记、来源和证据不被赋予学习目标的掌握状态。笔记总览、问题与关联、学习足迹锚在同一篇上，目标明确连接所属笔记。
- 星体点选、按钮、页签、旁页和相机用可打断弹簧，反向接续位置与速度。短拖动的后续滑行不超过拖动距离的 45%，另有 120px 上限；暂停后松手不再突然甩出。
- 打开笔记、来源或学习卡前保留选择、视野、阅读方式、筛选、图层和滚动位置，返回恢复。Esc 优先处理当前搜索、图层浮页或详情，键盘和内容不等待动画。
- 紧凑外壳仍保持全窗口画布；底部工具按伴星实际座位让位，筛选与缩放分两行。详情和小册本使用同一座位预算，伴星缺席释放空间。适配总览可低于旧 12% 下限，远视野的星体随比例缩小，命中范围保留额外余量。
