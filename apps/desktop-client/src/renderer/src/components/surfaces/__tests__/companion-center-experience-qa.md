导航壳在 `companion/companion-center-surface.tsx`，七个 `*-page.tsx` 分别持有资源和写入，`*-panel.tsx` 表达可见内容与可读视图。`Activity` 保留切页草稿与滚动位置，隐藏页解除订阅和可读视图登记。对话与轻聊使用同一份草稿、会话和发送链路；工作区切换清除草稿，迟到回执由 workspace epoch 拦截。

样式在 `companion-center.css` 和 `settings/settings-companion.css`，从 `styles.ts` 接入。中心的 `use-companion-tactile.ts` 管理页签圆垫、页面进入和按压的弹簧；设置接入当前 `SettingsBook`，由 `use-settings-tactile.ts` 统一驱动，伴星子页不再重复接管动效。反向操作从当前位置与速度接续；Full 保留轻弹，Lite 收敛，Off/系统减少动态直接到位。功能、焦点和输入不等待动画。日期、时间、开关、下拉、播放与删除确认均由应用绘制。

纸面宽度使用伴星实际占位预算，包含形象、头部和身边按钮；容器变窄时页签和正文重排。真正没有记忆时只保留一个空状态，并说明添加或确认记忆的入口，不显示无内容的详情栏。纯图标的设置入口保留独立读屏名称。

## 本次修复的调用链

- 对话分页到末页后停止；搜索的编辑值与已应用值分开；较早消息按目标读取。旧消息的块格式统一归一化，避免真实历史接口返回 500。
- 日记操作携带当前日期与版本；“聊聊这篇”使用共享会话的 diary reference。正文、图片和引文按原始顺序呈现，失败不丢草稿。
- 从日记、动态、星图或回收区定位记忆，均可补读最近 200 条之外的目标。等待补读时不误选其他记忆。删除保留 30 天，彻底清除单独确认；三条以上冲突保留到实际只剩一条。
- 人格写入使用当前 revision；失败保留编辑，成功后才收起。默认人格、待生效版本和旧版本恢复使用实际服务端回执。
- 设置按账号/设备区分保存；冲突重读当前 revision，保留静默时段草稿。声音页隐藏后清理播放器，返回同一 DOM 时重新绑定。
- 永久清除确认默认聚焦「取消」；Esc 收起当前确认并把焦点还给原操作，不关闭整页、不发出清除请求。记忆详情、回收区和设置中的清除确认使用同一原则。
- 导出流式写入下载目录「理解书房/伴星」，实际落盘后返回路径与字节数，不打开系统保存框。失败或工作区变化清理未完成文件。
- 修正数据库的作者/认识状态约束和来源归档遮蔽；来源关联按工作区、用户与真实引用定位，不遮蔽同一天其他用户的日记。角色初始化重新授予迁移已授权的伴星函数，修复受限 API 恢复记忆时报权限错误。
