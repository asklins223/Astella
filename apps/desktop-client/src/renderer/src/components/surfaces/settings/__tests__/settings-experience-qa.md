# 设置中心体验核对 · 2026-10-03

用户确认保留左侧分类、右侧内容的布局，要求动森式的圆润、清新与 Q 弹触感，并审视设置项的实际作用。

## 设置取舍

| 项目 | 处理与理由 |
| --- | --- |
| 账户、学习空间、成员与邀请 | 保留实际管理链路；个人资料先于空间，保存、加入与重命名增加读取、空值、忙碌和重复值守卫。 |
| 随时间变化的主题 | 补上真实的本机偏好入口，恢复既有白天、黄昏、夜晚时钟联动；手选日间或夜间保持固定。 |
| 伴星恢复默认位置与大小 | 补上本机恢复入口，解决拖到边缘或纸面前方后难以找回的问题。只恢复座位与 100% 大小。 |
| 动效等级与减少动态 | 保留；添加可按压的叶子试样，使偏好能够当场感受。 |
| 重新认识书房 | 从外观表单移到分类栏底部，作为随时可找到的帮助入口。 |
| 没有接口的删除账号 | 移除。占位删除按钮与虚构联系地址不能完成用户目标。 |
| 重复的归属、当前工作区、可见空间 | 移除重复行，只在导出旁说明存档的实际空间范围。 |
| AI 能力和设备功能状态 | 默认折叠；它们用于了解当前能力和排障，属于读取结果，没有配置开关。 |
| AI 外发示意图 | 移除用伴星读取权限推断全部 AI 外发的错误表达；同意仍由本人签署，并在同一部署的各空间通用。 |
| 高级维护 | 改成「搜索异常排查」，说明何时需要检查索引，再展开真实统计和重建操作。 |
| 音色选择 | 明确写「用这个声音」，避免把选择音色表达成更换形象。 |
| 更多提醒、阅读字号、模型/供应商配置 | 本次不增加：提醒需要确定递送与排程合同，字号需要贯穿正文与布局，供应商配置没有用户级接口。不能为了丰富设置数量增加无作用项。 |

## 实现与自动验证

设置册只由一个正文区域负责滚动；分类和伴星子页保留草稿、展开状态与阅读位置。目录圆垫、按钮、开关和选项由同一个动效所有者管理，使用解析弹簧并保留当前速度；输入、选中与焦点即时生效。

相关 8 个测试文件共 121 项通过，覆盖设置业务、往返保留、目录键盘路径、动效反向打断与取消、关闭和系统减少动态、下拉菜单顶层展示与退出、样式接入和变量解析。桌面构建通过。完整桌面类型检查仍被同时存在的 `space/__tests__/star-map-camera.test.tsx` 四处缺少必填 `selectedId` 阻断；没有设置相关类型错误。

下拉菜单使用应用绘制的顶层 popover，保持设置样式；Escape 返回触发器，Tab 正常前进，外部滚动/缩放关闭，关闭中的菜单不可再次提交。

日志保存在 `apps/desktop-client/outputs/settings-experience-20261003/`。测试出现既有 jsdom 媒体 pause 未实现提示，断言和套件通过。

## 真实窗口覆盖

在已登录的 Electron QA 窗口、1440×810 内容区检查了账户页、主题与动效、伴星陪伴规则和声音与显示。观察到左侧分类保持稳定，右侧正文与页脚操作可达，长说明换行，伴星保留右侧位置，日间主题卡与自动主题状态正常。实际试过连续按压叶子、完整→轻量→关闭→完整切换及「往下看看」滚动。

当前这轮没有完成 125% / 150% / 200% 缩放、成员和维护页的全部窗口交互、顶层菜单的真实键盘路径或系统减少动态的操作系统实测；相应自动断言通过不能代替这些窗口证据。共享 QA 应用在检查中被其他工作更新，独立设置 QA 窗口未恢复登录，因此不将这些状态记作已验收。没有执行账号同意签署、成员权限修改、永久清除或其他真实数据写入。
