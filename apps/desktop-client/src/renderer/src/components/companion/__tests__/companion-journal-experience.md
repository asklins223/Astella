# 对话手记体验与验证

2026-10-05，根据本次用户要求实施；工作区重置后的其他内容保留。

## 阅读与操作

- 奶油封皮、薄荷目录和连续内页组织「全部对话、伴星念想、交给我的事、待确认」。用户消息是右侧浅桃纸签，伴星正文平整排版。
- 正文与实际成果先读。原文引用、出处、执行详情和完成的确认默认折叠；待决定的动作直接显示，已确认但仍在执行的动作仍能查看进展。
- 念想使用独立的只读历史接口，限当前用户和空间已经表达过的内容，包括后来聊起过和到期的表达。翻页不会消费念想或生成对话；「聊聊这句」只带入引用。
- 切页保留输入草稿、阅读位置和已加载的念想分页。搜索、日期定位与返回最新对话继续使用原消息身份。
- 册页开合可接续被打断的弹簧；关闭立即停止接受交互，Off 和系统减少动态即时就位。

## 本次截图反馈

输入纸曾叠加两组焦点样式：共享 `:focus-within` 提供内阴影，手记通用 `:is(..., [tabindex]):focus-visible` 又给 textarea 画了矩形描边。第一次局部覆盖的优先级不足；`[tabindex]` 提高了整组 `:is()` 的优先级。最终使用作用域更明确的 textarea 规则消除内层描边，输入纸仅改变已有细边和底色。工具按钮、目录及展开控件的键盘焦点规则保留。

目录悬停的下划线来自全局 `.text-action:hover`。目录自己的规则重设 `text-decoration: none`，用底色表达悬停与选中。

在真实 Electron 窗口验证了输入框实际聚焦：可访问性状态确认焦点在「继续问」文本区，截图仅有输入纸的一条细边，没有内部矩形。点击并停留在念想目录时，两行文字都没有下划线；Personal Beta 的实际念想记录成功显示，包括「曾想对你说」和「后来聊起过」。长对话中输入纸保持在底部，伴星仍位于纸面右侧。
