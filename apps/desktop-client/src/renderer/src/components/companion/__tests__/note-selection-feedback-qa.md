# 笔记选文解释与批注验收 · 2026-10-02

用户确认保留选文反馈，重新设计摆位与状态。选文条现在嵌在伴星的处理、回复气泡中，点击回到原句的解释附页，随气泡一起收起。原句保留轻量虚线与段落状态入口，说明准备、解释、保存、停止或中断；完整生成并收到保存回执后转成正式批注。

## 状态与并行操作

- 每次解释冻结笔记、版本和原文范围。重复解释同版本的重叠选区时打开已有进度；旧版本、旧发送和旧回执不会占用新选区。
- 伴星生成时仍可另写自己的批注。两份内容分别保存；伴星保存回执更新原句入口，不替换用户正在写的附页、不抢焦点。重叠的正式批注各有可操作入口。
- 准备中立即停止会阻止提交；停止与提交回执交错时会取消迟到的 run。生成中停止先结束本地接收，迟到的增量与最终消息不得复活解释或写入批注。
- 主动停止、断流、失败或超时保留本次可读残稿，并明确标为未完成、未保存。可重新解释或收起状态；停止请求未获服务端确认时可重试停止。
- 完整解释保存失败保留全文，只重试保存同一份结果。回执按原笔记、版本、范围和消息身份核对；成功后只写一次。切换工作区会隔离旧回执。
- 解释状态由会话运行时维护，气泡关闭不丢生成或保存状态。未完成状态暂存于本次运行内；本次未实现应用重启后的任务恢复。
