# 伴星等待与状态表达 · 2026-10-07

本轮按用户要求检查伴星 loading 和周边文案，沿轻聊、任务气泡、对话手记、伴星中心与服务端状态事件调整。

## 表达与呈现

- 加载已有记录明确说加载什么，不再用“翻找”“来到书桌边”“取声音”代替状态。
- 文字消息发送、等待回复、真实思考、工具处理及组织回复分别表达。工具结束不宣称已经读完材料；之前的思考节点不覆盖当前阶段。
- 语音识别与伴星回复分开表达。朗读准备、暂未播放和播放失败各有交代，静音或声道占用不猜成“她在念别的话”。
- 任务排队、运行、等待生成、暂停、失败与停止使用明确状态。结果不明提示先查看记录，优先于额度用完后的重新交代建议。
- 初次读取任务不同时展示空任务邀请；读取失败不当成没有记录；刷新仍保留已读取成果。
- 中心初次加载使用轻量文字和静态沙漏，与空状态、读取失败分开；加载期间不展示重新读取按钮。
- 形象加载失败明确限于形象，恢复入口保留。日记失败说明未生成或未保存，去掉“在报数”等评价性文案。
- 过程摘要保留真实步骤和操作数，移除执行上限；旧语音状态样式在确认没有运行时使用后清理。

## 验证

相关伴星回归首次覆盖 80 个测试文件。文案断言同步后，对失败文件及关键状态测试复验：13 个文件、156 条用例通过。样式接入、顺序守卫通过，清理旧语音样式后死样式守卫 5 条通过。带路首次读取的测试回执补齐网关类型，17 条用例通过。桌面与 worker 类型检查通过。

真实 Electron 窗口核对了新的轻聊输入提示、发送等待气泡、实际回复与伴星中心近况、记忆长内容。未在真实窗口逐项注入网络失败、形象加载失败和长时间等待；恢复分支由自动回归覆盖。未重新录制完整语音往返，也未逐项复验所有缩放比例和动效偏好。
