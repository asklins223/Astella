# Desktop learning-card scenes

These three original backgrounds were generated with the built-in `image_gen` tool on 2026-10-20 for the production learning-card pages. They replace the reused prototype backgrounds. They are not UI screenshots.

| File | Used by | Composition |
| --- | --- | --- |
| `sunroom-v1.png` | Dedicated card front and practice record | Botanical reading conservatory, broad oak table, books and plants toward the edges |
| `atelier-v1.png` | Generation settings and waiting | Bookbinding atelier, cream paper, sage shelves, an uncluttered workbench |
| `focus-room-v1.png` | Answering, grading, celebration and results | Treetop garden study, calm cream wall, sage curtains and a warm desk |

The intended palette follows the notebook: cream `#fffbef` / `#faf5e5`, mint `#bfd5a9` / `#d4e9c8`, honey wood, peach `#f5ddc9`. The center is kept calm for actual paper UI; no text, controls, characters or marks are baked into the images.

The complete final prompt set, generation tool and filename mapping are saved in [generation-prompts.json](generation-prompts.json). Original generated files remain in the local generated-images directory; the application consumes the copies in this folder.
