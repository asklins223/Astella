# 伴星交互 Demo（2026-10-01 修订）

先评审 HTML，再实施生产 UI。本页只连接仓库内已有 Live2D 资源；消息、转写、工具过程与确认结果均为本机模拟，没有 AI 请求、麦克风访问、语音播放、持久化或业务写入。

## 打开

在 `apps/desktop-client` 目录运行：

```sh
python3 -m http.server 4175 --bind 127.0.0.1
```

预览地址：http://127.0.0.1:4175/demos/companion-interaction.html

## 这次修订的交互

- **两种聊天方式**：纯气泡轻聊，以及会话列表聊天。共用消息、草稿、引用与动作结果。切换不重开对话，列表合上后回到同一份轻聊。
- **对话手记与查找**：手记左侧不再用整根色条模拟书脊，外层左右留白一致，保留现有暖纸与柔圆纸边。查找聚焦时外层边界转 `--hud-clay`；键盘焦点环沿不规则圆角纸签外缘显示（`3px solid var(--focus)`、外偏移 `3px`），内部输入不再叠直角长方形描边。
- **用户输入气泡**：独立纸签，没有伴星回复。发送时同步设为隐藏，立即收起，没有延迟退出动画。已发送文字进入手记。
- **伴星回复气泡**：等待时不出现，从第一段回复开始显示，逐段补充；回复完成后自动收起。最近的真实指针、键盘或滚动操作短暂延后收起，静止悬停或焦点不会留下常驻回复。正文按实际空间扣除标题、底栏和尾巴的预算后独立滚动，长回复可用键盘翻到底。计时参数见下表，仍待用户评审。
- **语音气泡与按钮**：角色旁有独立麦克风小图标。录音、转写、可编辑的预览、发送和取消都在独立语音气泡。发送后立即收起，转写不自动发送；取消与发送语音都保留之前未提交的文字草稿。本页不会启用真实麦克风或播放语音。
- **引用**：输入中可以选择、展开核对或移除原文。用户引用与伴星返回引用都进入手记，返回引用单独显示，可直接定位到笔记原段落。
- **工具**：回复气泡上方的小型过程入口展示执行、完成、失败和停止；展开可查看输入与结果，失败可单独重试。回复保持主位，工具过程也会自动收起。只由演示场景触发模拟工具，不伪造每条消息都执行工具。
- **确认**：独立纸签支持确认、拒绝、等待与结果。待决定或正在处理时持续保留，回复文字收起后仍可操作；处理后的结果反馈自动收起。确认只改变演示状态，不创建真实学习卡。
- **图片**：独立图片纸签支持真实本地资源的加载、失败、重试与放大，并自动关闭。放大沿用同一份图片倒计时，到期同时关闭放大视图；打开与返回不重置时长。示例 SVG 为本次手绘说明图，清楚标明非真实模型输出。对话列表使用同一份图片状态。
- **其他现有富内容**：过程图、翻面卡片、笔记导航也共用内容模型，可在两种方式中操作。
- **身边小图标**：34px 可见圆面、44px 透明命中区、17px 图标；没有常驻文字或宽托盘。此数值仍待评审。
- **稳定座位与贴近气泡**：实际获准 Live2D 保持可见，座位大小不由气泡数量决定。短气泡按自身高度靠近可见头顶，剩余空气留在上方；长回复和富内容区域内部滚动。Full 最大回弹为纸边、尾巴与阴影留出空间，角色与四颗小图标保持稳定；具体间距仍待评审。资源失败显示真实说明，不造替身。
- **纸签面向正文**：图片、卡片、确认与其他富内容使用独立侧边附页；右侧伴星配左侧纸签，左侧伴星配右侧纸签。普通窗口同时显示笔记与纸签。紧凑窗口通过附页页签选择一张纸签，使用「返回笔记」恢复完整可读的笔记；笔记的「附页」计数入口可重开尚在展示期内的纸签。新富内容默认打开其附页，角色始终保留自己的座位。各区域独立滚动，具体几何数值仍是 Demo 提案。

## 生命周期评审参数

除待处理确认外，临时气泡与纸签都会自动收起。以下是本轮 Demo 已采用的数值，全部待用户评审，不是已批准的生产参数。

| 临时展示 | 本轮 Demo 时长 |
| --- | --- |
| 回复 | 完成后 1.2 秒开始收起；Full 退出 280ms，Lite 150ms，Off 即时 |
| 工具执行过程 | 最长 60 秒 |
| 工具完成、失败或停止结果 | 状态到达后 8 秒 |
| 引用、过程图、导航与错误纸签 | 60 秒 |
| 图片与卡片 | 90 秒；放大图片共用剩余时间 |
| 待决定或正在处理的确认 | 持续保留 |
| 已确认、拒绝或失败后的确认结果 | 10 秒 |
| 闲置输入与语音气泡 | 90 秒；保留未发送草稿与转写 |

气泡或纸签内最近的真实指针、键盘、滚动交互将当前计时暂停 2.5 秒；静止焦点或悬停不会无限停表。页面隐藏期间暂停，恢复可见后继续。相同内容重绘不重新起算；工具或确认进入实际新状态时开始对应结果时长。收起只改变临时展示，两种聊天方式仍共享完整消息、引用、图片与动作结果，可在手记中回看。

## 建议检查

1. 在“气泡轻聊”输入后发送：输入立刻消失；等待状态独立；回复出现并自动收起。
2. “完整交互”：直接在轻聊检查原文、工具详情、确认与拒绝、图片放大。工具入口位于回复上方，侧边附页页签可定位富内容；回复仍是视觉重点。
3. 保留一段草稿，切到会话聊天再返回；打开语音、说完、编辑示例转写，分别验证发送与取消。
4. “连接中断”验证工具重试、重新回复，并核对后来输入的草稿和引用仍在；“图片失败”验证失败说明和重新载入；不会把失败当成成功。
5. “长回复”用真实指针移动、键盘或滚动阅读，滚到底；保持静止焦点或悬停，核对回复仍会自动收起。打开会话列表核对全文。“第一次聊”与无搜索结果分别呈现。
6. 小窗口与缩放时，角色和四颗小图标仍在固定座位；语音结束和发送、回复尾栏、设置标题与关闭入口都在窗口内。设置内容、额外纸签和列表各自滚动，不带动整个窗口。确认、拒绝及重试后键盘焦点留在对应纸签；查找的展开状态跟随实际显示。
7. 在 Full 下首次打开、收起后重开输入与语音气泡，并从手记返回轻聊：检查整个回弹过程，左右纸边、尾巴和软阴影都不能被裁切。
8. 在普通窗口、原生最小窗口与放大视图中检查短气泡：它仍靠近角色的可见头顶，不因窗口剩余高度出现大块空白；调节形象大小后再检查。分别切换左、右座位，核对图片、卡片与确认纸签总在面向正文的一侧。紧凑窗口用附页页签检查原文、确认与图片，再用「返回笔记」恢复可读笔记；角色与小图标始终保留座位。
9. 打开手记，检查左侧没有贯穿色条、外层左右留白一致；展开查找并用键盘聚焦输入，焦点环只沿圆角纸签外缘出现，内部没有直角框。
10. 保持待确认纸签，等待普通富内容到期；图片放大也应随图片到期关闭。手记仍保留全部内容。闲置输入与语音预览收起后重开，核对未发送内容仍在；隐藏页面再回来，计时应从剩余时间继续。

场景按钮用于重置本地样例。“气泡聊天 / 语音聊天 / 会话聊天”三个角色旁图标才是正式交互方式的切换入口，不重置内容。

## 动效评审参数

| 动作 | Full 的可见反馈 |
| --- | --- |
| 输入、回复、语音气泡出现 | 560ms；48px 上行；0.78 → 1.09 → 0.98 → 1 回弹 |
| 额外纸签到达 | 同族弹出反馈，不逐字抖动正文 |
| 会话手记展开 | 560ms；110px 横向抽页；0.9 → 1.025 → 1 |
| 小图标重播 | 460ms；26px 进入；逐颗错开 90ms |
| 图标悬停 / 按下 | 1.14 / 0.78 缩放，仅细指针启用悬停 |
| 用户触碰角色 | 560ms；24px 跳起、3° 摆动与回弹；950ms 星光 |
| 确认完成 | 480ms；0.86 → 1.08 → 1 的盖章反馈 |
| 录音与等待 | 仅真实演示状态期间播放波形 / 点列；无闲置循环 |

沿用 `--hud-ease-out`。Lite 使用 150ms 淡入并停止循环；Off 与系统减少动效立即到达终态并暂停 Live2D ticker，保留已绘制形象。快速操作会取消旧动画，停止或切换场景使旧回复失效；图片和确认有独立生命周期。

生产改造要求已记入根目录 `DESIGN.md` 的 Companion Interaction Layer、Buttons & Fields 与 Interaction, Motion & Sound。本页尺寸、间距、时长与强度均为待用户评审的 Demo 参数；当前生产交互仍由 `CompanionHud.tsx` 承载。本轮生命周期、纸签位置、紧凑附页、手记色条与查找焦点修订只在评审 Demo 生效，生产实施尚未开始。Demo 文件不进入生产构建，也不改现有 renderer 样式入口。
