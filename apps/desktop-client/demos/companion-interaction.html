一篇关于 Query、Key 和 Value 的学习笔记

先想一个日常的场景

在书架上找一本讲海洋的书，你不会平均地看待每一本书。你会先看书名和目录，挑出与问题有关的几本，再读它们的内容。

Query、Key 与 Value 各做什么？

Query 表达当前想找什么，Key 用来判断是否相关，Value 是最终取回的内容。相关程度决定了每份内容在结果里占多少分量。

放回句子里，当前词的 Query 与其他词的 Key 比较，得到权重，再用这些权重汇总各个词的 Value。它不是删除“不重要”的词，而是让不同的内容贡献不同的分量。

“看过”与“理解了”之间

如果换成一个新句子，你还能解释某个词为什么会更关注另一个词吗？先用自己的话说一次，比重复定义更能帮你发现哪里还没弄懂。
