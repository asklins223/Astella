## 操作语义与验证边界

数据库操作是按任务类型执行，不按失败原因分组执行。因此重试与清理移至类型详情；失败分组只保留样例展开。确认文案说明类型范围，POST 显式携带不超过展示数量且最多 500 的 `limit`；批量清理同时显示总残留与本次处理上限。确认界面和取消路径已验证；未对真实任务执行删除、重试或容器启停。

## 刷新后的登录恢复 · 2026-10-07

按用户新决定，登录状态从仅内存改为当前标签页的 `sessionStorage`，按面板 API 挂载路径隔离。服务器验证通过后才保存；刷新时取回候选令牌，重新验证后进入后台。主动锁定或验证返回未授权时同时清除内存与会话记录。暂时连接失败保留已验证的会话记录，提供「重试恢复登录」，无需再输入令牌。登录页说明已同步；不使用 `localStorage`。
