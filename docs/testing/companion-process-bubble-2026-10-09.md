# 做事经过独立气泡 · 2026-10-09

用户决定：做事经过独立放在消息回复上方，只在实际调用工具时展示。消息文字与工具进展分别更新，伴星可以边说话边调用工具；两张气泡不互相替换。

薄荷色过程气泡默认展示当前动作、状态和操作次数，回复使用原有奶油色气泡。完成后显示紧凑结果；展开逐项读取真实回执，展开状态不被下一帧或回合终态强制合回。停止、待确认、结果不明、失败、未开始与能力不可用分别表达；无确定工具回执时不标成成功。停止按钮在过程气泡就地可用；终态可单独收起。

SSE 的 toolCallId 继续幂等折叠，首次工具帧即更新气泡。processRunId 在接收轮次回执时绑定，跨空间和新一轮清空，只与同轮历史摘要及快照匹配。快照补回漏接工具或终态回执并保存在当前节点，旧快照和空快照不会撤销已看到的确定结果。没有取得真实步数时不显示 0 步；工具次数以即时节点和同轮摘要较大值显示。

回复和工具气泡按各自内容渲染；无正文且已经开始工具操作时不重复显示工具等待文案。流式正文到达后立即出现在下方并继续按现有阅读/语音时钟推进。工具过程在长回复、正在朗读、遮挡或展开阅读时保留；成功回复显式关闭时同步收起成功过程，待处理结果仍有独立入口。

验证证据：

- 改动前相关 3 文件、42 项测试通过。
- 改动后相关 11 文件、146 项测试通过，覆盖 HUD、工具轨道、会话 SSE/快照接续、交付与历史、浮层定位及停留时钟。最后补强空快照接续后，会话 7 项再次通过。
- 桌面包 `npm run typecheck`、`npm run build`（含源与产物书房资源守卫）通过。
- 独立 Electron 宿主加载现役过程、材料与定位组件，合成工具帧先后经历 requested / executing / succeeded；核对消息在工具前到达、边说边查阅/保存、停止、无工具回复和结果待核对。
- 实际窗口核对正常及放大显示；浏览器 760×620 窗口核对展开回执与消息共处，过程没有水平溢出，Enter 能展开和合回。Full/Lite/Off 切换后状态正常；Off 下当前动作状态点的计算动画为 none。
