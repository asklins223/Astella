# 伴星是否自主、适当地选择搜索（2026-10-08）

用户要求：不要在提问中提示“联网”等方法，让模型自行判断是否需要搜索，检查滥查与漏查。

本轮保持现役 `opencode_go / deepseek-v4.1-flash`，经过真实 HTTP 建回合、队列、生产意图判断、Agent 工具执行、智谱接口与消息保存。没有固定意图、强制工具、换模型或根据评阅答案改生产路由。提问文本与预先确定的判据分开保存：只有自然提问进入请求，预期选择和判据不进入模型。

16 个独立案例各使用新建的合成账号/空间，避免之前明确要求查询的聊天污染结果；4 个连续案例接各自指定案例的真实回答，检查换话题。测试开启搜索、允许 AI 外发，使用只读权限；没有登录真实用户、修改真实用户开关。完成后合成账号总开关和搜索开关关闭、epoch 推进、会话令牌撤销。合成夹具仍保留供审计，不含令牌文件。

## 结果

| 分组 | 样本数 | 实际搜索的回合 | 结论 |
| --- | ---: | ---: | --- |
| 情绪交流、主观口味、基础知识、创作/改写、查询后的普通收尾 | 10 | 0 | 本组未发现滥查 |
| 当日天气、当前软件版本、现行开放/预约规则、本年度事件、当前产品映射 | 10 | 10 | 本组未发现漏查 |

10 个需要搜索的回合都有实际成功的 API 回执，不仅是模型提出调用。每轮实际请求 2–3 次；部分回合提出第 4 次调用，被当前轮预算门禁拒绝，因此工具账本条目数不等于实际请求次数。

完整回答为 **17/20 成功**。其余 3 轮在真实搜索后失败，不能当成整体功能通过，也不能误记成没有搜索：

- 上海博物馆预约：实际搜索 3 次，取得官方资料，最后 `unverified_quote` 引文校验失败，回合 `INTERNAL_ERROR`。
- 二分查找 → 当前 Chrome 版本：实际搜索 3 次，后续模型接口 HTTP 422，回合 `PROVIDER_UNAVAILABLE`。
- 给定天气材料写诗 → 当日实际天气：实际搜索 3 次，后续模型接口 HTTP 422，回合 `PROVIDER_UNAVAILABLE`。

这轮只验证与诊断搜索选择，没有为上述生成/引文失败放宽来源校验，也没有将它们改记成成功。

## 证据与复验

脚本：[web-search-discretion-probe.ts](../../workers/ai-worker/src/live-tests/web-search-discretion-probe.ts)。

基线证据在 `outputs/audits/2026-10-08-search-discretion/baseline-20261008-0139/`：

- `manifest.json`：运行前固定的提问、预期与范围。
- `results.json`：原始回合结果、意图、实际工具参数/回执、可见回答、失败码。其 `decision` 对最终失败标记 unassessed；这是回答级结论，查询选择另按实际回执统计。
- `selection-analysis.json`：从已保存回执离线导出的查询选择统计，未覆盖原始失败结果。
- `summary.json`：17 个完整成功、3 个未完成的回答级汇总。
- `fixtures.json`：已停用的合成账号/空间/对话身份，不保存令牌。

另有两例冒烟验证，普通安慰不查、当日天气查，均成功；没有把它们混进上面的 20 轮计数。脚本及 worker 类型检查通过。

```sh
cd workers/ai-worker
LIVE_SEARCH_DISCRETION=1 node --import tsx src/live-tests/web-search-discretion-probe.ts <新的证据后缀>
```

后缀必须新建，已有证据拒绝覆盖。`SEARCH_PROBE_CASES` 可选指定案例；连续案例自动带上其前置案例。只允许本机开发 API/数据库，运行会产生真实模型与搜索调用。

这是有限样本的查询选择测试，不是全部措辞的保证，也不是回答内容的正确率。搜索引擎可能返回旧资料或空结果；天气案例中模型确实尝试补搜并说明无法取得当日预报。没有独立逐条核对最终外部事实，也没有本轮新的原生窗口或真人听感验收。
