## 实际调用链

### 联想词

- `ConversationMethods.consume` 接收实际事件 `assistant.followups.ready`，以消息 ID、run ID、`messageContentSha256` 核对终稿身份。晚于事件返回的旧快照仍合并同内容的收据；内容改变时不继承旧联想。
- `CompanionSuggestionSet` 统一清理、去重、最多三项；当前回复之后已有用户输入、仍在发送／生成／录音／重连时不展示快捷发送。无关联的新主动回复不继承先前笔记引用。
- 大模型态、记录、浮动按钮、面板复用 `CompanionSuggestions` 与同一个发送锁；默认一条问题，其他问题由用户展开。按钮态显示一句完整短问句或「接着问」；面板复用记录态。原回复气泡保留时，快捷问句也可在其下出现。
- 点击调用现有 `submit`，长按可编辑。文字、图片、文件、语音及手动引用存在时不出现快捷发送。来源使用原提交的笔记／版本／选段或日记版本，不使用碰巧打开的另一篇笔记；失败保留同一发送意图和现有幂等回执链。

### 正式示例

- `RootView → FirstJourneyCoordinator → FirstJourneyView → AppStore(sample:) → MobileAPI.journeySample → JourneySampleEngine`。
- 示例使用正式 SwiftUI 页面和正文 Web Reader：创建／改写走真实的会话与建议确认组件，速览／脑图／拓展／学习卡复用正式成果页面。样例数据在 `JourneyContent`，未开放 Debug 夹具；Release 也能使用。
- 示例 API 入口在 HTTP、绝对图片、上传和音频 URL 之前截断，未知路由报错，不回退真实请求。示例不连接 WebSocket，不写真实会话缓存、不启动学习事实／Live Activity，不向真实 Agent 报送页面停留。原账号的对话草稿保持原样。
- 11 站为认识彼此、方言、创建、讲解、改写、速览、脑图、拓展、练习、结果、收尾。每站有快进、跳过、目录与稍后继续；嵌套建议、来源、拓展草稿和答题导航也有退出控制。切站停止旧音频并按方向转场；焦点与动作不等待动画。
- `visited / practiced / skipped` 分开记录。快进只切准备好的检查点；不确认建议、不保存偏好、不创建作答、不交卷。未交卷时结果站展示明确标注的报告演示，不展示伪造的个人分数。真实提交后按四题等权平均评分，并按当前规则换算星级。
- 第 1 版是原段落，第 2 版是对“空山”赏析段的润色；速览、脑图、拓展依据及四道固定题均引用准确的第 2 版原文。回看来源显式使用 `noteVersionId`。改写示例只接受预备的第 1 版整段选区，其他操作保留草稿并提示转到自己的内容。
- 示例草稿、未完成答案、操作和确认状态按服务器＋账号隔离恢复。关闭、快进和重启不把未完成作答记作零分；已经提交的结果不可被继续保存的草稿覆盖。
- 收尾的「保留示例」是独立明确动作，走 `/import/markdown`，以同一 `importId` 重试，只复制第 2 版正文；示例分数、卡片、对话、记忆和引导状态不复制。

### 声音与动效

- `Journey/Audio` 随包携带普通话、河南话、四川话、广东话各两句及一段讲解，共九段 MP3。生成脚本为 `apps/api/scripts/generate-ios-journey-audio.ts`，清单记录字幕与模型；仅合成项目编写的示例文案。
- `CompanionVoicePlayback.playRecording` 复用 AudioQueue 解码、音量计、口型值、停止／暂停和系统中断；快换方言、切站、退出和后台都会使旧播放失效。预制试听不向语音服务发请求，也不报真实播放成果。
- 小范围蓝色点阵用于联想出现和步骤响应；每次响应 850 ms 后停下，不延迟功能、不伪造进度。Canvas 只在前台且允许动态时以最多 30 fps 更新，静态背景不循环。应用减弱动效与系统减少动态任一开启时，点阵保持静态，转场取消位移。
- 对话中的语音输入仍走真实转写和现有授权；示例内的麦克风不申请录音权限，会说明可在真实对话体验。
