# 主动开口的「空、重复、没依据」：三轮真栈读数与两处硬伤（2026-10-16）

用户口径（本轮最新决定）：**「不用每次都必须要关联到具体学习上面……随机的，可以闲聊也可以聊学习。」**
这一条与 40 PRD 把"一次普通闲聊里强行转回学习"列为反面是同一个意思：闲聊是相处本身。
本记录只覆盖**正文内容**这一半；开口时机（该开口时不开口）另记。

## 现象与证据（真库，同一账号近三小时）

主动开口**全是**启动问候（`app.started`），正文几乎是同一句换时间词。修前最近 8 条：

```
周五晚上了才打开，今天过得咋样？
周五晚上了，才打开呀。今儿个过得咋样？
周五晚上了，又来了。今儿个过得咋样？
周五晚上了，又见面了。今儿个过得咋样？
周五晚上好，又来了。今儿个过得咋样？
……（同族变体）
```

判据：两两最长公共子串 **19 字**（「周五晚上了，又见面了。今儿个过得咋样？」），
8 条里 **6 条**结尾相同；套话命中「今天过得咋样」2、「又见面了」3、「又来了」2。

## 根因

1. **提示自己在递范本**。陪聊档的举例写着「问问他今天怎么样、说说你自己刚想到的一点什么……」——
   第一句正是她每次落进去、连着复用十几次的那句模板。历史就在她的上下文里
   （`companion_context_handoff_snapshots` 里能看到前几条问候原话），但没有任何一句禁止复用。
2. **禁止项被逐字写进提示，然后被抄成台词**。真栈实测：改掉范本后连造五次问候，
   第 2 次输出的正是提示里作为反面例子引用的那句「我去吃饭了，你先忙你的。」
3. 换由头之后又出现**编造看不到的环境**：「你房间里光线偏暗」「你那台灯搁左边还是右边」。

## 修法（`workers/ai-worker`）

- `companion-initiative-observation.ts`
  - **引她最近三次原话**（由调用方从回放历史里取，最多三条、各取尾部 200 字），并明令
    「这次的由头不要落在这几个上；上一句聊的是学习，这次就随口聊点别的，反过来也一样」。
    只引上一句不够——实测她会换几个字绕过去。
  - **不要求每次挂在学习上**：闲聊和学习都算，随性一点；别每次挑同一类，也别每次回到同一篇笔记、
    同一个时间点上。**这一条只给范围，不举例**：凡是在提示里给出的成句，她都会当台词抄
    （两次独立实测：「问问他今天怎么样」→ 十几次同族；写「闲聊随性」并附时间/近况的举例 →
    连着四次「周五晚上你没出去玩呀？」）。
  - **禁止项不复述原话**（执行收尾、屏幕外生活），只写"哪一类不能做"。
  - 补一条**看不到的环境**：不许描述、点评或假设他的房间、桌面与周围有什么。
- `companion-agent-runtime.ts`：从回放历史里取她最近三条正文传给观察块（不额外查库）。

## ⑤ 确定性角度轮换（同一轮内补上）

④ 轮证明"引原话 + 禁止复用"只是软约束：同一个由头换个说法照样连着来。所以变化这一步
换成**确定性**的做法——`openingAngleFor()` 按这一轮的身份（`preparationJobId` → 观察 id →
父运行 id）散列出三个**由头来源**之一，写进观察块：

1. 不引用任何材料：就着一件你此刻真想知道的小事闲聊（不聊他的房间、摆设，也不编排屏幕外的生活）；
2. 从他最近在学的东西里挑一处具体的来说（是你真在意的那一点，不是进度报告）；
3. 说一点你自己此刻想到的念头（一个看法、一个没想通的疑问）。

它只规定**从哪儿找由头**，不规定说什么，**也不给任何例句**（给例句就会变成台词——已被两次实测
证实）。同一轮永远同一角度（重放/重试不换由头），不同轮之间均匀落在三个角度上。

## 结论与限制（诚实记录）

- 原来的模板族（「……今天过得咋样？」）消失；反面例句泄漏、编造看不到的环境两处硬伤各修一处，
  并各留断言；"由头不必落在学习上、闲聊与学习都算"按用户口径写进提示。
- **句面约束是软的，来源轮换是硬的**。实测顺序：只删范本 → LCS 10；再引上一句 → 7；
  加"闲聊随性"举例 → 反而 11（新模板）；引最近三条 + 不举例 → 15；加确定性角度轮换 → **6**。
  要再严一档可以在生成后做相似度守卫（最近三条的长公共子串超阈值就不发这一句），
  但那会把开口压成沉默，与"开机招呼之后一直安静"那条诉求冲突，本轮不做。
- 判据脚本：`workers/ai-worker/scripts/companion-greeting-variety-probe.mjs`
  （连造 N 次启动问候，输出 LCS／结尾复用／套话命中，并硬判"反面例句泄漏"与"编造环境"两项）。
