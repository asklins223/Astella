# 伴星后台工具、共用面板与阅读交互（2026-10-23）

## 本轮范围与最新视觉决定

范围为 iOS 的速看、思维导图、拓展笔记、小伴星面板、选段改写、正文处理状态、头像和同句多批注，以及桌面正文的整组选区处理状态。保留既有记录、附件浮层、学习卡和分页阅读的实现；Android 本轮未改界面。

用户最后明确的是：**整片所选内容铺满镭射点阵，运动呈现球面般的三维起伏。** 当前实现是一张覆盖整组选区的连续曲面，光点随深度改变位置、间距、大小与亮度；点阵在正文前景，原文字形与排版保持稳定。没有独立球体轮廓、逐段播放、平直扫描或填充色带。此前几种被否定的视觉不作为本轮验收成果。

## 实际调用与状态归属

- `NoteGenerationMethods` 在 AppStore 中持有任务，不依赖工具页面生命周期。创建请求固定来源笔记、版本和请求 UUID；速看、脑图、拓展分别调用现有 `overview-tasks`、`mind-map-tasks`、`expansion-tasks`。前台按实际回执跟踪排队、运行、完成与失败。
- 三个工具共用 `NoteGenerationProgress`，提供等待时间、真实阶段、来源版本、后台继续说明及错误重试。没有模型进度接口时不推算百分比。提交回执不确定与已接收的后台工作分开呈现，同一请求重试不重复创建。
- 元数据按用户、书房、API 地址隔离并保存；恢复后继续查看既有任务。完成气泡在朗读、对话与工具面板空闲时投递，可进入对应任务及来源版本。自动朗读开启时进入现有 TTS 队列，气泡消失后仍可从任务入口查看。打开历史成果不重新宣告完成。
- 小伴星与主记录共用 `MessageHistory`，继承思考、工具过程、确认建议与成果展示；没有真实过程时不出现入口。`CompanionComposer` 共用语音录制转写、图片多选、文件和笔记引用，上传及提交沿用同一条真实链。打开面板定位最新，查看旧消息时不强制拖回底部。
- 笔记「改写」保留选文、块范围、偏移、原始块内容与版本，只附加到草稿并聚焦，等待用户输入想法。请求携带准确编辑上下文；确认写入后读回正文，停止、失败和完成均清理处理锁。

## 整组选区与点阵生命周期

桌面 `note-point-wave.ts` 是唯一绘制实现，原生构建前生成 `NotesWeb/note-point-wave.js`。桌面富文本、源码、阅读模式和 iOS WKWebView 均由整组范围容器承载一个 Canvas，段落节点只负责锁定。相交范围可组成一组，独立请求不因相邻而混成一次工作。

点阵使用稳定种子的错位网格，在连续深度场中变形；交叠的曲面起伏同时改变投影位置和光点强度。近处光点有紧凑微光，远处仍有覆盖，避免只剩几团亮斑。正文处理层在文字之上，工具栏仍可使用。长按不能选中忙碌原文，滚动保持可用。

仅为可见范围加少量缓冲绘制 Canvas，像素倍率上限 1.5，点数有预算，绘制节奏上限 30 次／秒；不会按整篇长文创建巨型位图，不逐帧触发 React 更新或正文排版。离屏、后台停止循环；减少动态、桌面 Off／Lite 模式保留静态状态。请求结束时销毁帧回调和观察器，移除覆盖并释放原文。上述预算是实现限制，不是实体设备帧率结论。

## 同一句多批注与身份图标

正文按批注区间切片，重叠处只绘制一层文字下半部浅蓝渐变，并携带该处所有批注 ID。点击只列出命中该句的批注，不把整段无关内容一起带入；列表可进入详情、返回列表、回到原文。跨段端点及中间整段分别按真实范围计算。长按选文不会被批注点击抢走。

伴星身份统一使用既有头像，包括批注讲解、消息身份、设置和底栏入口。真实舞台与浮动角色继续由 Live2D 渲染。底栏头像预渲染为原生尺寸，避免原图进入 UITabBar 后异常放大；功能图标、工具图标和评分星星保留本身语义。

## 继续验收与补修

继续验收时发现两处实际缺口并修正：

- 从成果入口进入脑图时，系统返回栏与自绘返回栏同时出现。脑图页面现在自行隐藏系统导航栏，保留原生侧滑返回桥接；过程页底部增加浮动伴星所需的滚动余量。
- 完成提醒原先只挂在右下角入口，首页和记录页没有带成果链接的同类气泡。现在三处共用 `CompanionGenerationNotice`，文案、收起和准确任务落点一致。收起、打开成果、提交新消息或开始录音时停止该条提醒的朗读，录音期间推迟投递。长标题在提醒中压缩为短句，任务记录及成果来源仍保留完整标题。

原 `Astella Image Intake QA` 设备在 20:57、21:18 等时刻再次被其他安装／启动操作切走，系统日志记录了安装协调器的强制终止。随后复用 `Study Speech 5c3656b8`（912953CC-9AD5-4BF3-A81C-A506D8CC6F36）完成固定场景的点按验证；没有把外部重启算作 App 崩溃。

## 尚未确认的边界

当前只连接模拟器，没有实体 iPhone；持续帧率、耗电、系统减少动态切换、麦克风权限及扬声器效果仍未在实体设备验证。减弱模式窗口证据使用 App 的 Debug 偏好，系统媒体查询与桌面 Off 的停止逻辑由单测覆盖。真实完成气泡和任务结果已分别看到，稳定场景下的气泡点按已补验；真实任务刚完成的 12 秒内点按全过程仍未留到连续证据。原生输入草稿引用与焦点已验收，最终真实改写使用与 App 相同的 HTTP 载荷验证，未声称原生键盘发送完成。图片与批注沿用此前实际验收，本批未改动其生产实现；新一轮连续操作再次被外部重启切成首页示例，未记为新增通过。桌面最终窗口回到缺少连接凭据的登录页，因此没有补拍最新点阵在桌面真实工作中的截图；桌面与原生绘制源一致，不能以此代替桌面视觉验收。
