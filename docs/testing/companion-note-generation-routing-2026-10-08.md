# 伴星速看与拓展生成路由修复 · 2026-10-08

## 原因与改动

用户在当前笔记上要求生成速看、拓展笔记，生成任务没有启动。开发库真实记录显示权限为 `full`，页面携带实际笔记与版本；速看轮次 `b3412db1-17ca-4270-9f1e-988f2575f460` 被解释为 `task/read`，拓展轮次 `4ff529a2-938d-4743-a80e-b65935e0fec7` 被解释为 `task/uncertain`。运行时据此只给读工具，`agent_start_goal` 被移出工具面。实际分别执行读取笔记与查看任务目录，没有任何生成回执，伴星却将其表达成能力没有接入。

分类器此前只获得内部工具名，无法直接读到 `agent_start_goal` 可以接速看、演示、拓展和制卡目标的能力说明。此次分类输入从唯一现役能力清单投影名字、说明和风险等级，仍只投影本轮权限允许的工具；补充项目产物与聊天文字的区别、当前笔记指代、后台入口和历史能力否认的处理。分类任务版本升至 8。聊天执行指导同步说明拓展先成为待选草稿。

没有放宽未知意图的写工具过滤，没有修改权限、生成器、模型配置或用户笔记正文。工作区已有的超时、联网搜索等修改保持原样。
