# iOS 伴星自然动态与点按归位（2026-10-23）

## 本轮用户决定

以桌面客户端的自然动态为参照：脸、头部细节持续有生命感，自动动作不要频繁切换。点击要有短暂、自然的回应，并且自行恢复。用户随后明确点击也要像桌面端切换表情，因此点按切换表情／动作保留，移除的只是固定朝向与整体弹跳。此决定覆盖 [上一轮记录](ios-companion-live2d-idle-2026-10-22.md) 中最后的“移除所有身体角度”、7–15 秒轮播和点击随机表情＋定向视线＋整模型缩放。

本轮只改 iOS，保留现有共享模型、下载缓存、真实音频口型与语义表情链路。改动前的相关文件副本位于 `/tmp/astella-ios-companion-motion-did30_du/`；工作区已有的阅读、后端、界面改动不回退。

## 实际根因与修复

- **桌面 SDK 的自然运动被移除了。** 桌面真实调用链还包括随包 `vendor/cubism4.min.js` 中 `Cubism4InternalModel.init → updateNaturalMovements → physics.evaluate`，不能只看上层 `WindowLive2DDriver`。它自带 AngleX／Y／Z 与 BodyAngleX 的呼吸输入，经 physics3 带动脸、头部、发丝和耳朵。Native 现在复用完全相同的五组 SDK 呼吸配置；上层再按桌面覆盖呼吸 `0.5±0.25` 和身体 `±2°`。不增加另一套自定义转头曲线。配置一致性由直接读取桌面 SDK 的回归测试核对。
- **最终帧被回存成下一帧基础姿势。** `ApplyBlendOverrides` 末尾的 `SaveParameters()` 连同表情、视线、物理输出一起保存；旧 LookUpdater 加算持续累积，回中目标变成 0 也清不掉已保存的角度。现在仅保存 motion 基线，呼吸、眨眼、语义表情、物理和点按反应都是当前帧临时层。桌面同款 SDK 自然输入在本帧物理求解前写入，上层最终参数在物理求解后落位，不靠回存最终帧传递输入。
- **Idle 阻断眨眼。** SDK 示例的眨眼 updater 在“任意 motion 正在更新”时跳过；鲸鱼 Idle 始终循环，又没有眼部曲线。改用桌面同款周期眨眼，并在语义表情之前应用，表情仍可控制闭眼笑等作者绘制的内容。
- **计时状态未初始化。** 原有 idle 时钟、表演停留计时与部分布尔／随机状态没有初值。`CompanionMotionState` 统一初始化相对时钟与反应状态，其余 native 状态全部显式初始化。
- **动作结束后没有中性基线。** 非 Idle 曲线每帧先还原默认值，再由当前 motion 覆盖。完整保留 `Selfie` 等作者动作，头、眼、嘴和道具在动作结束后均能归位；只有 Idle 循环。动作占用时长按实际资产长度加淡出窗口计算。

调用链：

`CompanionScene.onTapGesture → emitCompanion(.poke) → 当前活跃 CompanionStageView → CompanionLive2DHost → CubismBridge.poke → LAppModel.Poke → PlayNextPerformance(true) + CompanionMotionState → 桌面同款表情／动作轮播 + 当前帧短暂回应`。

点按与自动表演共用一个完整洗牌池，按桌面端切换表情／动作，一袋内不重复。用户直接点击可暂时覆盖语义表情；约 5 秒后恢复期间最新收到的语义表情，没有语义表情时回到待机。已有动作占用时，点按跳到可播放条目，避免卡在无法启动的动作上。短促且可中断的阻尼回应保留，不改变定向拖拽目标、不缩放整只角色、不叠加角度，真实音频口型保持。PNG 降级保留小幅按压反馈。

自动表演首次在约 24 秒后开始；每条表演结束后保留 20–40 秒安静待机。语义表情、音频口型和事件动作占用时顺延表演，保留完整洗牌池。切到后台／离屏后停帧并释放短暂反应；减少动态或应用内减弱动效时回到静帧，点按保留已有原生触感，不启动定向姿态或额外计时器。

- **最初版本点击／连点归位（用户补充点按换表情之前）**：通过 Device Hub 在真实 App 窗口执行单次与连续 6 次点击；最终 SDK 配置下再次执行连续点击。运行日志可见短暂的身体反馈（例如 `23:08:20 p_body=-3.19`），随后恢复同一时钟下的正常待机正弦，不再留下固定朝向。没有额外随机表情或全模型缩放。[点击前](assets/ios-companion-motion-2026-10-23/idle-before-tap.png)／[短暂回应](assets/ios-companion-motion-2026-10-23/tap-acknowledgement.png)／[恢复待机](assets/ios-companion-motion-2026-10-23/idle-after-taps.png)。
