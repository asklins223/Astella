# AI 操作前授权、消息时间与截图问题回归（2026-10-09）

## 用户决定

- 学习卡、伴星消息、原句解读、速看等 AI 操作，在创建任务之前读取账号同意与外发总开关。未授权时，由本地伴星指引打开设置，不创建任务或消息回合；服务端在接受事务内重复检查。
- 同一话题的连续补充需要一起理解。保留失败、取消或被后续消息接替的用户文字，提供真实发送时间、时区、间隔和回复状态，让模型结合话题判断。没有固定的时间切断阈值，也没有“只回答最后一句”的规则；取消的操作不能自行重新执行。

## 改动与证据

### 操作前授权

渲染层共用 `app/ai-action-gate.ts`，覆盖生成／重新生成学习卡、速看、思维图、扩展、原句解读、讲解、生成首道练习题，以及伴星任务的继续和修改。伴星发送的既有检查也接入同一套本地指引。设置页保留指引，直到相关权限开启；不依赖会被设置弹层遮住的浮动通知。

API 将账号门禁接入 Agent 接受、修改和恢复，以及伴星消息回合接受和学习卡重试／AI 候选操作。在新 run、任务或 outbox 写入前拒绝。取消、关闭、手动审核与保存不被 AI 门禁拦截。幂等读取已有请求仍可返回既有回执。

### 消息时间

历史读取不再排除 cancelled／superseded 回合中的用户文字。失败或不完整的 assistant 输出仍不作为完成的回复回放。系统提示的时间表关联原样消息的位置，包括本地日期时间、距离观察时刻和前一条消息的间隔、回复状态；摘要也保留时间和状态，并升级压缩策略版本。

使用已配置的真实模型做了两个合成抽测，结果保存在本地 `apps/desktop-client/outputs/five-reliability-fixes-20261009/dialogue-clock-probe.json`：

- 连续发送“12 伏”“4 欧姆”“解释电流单位”：模型合并三句，得到 3 安培并解释单位。
- 昨天失败的“哈哈哈”和今天的“小猪”：没有将昨晚那串笑称作刚发来的新问题。

这两例使用真实生产提示组装，但不经过数据库回合提交，且关闭思考以控制抽测时间；不是完整线上会话回归。

### 缩放图片

独立 image 阅读块与正文共用已有的 Markdown／安全 HTML 图片读取。保留宽高属性和认证图片通道；画廊也共用图片提取规则。已验证截图同类 `<img src="/api/uploads/...png" alt="" width="122" />` 可以解析。

### 学习卡失败原因

worker 记录稳定的输出格式错误与超时类别，API 将错误摘要限制在合同允许的 500 字符内。桌面主进程此前丢弃了失败原因；现在共享投影仅传递白名单原因及阶段，不传递原始 provider 错误、输出或提示词。渲染层区分未授权、核对未通过、生成／核对／修订返回格式无效与超时。

保留草稿和原有核对规则，不把没有通过核对的题面变成可保存候选。

### macOS 钥匙串

读取当前签名身份不会访问钥匙串。安装版在启动读取凭据前，检查已有加密凭据的签名身份与访问失败标记；对未知身份、拒绝访问、旧 ad-hoc 构建的凭据不再默默探测钥匙串。显式记住登录时仍使用系统加密，并记录当前身份；不落明文 token。
