# 手机图片输入验证记录（2026-10-12）

## 变更范围

- 对话输入支持从相机／相册选择一张 JPEG、PNG、GIF 或 WebP，选择时不上传；发送前要求有文字问题，限制 10 MiB。
- 图片通过登录态 multipart 请求上传到 `POST /uploads/companion-images`，把服务端资产块与文字放进同一伴星回合。
- 上传失败保留原图和草稿；上传成功但回合失败时缓存返回的图片块，重试不重复上传。
- 用户消息和历史消息显示图片。私有图片通过 Bearer 请求读取，拒绝外部 URL，提供失败重试；笔记图片也复用相同鉴权读取组件。

## 验证

- `cd apps/mobile-client && npm run typecheck`：web 与 node 类型检查通过。
- `cd apps/mobile-client && npm test -- --run`：7 个测试文件、34 项通过；覆盖 multipart 鉴权与 boundary 行为、服务端图片地址校验和私有图片消息渲染。
- `cd apps/mobile-client && npm run build`：Vite 生产构建通过。现有主 JS chunk 超过 500 kB 提示仍在。
- 浏览器窗口检查：390×844 下输入、附件卡和底部导航均可见；320×567 下横向溢出为 0，输入区与导航之间约 8 px。选择本机图片只用于本地预览，随后移除；没有通过界面向 API 上传测试文件。

## 尚未验证

- 原生宿主与真机系统选图器、相机权限、方向变化和系统键盘行为。
- 已登录真机向实际 API 上传图片，以及不同账号／空间的图片读取权限。
- 图片文件解析、语音输入／朗读、伴星 WebSocket 与 ASR/TTS 服务端链路。

因此，本记录证明浏览器端代码、合同与窄屏布局已验证，不等同于原生 App 或真实设备上传验收。
