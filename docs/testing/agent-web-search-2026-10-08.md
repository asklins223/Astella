# 联网搜索与伴星引用验证（2026-10-08）

本次接入统一能力 `agent_web_search`，对话与持续目标共用服务端执行器。智谱凭据从现有 `bigmodel` 平台读取，不进入 renderer/preload；请求使用 `search_std`，支持查询、域名及时间范围。开关保存在已有账号 `agent_settings` JSON 中，无需迁移；未设置即关闭。实际调用前复核账号开关、AI 同意与外发政策，搜索词经过既有脱敏，供应商异常不会原样送到用户或模型。

来源由真实搜索结果构造，按网址生成稳定身份；正文使用对应标记，客户端将其画成编号角标。来源保存在消息引用块和工具回执中，恢复不重复搜索；正文、复制文本与来源列表分别投影。网页图标不触发额外远程加载。每轮最多三次搜索，最多 24 条网页来源，优先保留引用块，避免富结果截断导致来源丢失。

用户追加修正：网页标题与摘要仅在折叠列表/来源弹层展示。已从 `companionMessageText` 排除搜索引用块，避免网页标题成为逐字正文和显现钟长度；模型协议也不再要求追加来源清单。引用标记在语音投影中屏蔽，硬切段跨标记仍不朗读其片段；未闭合标记不提交给流式显示和合成，移动预览不暴露半个标记。

## 验证结果

- shared、api、desktop-client、ai-worker 的对应 `npm run typecheck` 通过。
- shared 合同/工具面 9 项、worker 搜索/执行/语音相关 100 项、desktop 相关 155 项通过。额外执行器台账、工具文案台账和执行预算测试通过。
- 受限 API 数据库角色下验证：新账号默认关闭，首次写入生效，跨空间保持一致，另一账号不受影响，改权限保留搜索设置，关闭搜索保留权限，旧 revision 拒绝写入。
- 实际智谱 API 请求成功；完整桌面回合经过真实分类、两次搜索、最终消息保存，手记显示 15 条网页来源。窗口中验证正文角标、来源弹层、复制成功提示及 Safari 打开原 CSDN 网页；Escape 关闭来源后手记保留。
- 用户反馈后再次通过真实轻聊查询：三句正文、三个有效引用、16 条折叠来源。服务端生成的三个有声片段均有 `playback=ok / played` 回执，无 dropped；正文和读屏摘要均不再附加网页标题。测试账号的联网开关已恢复关闭。

## 仍需区分的边界

额度不足使用模拟 `1113` 响应验证，未人为耗尽真实账户余额。冷却为 worker 进程内、同凭据共享的 30 分钟状态，重启会重新允许一次探测；普通网络错误只停用当前轮，后续请求可再次尝试。持续目标已接目录、账号门禁和执行器，但本次未跑真实长目标全流程。播放回执证明三个音频片段完成，未做不同设备、所有声音的真人听感验收。

`search_std` 的排序与覆盖影响资料质量：第一次要求 Python 官方文档时返回第三方文章，回复如实说明未取得官方原文；本次补充域名筛选能力，不保证任何查询一定找到官方页面。来源只是证据入口，模型仍可能概括错误，需要用户核对原网页。
