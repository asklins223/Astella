# Agent 来源核验与短答优化

2026-11-04，接用户继续优化及切换免费搜索的授权，在 s-v2.0.22 上修改。MiMo 主模型、DeepSeek 回退的模型标识、平台地址和能力路由不变。本轮没有 iOS 代码变更。

## 实际问题和修改

- GLM 搜索实际返回 429 / 1113，线上与本地凭据一致。用户提供 Tavily Key 后，新增独立搜索配置：`WEB_SEARCH_PROVIDER=tavily` 与服务端 `TAVILY_API_KEY`。实际账户是 Researcher、每月 1,000 积分；默认 basic、关闭自动升档，每次搜索 1 积分，不调用额外的 Research / Extract API。密钥不进入仓库或客户端，额度不足不自动转去另一付费账号。参见 [搜索方案评估](search-provider-evaluation-2026-11-04.md)。
- Tavily 定位结果统一为现有来源合同，域名过滤、稳定引用身份、真实原文读取、权限、外发同意和取消边界保留。过程展示与引用所用字段不变，不把搜索摘要标为已读网页。Compose 同时向 API / worker 显式传入配置，避免只在本地生效。
- 核验、分类等调用已请求 `reasoningEffort: low`，但回退模型的旧能力档案只声明 `high / max`，实际会被提升为 `high`。补入 `low`，默认仍为 `high`，显式 `high / max` 保留；其余配置字段逐项比较一致。[DeepSeek 官方文档](https://api-docs.deepseek.com/guides/thinking_mode/) 列出这三个档位，原网关已完成真实调用。
- 每次来源核验的 `draft` 只放当前交付单元，全文另作跨段前提、单位和矛盾检查的背景。全部实际读到的材料和回执保留，不能仅按草稿引用过滤证据。
- 短答逐段改写曾出现两段各自重写成完整回答。正文不超过 800 个 Unicode 字符（不计引用角标）的短答合并核验，总句数、篇幅与重复一并检查；只合并完整文字，不截断草稿或原文。长答保留最多四项在途的段落并发，完整判定后按顺序交付。
- 模型曾只计算中文、漏算外语引文。宿主提供当前单元和全文的实际正文字符数，包含外语、标点和换行，只去掉界面角标。作者与核验都明确查阅原文不等于逐字摘录，短答不为展示查证抄长引文或另写来源清单。
- 来源核验用原模型的流式接口收取完整 JSON，记录首个活动时间、正文与推理字符数、每单元耗时，不记录推理内容。碎片不发布；完整解析、来源当前性和租约检查通过后才交付。截断、损坏 JSON 和迟到结果不能放行未核验正文；后续失败保留已交付前缀和 partial 状态。

## 否决的方案和测量边界

整篇长答合并核验的候选曾等待 90 秒仍无完整判定，已撤回。短答只合并两个段落的候选仍交付大量外语引文，未守住整体篇幅，也未采用。最终只合并有界短答；长答不变成整篇串行核验。

短答需等待一次完整判定，首段不保证早于逐段核验，这是跨句一致性和总篇幅的取舍。真实外部服务还有下载失败、主线路超时、回退和推理长尾。本次不声称复杂查询稳定秒回，也未同题实测竞品。

早期 watcher 重启造成的恢复间隔不作为模型速度证据；另一次高负载、数据库客户端超时的波次单列。有效测量使用独立数据库、无 watcher 的 API / worker，并检查 PID 与重启次数。清理临时目录后，候选迁入持久工作区；七个源码和测试文件与清理前编译结果一致，配置指纹也一致，随后重跑全部相关检查。原始测试数据已由独立数据库恢复。

## 验证

- worker、shared、API 类型检查通过；全量 2,003 项 worker 单元测试通过。原来源核验真实数据库 68 项通过；搜索迁移还将随最终发布再次回归。
- 数据库覆盖 body / finish / publish、核验不可用、截断、损坏 JSON、长答流式和后续中断。后段判定主动等待前段进入持久 SSE，最终存储与已交付正文一致，未核验草稿不泄露；来源、权限与租约边界保留。
- 六项真实模型、HTTP、worker 和实际材料读取检查通过：实验范围、秒与分钟比较、最终记录替代初版、相关与因果、Mb/s 与 MB/s 换算、无回执不能宣称保存。逐项核对实际回答，六轮完整结束，来源实际读取，写工具数为零。材料为合成测试资料。
