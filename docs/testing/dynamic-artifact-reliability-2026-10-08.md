# 动态讲解失败与重复生成修复 · 2026-10-08

用户反馈：动态讲解生成经常失败，等待时间长。本次沿笔记选区 → Agent 领域任务 → Worker → 模型 → 页面核对 → 保存 → 窗口打开检查。

## 已确认的原因

- 本地最近一条生成任务 `4ebdd254-aa18-4a66-be08-4fa0b3add9c4` 的模型调用在 124832 ms 后成功，34107 token；随后页面核对以 `external_reference` 拒绝。旧日志没有具体规则，也没有保存被拒页面，因此不能断言该历史页面的确切代码。
- 用同一电功率题目的合成单块素材，在原提示 v16 / DeepSeek V4.1 Flash / high 下复现：134612 ms 返回完整 JSON、14997 字符 HTML，结构与引用通过，页面核对拒绝 `var NS = 'http://www.w3.org/2000/svg'`。它只用于 `createElementNS`，不是资源地址。此前只豁免 xmlns 和直接写在 DOM API 第一参数里的命名空间字符串，漏了变量。
- 原始提示只有一个原文块时只提供一条 outline 示例，但合同要求至少两条；原文带 Markdown 时，生成素材和引用核对又使用不同文字形态。
- 元数据结构解析失败的自动重试没有提供具体修复方向，还会重新请求整页 HTML；可解析但引文、块号或重复标题错误则直接判完成未达成。
- 窗口重试期间，其他正在修改的源码触发 tsx watch 三次重启；日志出现 `Process didn't exit in 5s. Force killing...`。每次都中断付费生成，之后等待两分钟失联租约回收。此现象属于开发热重载，和模型超时、页面校验分别记录。

## 改动

- 页面检查允许标准命名空间通过 const/let/var 绑定提供给 `createElementNS` / `setAttributeNS` 第一参数。只有所有变量引用都在该位置时才豁免；用于 src/href、网络调用、其他用途或赋值仍拒绝。CSP、sandbox 和资源隔离未扩大。
- v17 提示的单块示例含两条不同标题，明确允许同一句支撑多个不同要点；生成材料与引用检查共用纯文本。要求模拟读数如实命名，避免把教学模拟写成真实测量。没有关闭 high 推理或缩减已放宽的输出/时间预算。
- Worker 和 API 共用响应修复会话。安全 HTML 保留在当前调用的内存中，第二次仅请求 title/subject/caution/outline。修复字段必须严格解析、引用核对，最后仍执行原完成与页面检查。两个调用上限、租约、取消、父目标计费和版本围栏继续有效。未解析 JSON 或不安全页面不会被当作安全候选保存。
- API 为每个冻结输入与发起人作用域保留对应 provider，避免每次模型步都重建会话；provider 内也隔离不同输入。候选没有新增跨任务持久化，Worker 崩溃后仍需重新生成。
- 页面拒绝日志新增固定规则名，保持不记录笔记文字、页面代码或证据片段。

## 证据

脚本：`workers/ai-worker/src/live-tests/dynamic-artifact-reliability-probe.ts`。合成输出及收据位于 `outputs/audits/2026-10-08-artifact-reliability/`，不保存隐式推理或凭据。

- 原始同题生成：134.6 秒，39087 输出 token，其中 32354 推理 token。修复页面检查后，同一份 HTML 直接通过，无需再付一次生成请求。
- 元数据修复：人为给已生成的合成候选注入超长标题与错误块号，再经生产共享修复会话和公共内核请求同模型 / high。一次实际请求 6.9 秒、1605 输出 token（1097 推理 token），修正后通过结构、引用、完成与页面核对，HTML 字节完全保留。内核第一步为回放候选，第二步才是真实模型请求，因此不能把它计作两次真实请求。
- 单次样本支持“短字段修复能避免重新生成整页”；不代表所有生成耗时都会下降到 6.9 秒。正常整页请求仍需约两分钟，且本次不足以测量总体失败率。
