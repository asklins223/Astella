# 全流程测试：问题与解决方案（2026-10-05）

本轮使用两个新账号、个人与协作空间、独立 Electron 安装包及测试用户目录。主要学习流程、页面和已列出的控件已实际操作，长正文、结果详情、来源片段、版本历史和演示说明均逐段滚动检查。以下是修复后的结论；未确认项目单独列出，不能据此宣称所有功能全部通过。

2026-10-06 快速复测更新：原来 8 组未闭合项里，争议补充与最后窗口检查已通过，两条过度推断的旧测试记忆已移入回收区。这一轮在真实窗口里又修掉四处：① **修改密码永远失败**——`changePassword` 在事务外裸查 `users`，受限角色下 RLS 恒返 0 行，任何旧密码都被判错（已改成同一个 actor 事务，改密真跑通、旧密码失效、新密码可登录）；② **演示关闭动效不生效**——宿主用具名 origin 给不透明 origin 的 frame 发指令，浏览器静默丢消息，且档位运行中不补发（已修，安装包内切档即时生效）；③ **本地语音识别引擎在应用里起不来**——随包引擎是 emscripten 的 Node 构建，沙箱渲染进程的 worker 里没有 `require`（已把解码搬到主进程 `utilityProcess`，合成语音 2.1–2.9 s 出字，连续第二/三句不重载模型）；④ **语音气泡两个交互缺陷**——麦克风按钮会把整个气泡收走（所以点不到「结束录音」），且认出一句之后再点麦克风永远开不了新录（`if (!voiceDraft) voice.toggle()`），这两处都由用户在真机上撞到并已修。现剩 1 项需处理/复核（旧答案泄露测试卡：详情没有删除/归档入口），以及 2 组受版本或观察时长限制的未验证项目；没有重新跑已通过的全量页面。
