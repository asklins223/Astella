# 主动发言与引用发布复查（2026-11-02）

iOS 真实接口验收发现：普通回答后的一次主动补话将内部「没有需要补充的内容」连同 XML 包装发布成消息。原有主动发言核对只在有相似旧话或未完成请求时运行，新的内部收尾说明绕过了它。现在每条可选主动发言都在消息、正文增量和语音交付之前核对实际交流内容；没有新内容就正常静默完成。判据采用语义核对，保留正常问候、贴题新看法和对 XML 本身的讨论。普通用户提问不增加这次检查。

线上 s-v2.0.17 的实际搜索还发现：结论正确却挂上不相关 NASA 网页的编号。搜索可用不等于引用正确。此前只有实际读取资料后才启用来源核对，纯搜索摘要形成的终答可能绕过它。现在搜索之后的候选正文暂缓发布，每个原位标记必须有本轮对应网页的成功读取回执；缺失时在原任务内补读，保留已完成工具，不重复搜索或写入。来源逐一绑定实际读取网址，语义核对检查每个标记紧邻的结论，不能借用同批其他网页的证据。普通终答、原生 finish 与独立消息发布均覆盖；不使用关键词黑名单，不更换原 MiMo 与 DeepSeek 模型搭配。

验证：1974 个 worker 单元测试、46 个 PostgreSQL 集成测试（主动参与 36、模型预算与发布边界 10）和类型检查通过。主动发言的两个发布通道均验证无新内容时没有消息、正文增量或语音事件，只留下成功静默终态；真实主模型五个候选检查全部通过。新增引用回归验证搜索后尚未读取的来源在正文、finish 通道均先被扣留并得到补读指引，同步保持预算和工具回执。

真实本地 HTTP/worker 搜索用时 58.731 秒，最终引用 Telling Time on Other Worlds。它与本轮 web.read_document 的实际请求、返回网址及 6000 字符原文窗口绑定，正文引用只有该来源，无未知编号。时间包含搜索、补读及核对，不宣称深搜索即时完成。结构化结果见[验收记录](evidence/agent-conversation-fixes-2026-11-01/initiative-publication-followup-2026-11-02.json)。此记录是发布前结果，线上复测和交付另行记录。
