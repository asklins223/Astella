# 60 · 桌面客户端完成度：问题与改法

日期：2026-11-07；时区：Asia/Shanghai。

**状态：方案，未实施。** 2026-11-07 用户确认伴星贯穿桌面每一页，座位属于这一页的页边，纸在座位前停住。同一次窗口走查里的问题与改法都写在本文：座位、搜索句子、回到当前笔记、页面骨架、长文阅读、疏密，以及较小的读法和图标问题。首页房间保持。工作页以纸面为这一页，房间退到纸的边缘。

## 1. 已确认的座位

伴星是这个软件的主体，每一页都有她。挡住按钮的原因是座位按窗口角算，人盖在控件上。改法是让这一页的纸为她留出页边，人留在座位上。

| 页面 | 她怎么在 |
| --- | --- |
| 首页 | 维持现在：人站在房间里，全身，可以拖。 |
| 读和写，含全屏 | 坐在纸的一侧页边。正文行宽不动。点她，对话从身边展开，贴着正在看的段落。全屏已有的右下座位、左侧批注与工具继续有效（`DESIGN.md` 2026-10-08）。 |
| 来源库、笔记库、搜索、设置、星图、伴星中心 | 上半身，座位固定。这一页的最后一排控件在座位前结束，纸为她收一寸。 |
| 没有进行中的事 | 头顶不挂「交给我的事」。有事才写出件数和状态。说完话，纸签收回，人留下。 |
| 体型 | 整身只留在首页，以及明确空出全身位置的页。工作页用上半身。鲸鱼现在每一页都整身入画，登记里的上半身被盖掉，工作页改回上半身。 |

登记表已经写了左右座位（`HUD_PAGES` 的 `seat`）。真正把她钉在窗口角的是 `companionSeatTarget`：贴窗口底边和侧边，离边缘大约十几像素，不看纸上有没有按钮。`CompanionPresence` 里鲸鱼强制 `framing: "full"`。任务签在 0 件时仍是一枚勾（`CompanionGoalBubble`）。

## 3. 问题与改法

### 3.1 她盖住正在用的控件

人格页上，她和「交给我的事」压着「她怎样表达」。伴星设置里，主动介入的「中静 / 适中 / 活跃」被卡片底和任务签挡住，当前档读不到。搜索里她盖住预览。笔记库里她坐在一张样例卡上。设置表单比卡片短，出现「往下看看」，主动介入被切断。

改法按 §1。纸的可点区域在座位外结束。设置是一页，表单自己滚动，当前选项完整可读。任务签只在有进行中的事时出现，写件数和状态。

### 3.2 搜索和预览印出存储格式

搜「滚动」时，纸条和预览画出 `<span style="color:#b83c44;background-color:#fff0ad">`，以及 `{astella-note:592ac32a-…}`。`displayBlockContent`（`search-presenter.tsx`）只剥掉 `h1–h6`、`p`、`strong`、`em`、列表、引用和代码，`span` 和笔记链接留在字符串里，预览再把这串字符串当正文印出来。同一套高亮写进了笔记正文里的「版式样例 5」。

改法：预览和纸条只出现人读得懂的句子。样式标签剥掉，留下字和本来的高亮；笔记链接显示笔记标题，内部 id 不出现在纸上。正文里作为样例保存的标记，在阅读和搜索里同样先变成句子再给人看。

### 3.3 她在每一页，带不回正在读的那一篇

她能去首页、来源、笔记库、搜索、星图、对话、设置。`HUD_PAGE_DESTINATIONS` 里阅读、编辑、学习卡、学习页、学习记录是空的：`companion_open_page` 只收无参落点，而这几屏都要笔记 id。空间切换走顶栏胶囊，仍不归她。

改法：她能回到用户当前打开的那一篇，连同当前的正文、速看、回想、往外学、学习卡或学习记录。落点带上这篇笔记的 id，沿现有打开动作走，不另造一套无参页面名来假装能跳进某一篇。空间切换保持顶栏胶囊。

### 3.4 同一件事三扇门，模式和目录要靠猜

伴星中心、设置里的伴星设置、半身像上的齿轮，都通向同一个人。笔记六个模式的副标题约 10px（读懂重点、想起一点、发现关联、配套练习）。左侧七个目录图标，文字只在悬停时出现。⌘K 的提示写在空搜索框上。

改法：人格、日记、对话和记忆留在伴星中心。在场和主动介入留在设置的伴星设置。半身像上的齿轮打开同一份伴星设置。当前页的名字在目录上一直可读。当前笔记模式用能读清的一行说明自己干什么。搜索的快捷键在目录的搜索入口上能看见，结果仍是 §3.2 的句子。

### 3.5 空页说两遍，书架第一屏装不下

来源库同时说「没有待处理的材料」和「来源库还是空的」，五个筛选都是 0，「采集新来源」容易错过。笔记库 14 篇，第一屏一张主卡加四张小卡，「全部笔记 · 14」埋在主卡里，「暂无学习记录」每张都重复。日记是空白的管理日。动态里那句「上午那几个单字发得跟密码似的」底下是「查看 / 忽略」。

改法：来源库空的时候一句说明，采集是这页的主动作。笔记库按书架滚动，篇数写在架上，单篇没有学习记录时不在每张卡上重复这句话。空日记是桌上的一页空白，写下一句可以记的入口。动态保留她的话；「查看 / 忽略」只出现在需要人处理的那一条上。

### 3.6 星图和同意书把内部信息拿给人读

星图标签被截成「1:1 版式对照（Tr…」。「拖动漫游 · 滚轮缩放 · 点一颗星展开」在水面上很淡。筛选、27%、适配、复位、图层与图例压在夜空上。AI 同意先是一段密的法律文字，然后 `ai-consent-v1` 出现两次。

改法：星的名字能读全。漫游提示在夜空上可读。筛选和缩放留在页边，夜空仍是这页的主体。同意书用人读的签署日期和后果；版本号留在需要核对的回执里，不作为标题写两遍。

### 3.7 一个产品，四套页面骨架

首页是一间房间。来源库和全局搜索是同一块固定的薄荷面板，换一张空插画。理解星图是铺满的夜，底下一条筛选和缩放条。设置中心和伴星中心是左栏书，只有设置把标题放进卡片里。「来源库」「笔记库」的牌子和目录撞在一起。离开房间之后，这块舞台可以换成「文件 / 搜索 / 设置」，骨架不用动。

改法：工作页的纸面就是这一页，房间退到纸的边缘。来源、笔记、搜索、设置、伴星中心用同一种纸：标题在纸上，离开目录，不和目录抢同一块。星图的夜空仍是这页的主体，筛选、比例、适配、复位、图层与图例收到页边。首页的房间不动。

### 3.8 笔记停不成可以留下的一页

《这篇笔记》仍留着房间壁纸，壁纸在纸的边缘还在动；上面还有第二套工具条，以及六个模式和约 10px 的副标题。文章是浮在图画里的一张卡。正文栏本身的行宽是舒服的。速看、回想、往外学在这个字号下解释不了自己。

改法：长文阅读时，纸铺开，栏宽和安静留给段落。壁纸停在纸外，不在正文边缘继续动。六个模式收成当前这一档，旁边一行能读清的说明（读懂重点、想起一点、发现关联、配套练习）。速看、回想、往外学仍在，从当前模式进去，不在正文上方同时摆开。阅读、编辑、源码继续只切换同一份正文。

### 3.9 疏密反了

来源库、空搜索、空日记是一大块空白卡片。设置的表单比卡片短，于是出现「往下看看」。笔记库 14 篇只给一张主卡加四张小卡。星图快要安静下来，然后「再练练 0 / 没练过 0 / 练过 6」和 27% 把它变成仪表盘。

改法：纸按内容长。空搜索就是输入和按键说明，不铺一块空舞台。空来源、空日记用一句说明加下一步，卡片不高过这句话。设置是一页，表单自己滚，不靠比表单更矮的卡。书架自己滚，14 篇都能顺着看到。星图的练习计数和缩放留在页边，夜空保持这页的主体。

## 5. 验收

实施时在真实 Electron 窗口核对，而不是只看组件测试。

- 首页：全身，站在房间里，拖动仍记住摆位。
- 人格、伴星设置、搜索结果、笔记库：座位外的控件能点到，当前档能读到。没有任务时，头顶没有「交给我的事」。
- 搜「滚动」：预览是句子，没有样式标签和 `{astella-note:…}`。
- 从一篇打开的笔记里，她能回到这篇的正文和学习页。
- 半身像齿轮打开的是设置里的伴星设置。目录上当前页的名字一直可见。
- 来源库空态只有一句说明，采集找得到。笔记库 14 篇能顺着书架看完。
- 星图节点名读得全。夜空仍是主体，筛选和 27% 在页边。同意书标题里不出现 `ai-consent-v1`。
- 来源、笔记、搜索、设置、伴星中心是同一种纸，标题离开目录。打开一篇笔记时，段落是这一页，壁纸停在纸外，六个模式收成当前这一档。
- 空搜索、空来源、空日记的纸不高过那一句说明。设置表单能滚完，当前档看得见。
- 鲸鱼和工作页公皮都用上半身；首页仍是全身。
- 目录、设置、伴星中心是同一套图标。空间名字在顶栏出现一次。学习卡的星能看清点亮了几颗。
- 切页、Esc、返回书房、减少动态和 Off 仍按现有动效合同。回弹停在终点。焦点不等待座位移动。
