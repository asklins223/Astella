# 39：新笔记直接学习的真实模型闭环

日期：2026-09-27。范围：W4-3、W4-6 的首轮学习路径，以及必要的保存、权限、预算修复。此记录不表示 39 整体完成或集成试用门槛通过。

## 已落地的行为

新建、手写或来源起稿的已保存笔记，无需先制卡或填写目标表单即可开始一轮。空问题由服务端根据保存的标题与小节建议；最初阅读路线、改写问题后的路线、按当前版本重开后的路线都在同一事务内持久化。桌面显示最新路线，沿用现有动森 HUD 的册页、纸签与伴星座位。

生产讲解改用真实模型，完整读取本轮冻结的 `note_versions.content_json`，不读取后续未定版正文。确定性摘抄 provider 只保留为显式离线测试注入。模型配置可用 `NOTE_TEACHING_URL/KEY/MODEL`，未配置时复用已有 `ASSESSMENT_CRITIC_URL/KEY/MODEL` 与 `DASHSCOPE_API_KEY`；没有配置会明确失败，不伪造成功。

独立核查覆盖讲解的每个句段与例子，并另查可选练习目标的范围、事实、判据和逐字引文。漏查句段或出现无依据断言时，不展示讲解、不生成演示或练习目标；目标被拒绝但讲解通过时，讲解仍可阅读。没有本轮合格目标时，不借用旧目标伪装成本轮练习。核查由模型完成，仍须进行人工教学样本审核，不能据一次通过宣称零错误。

通过核查的目标接入现有目标快照、依据副本、评分判据与 LearningRun，数据库不创建学习卡或复习日程。讲解已经暴露答案，因此即时练习记为 `practice_only`；提交、结算与本轮历史复用既有链路。

## 本批一起修复的问题

- 自动同步清掉本机 dirty 后，手动保存曾直接返回假成功，未生成保存版本。显式保存现在总是请求服务端 checkpoint，由服务端判断重复；开始一轮先保存，失败则保留草稿并停止开轮。用户可明确选择上次保存的内容。
- 模型调用改为先预约预算、事务外执行、短事务提交；失败、重试、并发与进程中断都计入持久预算，过期尝试不能提交结果。
- AI 同意原先在用户 RLS 上下文之外读取，受限 API 角色读不到已签同意。现在按工作区和用户读取，未同意仍禁止外发；生成前后及教学读侧核对当前笔记可见性。
- 静态演示实际有四步，宿主曾显示“共 0 步”。播放器现在统计已生成的分镜；减少动效不会把整份分镜重复复制。删除已无调用方的旧讲解计数预算检查与前端 `no_change` 假保存回执。
