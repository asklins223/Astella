## Files and integration

Notes UI paths in the table are relative to `apps/mobile-client/ios/Astella/Screens/Notes/`. Store paths are relative to `apps/mobile-client/ios/Astella/App/Store/`. Reader assets are in `apps/mobile-client/ios/Astella/NotesWeb/`.

The parent registers sources with Xcode and added the lightweight `NoteGeometry` / `NoteGeometryTests` Swift package targets. Shared rendering changes are in `packages/shared/src/learning/note-learning-card-operation.ts`.

Only the approved `NoteBlock` optional rendered-field decode was changed in `App/Models.swift`; the parent updated CacheManager to persist those optional fields. Shared scaled typography and `.mindMap` / `.operation` / `.form` skeleton support come from the parent. No unrelated shell, auth, account, companion or journey source was overwritten.

The companion route contract is `CompanionNoteRouteDTO` plus `companionSession.pendingArtifactRoute`. `NoteReader.swift` consumes a route after the target note loads and the companion panel closes. It preserves note/version/task/artifact identity. Overview and map validate their task receipt against the exact artifact id; dynamic artifacts use `NoteDynamicArtifactScreen` with the same complete identity check. A mismatch produces a visible retry/failure surface, never a substituted newer artifact. Reference-only companion drafts call `persistCompanionDraft()` at the note/diary/rewrite attachment points.
