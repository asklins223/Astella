## Notification delivery guarantee and required remote-push work

This implementation delivers a local reminder only if the iOS process receives the companion event while it still has execution time in the background. A suspended or terminated app is not promised a reminder. Settings and contextual opt-in expose that limit and point the user back to task records.

Guaranteed remote completion needs a separate configured APNs path: signing/entitlement for the app/environment, APNs key or certificate with deployment secrets, per-device token registration tied to the authenticated account/server/space, token rotation and logout revocation, a durable server completion outbox with event/run deduplication and retry, privacy-controlled notification bodies, and the existing scope-aware tap route. No credentials, registration service or server push sender are represented as present in this change.
