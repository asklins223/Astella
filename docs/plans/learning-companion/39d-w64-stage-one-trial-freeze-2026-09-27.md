## 2. 样本冻结（A 类）

### 2.1 人

- **人数**：8–12 位目标学习者（§18.2）。**这不是效果样本**——§18.2 原话「这个人数用于发现可用性和教学故障，
  不能据此宣称统计意义上的效果提升」。
- **本人真实笔记**：每人用自己真想学的材料，不用测试夹具（§18.2）。**夹具笔记上的成功不算数**。
- **先验记录**：初学者 / 有基础者，逐人记录（§18.2 要求「记录材料和先验差异」）。
  **不匹配样本不得直接算作产品胜负**（§18.2）。
- **覆盖要求**（§18.2）：初学者与有基础者、短长材料、过程类与静态概念类、有来源与无来源。
  每一格都要有人；**填不满的格在报告里明写"未覆盖"，不许拿相邻格代替**。

### 2.2 材料

- **内部演练材料**：`note-01` … `note-09`（`packages/ai-quality/src/dataset.ts`）。
  其中 **`note-03-database-index-optimization` 是 §16.26 的旗舰案例**，
  逐日剧本见 [39a 演练](./39a-database-index-learning-journey-walkthrough-2026-09-24.md)。
- **对照材料**：§18.2 要求「不同但难度接近材料交叉安排并平衡顺序，
  避免同一材料先学一遍后天然有利于后测」。**排期表在开始前定死并留档**。
- **材料里已知的一处实质疑点**：note-03 复合索引段的绝对表述（39a §1 已人工核对过）。
  **这处疑点必须保留在被测材料里**——它是 §16.26 唯一的真实现场。
  把它预先修掉，等于把这一条验收提前判死。

### 2.3 时间点

当天、约 2–3 天后、约 7 天后（§18.2）。**首次试用必须包含隔天或数天后的回访**（§17 阶段一）——
只演示当天生成与播放不算。

## 3. 评分冻结（A 类）

- **任务来源**：使用**独立编写**的新情境或回忆任务（§18.2）。
  **不许复用学习过程中见过的题面**——换数字、换措辞、换目标 ID 都不算新任务（§14.1.1）。
- **评分者**：尽可能由**不知道学习条件**的审核者按预先确定标准评分（§18.2）。
  不知道谁看过哪份材料的那一位，才不会把"帮他回忆起来"读成"他学会了"。
- **生成器与评估器的角色隔离继续保留**（§14.2）；**模型评价不能作为自己的唯一验收证据**。
- **两件事分别验收**：教学生成对不对、评分判得对不对（§14.2）。
  「一道题答对」不同时证明题目设计正确和评分正确。

## 4. 操作成功要求（A 类，起点值）

§18.4 给的起点值，**本轮照用，不下调**：

| # | 要求 | 起点值 | 分母口径（见 §4.1） |
| --- | --- | --- | --- |
| 4.1 | 关键操作**无主持人代操作**完成 | ≥ 90% | 每人每项关键操作 → 逐人 → 再汇总 |
| 4.2 | 下一步含义**能正确复述** | ≥ 90% | 同上 |
| 4.3 | 已审核教学样本**无未解决的严重主张错误** | 0 | 已审核样本条数 |

「无代操作」是硬条件：主持人替用户点一下，就算该项未完成。
**不许记成"完成，但有协助"**——那是两件事。

### 4.1 分母口径（本轮最容易被做虚的一格）

**8–12 人的样本上，"90%" 没有小数点后面那一位的意义。** 8 人里成 7 人是 87.5%，
离 90% 差 2.5 个百分点，但**那是 1 个真人的失败**，不是"略微未达标"。

所以：

- **只报 `X/Y 人` 与 `X/Y 次`，不报百分比**（§18.4 明写「小样本报告人数与分母，不仅报告百分比」）。
- 判定按**人**：`8 人样本下 ≥90%` 实际等于「**最多 0 人失败**」；`12 人样本下` 等于「最多 1 人失败」。
  **哪一档在开始前定死，中途不得换分母。**
- 百分比可以并列写，但**必须紧跟分母**，且**不作为判定依据**。
- **失败与未做的分母分开**：用户没走到那一步 ⇒ 记"未覆盖"，不记"失败"，也不并入分母。
  把未做算成失败会低估产品，把未做剔除会高估——**两者都要说，不许只说一个**。

## 6. 指标与反指标（A 类口径，量法在 §6.1）

照搬 §18.3，**不新增成功指标**，只补"怎么量"：

| 维度 | 重点观察 | **不是**成功替代品 |
| --- | --- | --- |
| 学习价值 | 相近投入下的新情境应用、延迟回忆、能指出具体改进 | 看完动画、点下一步、主观觉得讲得好 |
| 适应性 | 是否找对缺口；略过重复教学后表现是否保持；用户纠正诊断的频率 | 生成更多不同题型 |
| 首次体验 | 从笔记到第一个有意义动作的等待与步骤；是否知道为什么学 | 首屏曝光、开卡数量 |
| 结束与回访 | 借助/失败后能否正常结束；能否找到恢复点；自愿再次回来 | 让用户多停留一会儿 |
| 复习负担 | 相同目标重复提问；每批是否超预期；积压是否造成放弃 | 每天清空更多待办 |
| 笔记价值 | 是否保留解释；之后是否回看、使用或修正 | 自动写入的字数 |
| 星图价值 | 定位缺口或关系的成功率、耗时、下一步是否合理 | 连线数量、画布停留时间 |
| 质量与成本 | 事实与关系错误、误评分、**可疑主张的漏检**、生成重试、等待分位数、每次有效学习成本 | 单次模型请求便宜 |

### 6.1 三件必须分开统计的（§18.3 末段）

**动画成功、内容可教学、评分可判断**分别统计。**三者合成一个"成功率"就是 §18.3 说的反指标。**

**可疑主张的漏检**单列：§18.3 把它写进"质量与成本"行，§21 表格也强调
「自动发现疑点仍可能漏检，因此需要把此类真实笔记放进教学与制卡质量样本，
**不能把规则存在等同于准确识别**」。§4.3 的"零严重错误"只管**已审核**的样本，
**漏检的那部分材料根本不会被审核到**——所以漏检要靠**独立人工过一遍全部真实笔记**来数，
不能从审核通过率反推。

| --- | --- | --- |

| 8.2 | 执行不受信任代码（动态讲解的隔离面） | §18.4 |
| 8.3 | 伪造出处 | §18.4 |

**§18.4 紧接着的那句必须一起读**：「此规则不等于声称一次测试能证明绝无风险」。

另有 §18.4 末段的三条回退判据（不停止，但缩范围）：
动画提高喜欢程度却不改善理解且明显增加等待 → 缩小动画使用范围；
诊断频繁误导用户 → 退回可选择的解释路线；
星图不能帮助定位 → 保留笔记总览并延后复杂关系；
提示后复习仍产生无法结束的待办 → **先修复安排政策再扩入口**。
