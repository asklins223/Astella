## 1. 用户决定与适用范围

本方案合并本次连续对话中确认的三件事：

1. iOS 在大伴星模型态、记录页、右下角伴星按钮态、展开后的随行面板态接入联想交互。
2. 联想交互与新用户引导一起设计，通过一篇预先生成、相互对应的示例，体验伴星命名、对用户的称呼、写笔记、改笔记、速看、思维导图、拓展笔记与学习卡答题。
3. 加入方言试听和方言对话体验；整个过程支持快进、章节跳转和跳过，不要求看完旁白、做完动作或交完学习卡才能离开。

实施范围为 iOS。共享合同和已有服务按必要范围承接；不据此重做 Android 界面或桌面引导。

本文承接 [51](./51-mobile-companion-full-agent-product-design-2026-10-10.md)、[55](./55-mobile-redesign-and-companion-realtime-2026-10-12.md) 的原生移动链路，沿用 [56](./56-companion-initiative-and-natural-exchange-2026-10-13.md) 的默认主动相伴能力与 [57](./57-learning-card-and-review-reset-2026-10-19.md) 的版本化学习卡规则。iOS 的首次引导以本文替代 [43](./43-companion-guidance-and-space-arrival-2026-10-04.md) 的桌面影片构图、岛内入口和固定带看站点；桌面实现及新空间权限规则仍按各自现行依据执行。

手机端最新视觉决定见 [DESIGN_SPEC](../../../apps/mobile-client/DESIGN_SPEC.md)：苹方、清亮钴蓝、柔软轮廓、角色场景，液态玻璃用于交互控件。阅读正文保持稳定。

### 1.1 体验目标

让用户在第一次相伴中形成三个认识：她是谁、内容怎样变成自己的笔记、围绕一篇笔记可以怎样学习。引导结束后，同样的接话和功能入口继续服务日常使用。

完整演练以约五分钟为设计目标，实际用时需通过首次使用走查验证；交付前不把估算时长作为已经测得的承诺。用户可以只听一句方言、只试一种学习方式，也可以直接开始自己的内容。

### 1.2 本次不增加的产品任务

不恢复全局卡库、今日学习、到期队列、打卡和催促。引导结束不生成提醒或伴星计划。参与偏好用于细化默认相伴方式，填写偏好不是启用主动交流的前置条件。

## 3. 联想交互：同一建议，跟随眼前的内容

### 3.1 三种语义

界面使用“接着问”“这篇可以这样看”“试试下一步”等具体措辞。

| 类型 | 来源与例子 | 点按结果 |
| --- | --- | --- |
| 接话追问 | 已完成回复的 `followUpPrompts`；“举个生活中的例子” | 发送这句完整问题，沿用正常发送和重试链；长按提供编辑后发送 |
| 页面功能 | 客户端依据当前可访问对象与真实功能状态给出；“打开速览”“看看脑图” | 打开对应功能或已有成果；按钮文案准确区分打开、生成与继续任务 |
| 引导下一步 | 已登记的示例步骤；“试试改写这一段” | 进入示例步骤或执行用户明确选择的示例动作，不触发真实模型或生产笔记写入 |

三类按钮共用柔软的轮廓与按压语言，以文案和动作图标表达结果。保存默认方言等真实设置使用明确的设置动作，不藏进普通追问。

追问继续使用现有服务端判断：回答已经完整、寒暄、简短确认或任务收尾时可以没有追问。页面功能和预制引导不需要额外调用模型。模型生成的普通追问不包含保存、修改、删除或分享动作。

### 3.2 优先级与出现时机

当前必须处理的确认、发送失败与真实任务回执优先；引导期间再由当前步骤提供一个清楚的行动；日常由最新有效追问或页面功能承接。同一位置不同时堆放三组建议。

候选只在完整回复可读后展示，不按每条自然短句各生成一组，也不等声音全部播完才允许用户继续。朗读期间可保留接话入口；用户主动发送时按现行规则打断声音。候选到达本身不触发朗读、触感或模型表演。

空闲页可由少量入口帮助起步，例如“试一篇示例”“聊聊方言”；已经有上下文时优先服务当前内容，不能每轮都推荐换方言或重看引导。

## 4. 四个位置的具体设计

### 4.1 大伴星模型态

输入器上方为轻量接话带，通常两项，最多三项。候选以完整短句显示，宽度按内容安排，最多两行；过长或空间不足时收成“接着问”入口，展开后再选择完整内容。

```text
当前一句对白

               伴星角色

 〔举个生活中的例子〕〔换个角度讲讲〕
                 接着问 · 更多

 ＋  说给她听……                         麦克风
```

保持角色头部安全区与视觉中心，不因每条候选迟到反复缩放模型。键盘、大字号或小屏幕压缩可用空间时先收建议。点击角色仍触发表情／动作，不把角色点击改成展开建议。

### 4.2 记录页

建议位于最新一次完整回复的正文、过程入口和成果之后，以“接着问”引出纵向短句。与该次回复保持关系，不固定压在用户正在看的历史上。

同次分句只显示一组；一旦出现下一条用户消息，上一轮追问退出可操作展示。晚到建议只补到所属回复，不重建整轮记录。用户停留底部时可自然跟随，向上阅读时保持位置。历史引用与完整正文仍可正常查看。

### 4.3 右下角伴星按钮态

头像左上方最多露出一个完整追问，附一个打开其余建议的小入口。该追问点击直接发送，头像仍点按展开面板、长按语音，保持现有手势。

只在本页刚完成的相关回复后主动呈现一次；用户正在滚动、选字、输入或打开其他面板时不出现。用户收起后，本轮不重复弹出。任务完成提醒和当前对白先占用同一提示位置，候选等待合适时机或留在面板中。

气泡靠近头像并避让工具和安全区，不推动阅读正文。短文案能够完整显示时才直接露出；长追问改用“接着问”打开列表，不把截断文本作为直接发送按钮。打开面板后收起外部候选，避免内外各一份。

### 4.4 展开后的随行面板

完整候选放在最新回复下方，与记录页共用分组。空对话时，可在“已带上《笔记名》”下展示两项当前可用帮助。已有选文时清楚显示选文，建议针对该段。

键盘弹出后沿用面板升到大档的现有行为；输入草稿优先。候选不与输入器重复固定，也不把历史消息顶走。从速览、脑图或成果回来后恢复同一阅读位置与对话位置。

### 4.5 共用操作规则

- 点追问即发送；长按提供“编辑后发送”。不修改用户已有草稿，不夹带未发送的图片、文件、语音来源或另一个引用。
- 输入框有文字、附件、待发送引用或正在录音时，收起自动快捷发送；用户仍可手动打开候选阅读。选择“编辑后发送”时，若已有草稿，先保留当前草稿，不直接替换。
- 点击发生时立即锁定本次发送意图，再进入异步提交；快速重复点击不产生多个回合。失败保留原问题与来源，沿用同一个发送标识重试。
- 新一轮发送、切账号、切书房或来源失效后，旧建议不重新浮到前台。切大伴星、记录和小面板不创建新一轮生成请求。
- 记录中的追问与原始对话语境绑定；页面功能与眼前页面绑定。两者不互相借用笔记。若当前阅读对象已不同，先显示原问题关联的笔记／选段，不能静默附上新笔记。
- 点按热区至少 44pt，长内容随字号换行；VoiceOver 分别说明“发送问题”“打开功能”“进入示例”。内容不依赖横滑或长按才能发现。

## 5. 新用户入口与整条路线

### 5.1 进入方式

新账号在完成必要会话恢复、真实首页可用后，由大伴星提供一次“陪我试一篇”的明确入口，旁边可直接跳过。邀请出现不自动播放声音、不默认修改设置。外部链接或真实任务把用户带到指定页面时，先保留用户原来的目标，不用引导覆盖它。

已经在桌面熟悉产品的账号，iOS 提供轻量的“看看手机上怎么用”，继承已有伴星名称和偏好。新空间不会重新要求命名或重走完整演练。

“我的 → 使用指南”为稳定的继续与重看入口，包含完整演练和各章节。结束或跳过后不在每次启动时重新展开，不生成未完成待办或提醒。

### 5.2 三个章节与步骤

引导围绕同一篇示例展开，章节是“认识彼此”“完成一篇”“用它学习”。屏幕只突出当前一步，路线目录按需打开。

| 步骤 ID | 所在场景与伴星提示 | 用户可体验的动作 | 本步完成依据／快进入口 |
| --- | --- | --- | --- |
| `meet` | 大伴星：“以后我叫什么，由你来定。你希望我怎么称呼你？” | 设置伴星名与私下称呼，或保留默认 | 保存回执与跳过分别记录；快进不保存草稿 |
| `dialect` | 大伴星：“挑一种，听我说两句？” | 方言试听、示例对话、可选设为默认 | 试听、自由对话、偏好保存分别记录；随时停止并快进 |
| `create` | 大伴星／记录里出现一小段示例材料 | 发送准备好的整理请求，阅读结果，确认保存示例笔记 | 在示例会话中完成，成果卡进入阅读；快进可直接使用预置初版 |
| `explain` | 示例阅读页：“试试选中这一句。” | 长按选句、讲解；也提供可点选的示范句入口 | 右下角接住问题并打开完整讲解；快进不伪造批注写入 |
| `rewrite` | 示例阅读页与随行面板 | 选中“空山”赏析段，发送保留原意的润色请求，阅读对照、确认 | 确认后得到示例第二版；快进后续使用预置第二版并说明来源 |
| `overview` | 第二版笔记的速览 | 读核心脉络，点一个要点回原文 | 使用版本匹配的预制成果；可以直接跳转下一段 |
| `mind_map` | 同篇脑图 | 展开分支、查看节点与原文，回到阅读 | 显示预制图，不假装刚完成真实生成 |
| `expansion` | 拓展笔记入口与预览 | 辨认 AI 补充／来源，决定是否保存示例拓展 | 仍在示例会话内；跳过不自动创建拓展笔记 |
| `practice` | 同篇的四题学习卡 | 独立作答、题号跳转、检查并交卷 | 完整提交才结算自己的示例成绩；快进和引导跳过均不交卷 |
| `results` | 示例成绩与原文依据 | 看反馈、定位依据、认识本次与最佳成绩 | 有完整提交则显示真实示例结果；否则只可查看明确标注的报告示意 |
| `continue` | 记录／书房：“现在从你自己的内容开始。” | 写自己的、导入材料或选已有笔记；也可结束 | 只在用户选择后离开示例进入对应真实入口；结束不代发请求 |

“速看”在当前 iOS 界面中的名称为“速览”，“思维导图”的短标签为“脑图”；引导文案与实际控件保持一致，不在本轮另改产品词汇。

### 5.3 四种伴星状态怎样被认识

开场在大伴星前建立关系；整理请求与保存结果在记录中可找回；进入笔记后，选句交给右下角伴星；改写在展开面板内继续。最后回到记录找一次成果，让用户理解这些位置承接同一位伴星。

书房负责笔记和继续阅读；星轨提供真实日记、记忆与手边任务；我的管理本人、伴星与偏好。只在相关位置用一句话点明，不为认识四个一级入口强制多走四段教程。示例不会制造星轨里的学习事实。

## 6. 全程快进、跳过与恢复

这是所有步骤必须支持的行为，不是末尾的退出按钮。

### 6.1 始终可找到的控制

在已登录页面上方预留一条紧凑的引导栏，包含“示例演练”、可打开的路线、快进和跳过。该栏占真实布局空间，避让状态栏、页头和键盘，不盖住选区、答题选项或伴星面部。大字号时允许分行。

“稍后继续”放在路线菜单内；当前主要按钮用于实操。菜单和面板内部也必须有可访问的快进／退出方式。系统权限或真实确认弹窗使用其正常取消操作，返回后继续快进；引导控件不能穿透系统弹窗代选。

| 控制 | 明确含义 | 状态与副作用 |
| --- | --- | --- |
| 快进 | 跳过本段剩余旁白与实操，直接进入下一段可用的预置示例状态；辅助说明为“快进到下一段” | 不等待声音、动画或手动练习；本段记为跳过实操，不伪造完成 |
| 路线选章 | 直接进入任意章节／步骤，包括尚未到达的位置 | 按目标检查点准备对象；中间步骤不补记为做过 |
| 跳过本段 | 路线菜单中的显式跳段，与本段快进使用相同数据边界 | 保留已经做过的示例操作，不执行尚未确认的动作 |
| 跳过引导 | 结束本次引导，回到进入前的真实页面；首次从首页开始则回真实首页 | 停止引导声音，消费本版本首次展示机会，不反复邀请；保留手动继续入口 |
| 稍后继续 | 暂停在当前检查点，回到原页面 | 下次由用户主动继续，不在启动时自动重播 |
| 返回上一步 | 查看上一段，或重新练习该段 | 不撤回已成功保存的真实设置，不回滚真实笔记 |
| 重看／从这里继续 | 从使用指南进入独立的手动演练 | 不回退首次引导的完成／跳过终态，不重新命名、不重复保存 |

快进用直接跳段来节省时间，不要求先切换一种倍速模式。连续点按时以最新目标为准，不排队播完中间章节；用户可随时改选路线。结果庆祝中的快进直接进入静态报告，保留实际已得的分数与星级。

### 6.2 跳过依赖步骤后仍能体验

每个步骤都有独立可用的预置检查点，至少包括进入位置、笔记版本、所需成果及该段示例记录：

- 没做“写成笔记”就进入讲解，使用已准备好的初版，并说明“这一段使用准备好的示例笔记”。
- 没确认改写就进入速览／脑图，使用“改写后的预置示例第二版”；不宣称是用户刚保存的版本。
- 没做题就进入结果，只展示“报告示意”，不生成用户成绩、星级或练习完成记录。
- 从脑图直接跳到方言，关闭当前示例展示并切到方言段，迟到的节点回调不再拉回脑图。
- 选择回到先前练过的步骤，可以继续该段本地草稿；需要展示另一检查点时，明确其为预置状态，不把已有演练结果覆盖成新的操作事实。

导航检查点与用户已完成的动作分别保存。快进改变当前展示位置，不执行被跨过的保存、确认、授权、发送和交卷。

### 6.3 学习卡的特别规则

“下一题”是题目导航，“快进／跳过引导”是导览控制，两者必须在位置与文案上区分。

答了一题后快进或跳过引导，保留未提交示例草稿，不提交、不判零分、不点亮卡。用户自己选择“检查并交卷”时，才沿用未答题按跳过计入等权分母的规则和提交确认。完整提交得到的零分仍是一次已尝试，展示真实的零星结果；没有完整提交不等于零分。

结果示意与用户实际提交后的示例报告在标题和数据来源上明确区分。正式作答界面不显示答案、依据、联想词、讲解旁白或其他主动打断；导览退出控件仍可操作。

### 6.4 快进时正在进行的事情

引导旁白与试听立即停止；未完成录音取消，迟到转写不回填其他步骤。普通引导素材加载可取消，过期回调不能继续播音或打开旧面板。

用户已经明确提交的真实设置写入或真实任务，快进不能把它假装取消或回滚。回执按原对象正常更新，在使用指南或相应设置／任务入口可查；它不强行切回已离开的引导步骤。引导不会为了展示下一段自动重试真实写入。

## 7. 认识彼此：名字、称呼与设置

两个字段分工明确：伴星名字属于现有 persona；她对用户的私下称呼属于账户级个人偏好，与公开昵称、邮箱和头像独立。开场提供默认值和即时文字预览，允许只改一项或全部略过。

例如文字预览：“小林，我是小澄。先陪你试一篇？”预置旁白不冒读任意自定义名字；需要真实个性化声音时走正常语音能力，不能让字幕与录音说不同的称呼。

| 数据 | 作用域 | 写入时机 |
| --- | --- | --- |
| 伴星名字 | 账户 persona，跨端一致 | 用户明确保存，沿用当前 revision 与冲突处理 |
| 对用户的称呼 | 账户级、可查看修改的明确偏好 | 用户明确保存；新合同与 Agent 上下文注入属于待实施工作 |
| 默认方言 | 账户声音偏好 | 点击“设为默认”或明确要求以后默认使用 |
| 自动朗读／本机动效 | 现有设备偏好范围 | 只在用户主动调整时保存，试听不代开自动朗读 |
| 未保存输入 | 当前引导草稿，按账户隔离 | 快进或暂停保留草稿，跳过不把草稿当设定提交 |

每项以真实回执判断成功；部分保存成功时如实呈现，不用一条笼统成功消息掩盖另一项失败。离开与继续均可用。语气、相处约定以后按需调整，不能要求先填写一大页人格问卷。

## 8. 方言：从试听到聊两句

### 8.1 呈现与节奏

命名后由大伴星邀请“挑一种，听我说两句？”。首屏建议三种差异清楚、已通过听感验收的方言和“更多”；候选可从粤语、重庆话、东北话中筛选，但不能把这份设计候选当作已验收名单。

方言选中先播放一段短开场，显示完整字幕并由真实音频电平驱动口型。按钮为“再聊一句”“用这种话讲讲这篇笔记”“换一种听听”，随时可快进或跳过。

声音从当前播放位置停止后再切另一种，不叠播；快速往返只响应最新选择。方言表达需自然，逐条听审，不用字幕里插几个词来代替口音。部分方言会使用不同声线，试听与真实会话采用相同的声音选择规则，并在选择处轻量说明。

### 8.2 试听、示例对话与自由对话

| 层次 | 内容与能力 | 数据边界 |
| --- | --- | --- |
| 听一句 | 随包的预制音频与字幕，可离线 | 不发模型请求，不修改账户默认，不写真实聊天 |
| 再聊一句 | 几条明确可选的示例提问与对应预制方言回答 | 仍在示例会话内，不假装识别了任意自由输入 |
| 用这种话讲示例 | 用户显式选择后，把临时方言延续到有对应音频的笔记讲解段 | 页面标示本次体验，未设置默认就不影响以后 |
| 自己聊一句 | 文字或主动开启麦克风，进入真实 Agent 与 ASR/TTS 链 | 接正常授权、整段识别、发送与失败重试；真实聊天按正常规则留存 |

试听不要求先开启自动朗读。主动点击试听只播放这一次，仍遵守既有总静音和音频中断规则。麦克风只在点击语音后请求；不承诺所有方言都能被 ASR 同样准确识别。转写文字可检查修改，文字输入随时可替代。

跳过或快进离开方言段时停止当前试听，恢复已保存的声音偏好；只有用户选了“用这种话讲笔记”才延续临时体验。临时状态离开引导即结束，真实账户默认不受影响。

### 8.3 留下喜欢的声音

听过后提供“以后也想听我这样说吗？”以及“设为默认”“这次试试就好”。默认保存走现有 `GET/PATCH /voice/preference`，保留用户原有音色、语速／风格配置，只改需要改的字段。保存成功才确认记住，失败保留重试，不误报。

“我的 → 我的伴星 → 名字与表达”增加独立的默认方言区域，可恢复普通话。自然语言“以后用东北话”“以后还是普通话”复用现有持久偏好语义；“这句用粤语说”只影响临时回合。

当前真实引擎不支持所选方言时，仍可播放已准备好的本地试听；进入真实方言对话或设为默认前，说明需要采用支持该方言的声音配置，并由用户明确选择。不能静默改掉引擎后声称只保存了方言，也不能用普通话回退冒充该方言。

陪聊与讲解可按用户选择发声；写入笔记和学习卡的正式内容默认规范书面中文，沿用现行创作轮的普通话规则，用户当轮明确点名时按现有协议处理。话题中出现地名不自动触发切换。

### 8.4 资产验收

共享目录目前列有 20 个方言取值，其中系统方言目录与通用方言声音的能力范围并不相同。生产选项以实际引擎、配置与试听验收交集为准，不能仅凭枚举全部开放。

每段录音记录字幕、方言、模型、音色、指令、生成配置摘要和音频摘要；录音与正式调用规则不一致时重新准备并听审。没有对应资产时保留文字并允许继续，不在后台临时合成整套引导。

## 9. 一篇预生成示例及其版本

### 9.1 内容包

示例题目为《为什么看懂了，合上笔记却想不起来？》。正文几百字，包含清楚的小标题、可解释的原句、可改写的一段和可组织成图的关系。具体正文、科学表述与音频均在资产制作阶段审阅，本轮未生成成品。

| 内容 | 必须对应的对象 |
| --- | --- |
| 原始材料与整理请求 | 同一份准备好的材料，明确示例来源 |
| 笔记初版 v1 | 稳定段落身份、原文选区、标题与版本摘要 |
| 改写提案与 v2 | v1 的准确范围、前后对照、确认后的完整 v2 |
| 原句讲解／批注 | 指向其实际使用的 v1 或 v2 选区 |
| 速览与脑图 | 当前演示使用的固定版本及逐字原文依据 |
| 拓展笔记 | 来源笔记与版本；AI 补充标识，引用外部来源时保留真实网址 |
| 一张四题学习卡 | 对应 v2，每题题干为明确疑问句，题型固定、均有原文依据 |
| 评分与结果 | 复用现行确定性题型规则、整卡等权平均、0–5 星与最佳完整作答规则 |
| 旁白与方言音频 | 对应字幕、步骤和实际声音配置 |
| 分段检查点 | 可直接跳入的场景、版本、成果与示例记录；状态标识为预置 |

首版四题可使用单选、多选、判断、排序四类，避免首次演练依赖在线语义批改。演练题量为四题，不改变真实学习卡默认六题、可选四／八题的设置。若示范拓展题，仍同时提供笔记依据和带标识的补充文段，数量遵守 57。

### 9.2 一致性检查

内容包带独立版本与稳定身份。预制成果、题目和选区必须校验到目标笔记正文摘要；所有检查点离线可读，不依赖先生成上一项。更新资产时不能用新包解释旧版本的选区或草稿。

用户实际确认示例改写，进入 v2；快进采用 v2 检查点时标识其为预置版本。任何情况下，都不能把 v1 的速览或题目无提示地挂到 v2 上。

### 9.3 自由输入的出口

预制示例支持已经准备好的演练请求和分支。用户编辑请求后超出范围，不拿固定录音或固定改写冒充自由生成结果；保留输入，提供“用自己的笔记试试”并接真实操作入口，也可回到预制演练。

真实创作使用正常授权、当前版本和提案确认。必要时先把示例明确复制为用户自己的笔记，再交给真实 Agent；不能让预制成果继续伪装成这篇自由修改后笔记的新结果。

### 9.4 留下示例

结束时可选“把示例留在书房”，默认不自动创建。沿真实写入权限明确目标书房，重试使用同一个创建标识。

首版保留当前明确选择的笔记正文为一篇新的真实笔记；示例成绩、聊天、批注、扩展对象及派生成果不自动复制。要把预制成果同时带入，需要另行具备服务端身份重映射、摘要与版本校验，本方案不以该扩展作为首次引导上线的前提。真实新笔记的练习纪录从零开始。

## 10. 正式示例与真实账户的边界

此前“示例仅存在 Debug”的开发约定，继续适用于验收预览和测试夹具。本方案新增用户已确认的正式产品示例，必须建立显式隔离的生产引导会话；不能直接去掉 `#if DEBUG` 或 `uiReviewMode` 的阻断，把现有验收数据接进真实账户。

| 内容 | 可以发生在哪里 | 不得产生的混淆 |
| --- | --- | --- |
| 示例笔记、改写、成果、问答与成绩 | 隔离的本机引导会话，可持久恢复 | 不写生产 notes、inbox、批注、学习事实、星轨、日记、记忆或成长数据 |
| 引导步骤与首次展示状态 | 专用的本人引导进度合同 | 不把看过、快进、跳过算作掌握能力 |
| 用户明确保存的名字、称呼、默认方言 | 各自真实账户设置入口 | 不因跳过被自动保存，不因重播被重设 |
| 自己聊一句／自己的笔记 | 明确交还的真实对话与业务入口 | 不向真实 Agent 发送整段虚构演练历史作为共同经历 |
| 留下示例 | 用户明确选择后的真实创建桥接 | 不复制示例练习成绩或暗中创建多篇内容 |

界面持续保留轻量“示例演练”标识，首次说明“内容已提前准备，可以直接体验”。没有真实生成时不出现伪造思考、联网步骤、百分比或故意延迟的进度。使用真实应用组件和导航行为，数据与命令由明确的引导会话提供。

正式示例的本机隔离不等于整个功能禁止联网：账户设置、本人引导进度同步以及用户明确进入的真实操作分别走各自接口。示例内容执行通道不能调用这些生产写入口。

未签署外部 AI 授权时，可继续本地示例与已打包试听；进入真实 AI 请求时接现有授权页。此规则仅适用于本文的 iOS 本地示例，不改变桌面 43 的影片前置流程。权限拒绝、离线或模型下载失败均不阻止快进、跳过或阅读示例；Live2D 不可用时降级已有静态头像。

## 11. 进度、声音与恢复

### 11.1 独立引导版本

为 iOS 定义独立首次引导版本，例如 `ios-first-journey-v1`，与示例内容包版本分别管理。复用已有账户级一次展示许可、单调终态、revision 与手动重播能力，不改写 `companion-guide-v1` 的桌面进度。

步骤的“看过”“亲手操作过”“快进／跳过”分别记录；引导结束只表示这次路线已经结束。现有 `visitedStepIds` 不足以证明实操，实施时扩展明确的进度合同，不用一个已访问列表推断学习事实。

最低恢复语义包括：引导版本、内容包版本、本次 run、当前步骤、检查点、每步体验结果、进入前返回位置，以及本机隔离的未提交草稿。本人账户进度跨设备同步；声音播放位置、瞬时弹层和本机草稿按设备保存，不承诺在另一台设备恢复尚未同步的精确答题内容。

跳过引导消费首次机会；以后点击“从这里继续”创建独立的手动重播 run，不反转 consumed 终态。暂停不自动展开。旧包仍有可用资产时继续原包；不兼容时说明并允许从相应章节重看，不把旧题答案套进新题。

### 11.2 不阻塞示例的进度同步

已登录且联网时先读取展示状态并申请一次许可，避免多设备同时强制开场。状态未读出时不猜测为新用户；手动打开本地示例仍可用。离线演练保存本机进度，恢复后按本人、引导版本和并发版本核对合并，不覆盖另一设备已经完成或跳过的终态。

重播不自动保存设置、保留示例或重复提交成绩。退出账号时关闭当前引导，隔离不同账号的草稿和恢复入口。

### 11.3 声音与主动相伴

引导旁白、示例试听、真实回复和录音共用现有播放器、真实电平与音频中断规则，分别带可停止的播放身份。快进结束当前引导音频，后台或系统中断暂停，回到前台不自动突然续播。

引导占据前台时，普通启动问候、安静时主动话题和完成气泡暂缓自动呈现，真实任务状态继续更新；离开后恢复既有参与规则，不集中补播过时问候。不能把引导暂停实现为永久关闭账户的主动相伴能力。

全程静音可完成。已有自动朗读偏好不因试听被改动。学习卡正式作答期间只保留必要操作说明与导览退出，停止相伴插话。

## 12. 后续实现的调用链与职责

以下为待实现工作清单，不代表已存在新接口或已经完成接线。

### 12.1 真实追问链

1. 已有 worker 在答案完成后保存 `followUpPrompts`，发布 `assistant.followups.ready`；不为每个展示位置另建生成任务。
2. iOS DTO、消息模型、本机消息缓存和读取映射完整保留字段；现行合同内已有的历史块形式按共享语义读取，不再创造第三套格式。
3. WS 消费处理就绪事件，按 message／run、事件游标与内容身份合并；验证事件经过 delivery／process 的过滤后仍能被接收。终稿先到、追问后到、重复事件和先收到事件后刷新消息都能收敛。
4. 一份共享的建议状态负责有效期、来源和发送锁；模型、记录、按钮和面板只决定呈现。快照刷新与本机缓存回读也能恢复同一结果。
5. 点击追问走现有 `submit` 的独立明确输入路径，不带入无关 composer 草稿；失败幂等重试。当前页功能导航继续用实际 note/version/task 身份。

来源笔记与选段从该轮真实输入及其持久引用恢复，不从“当前打开的笔记”猜。不能恢复来源时展示可核对的入口，不静默发送到其他对象。

### 12.2 引导链

正式引导控制器负责当前步骤、快进／跳过、返回位置和呈现世代；示例会话负责笔记、提案、成果与答题的隔离状态；内容包负责检查点和版本化资产。三者复用实际页面组件，避免另做一套只能播放的假阅读器。

不把流程全部继续堆进 `AppStore` 或 `MainTabShell`：按既有目录职责划分引导、建议与数据适配，保持真实发送、权限与业务执行仍由原来的所有者负责。后续实现新增目录需遵守现有直接文件数与依赖分层约束。

### 12.3 设置与进度合同

伴星名字沿用 persona；默认方言沿用声音偏好。私下称呼补充结构化、可清除、可同步的账户偏好与 Agent 上下文读取，不能用公开昵称或一条未经确认的记忆替代。

引导进度扩展要明确快进、跳过和实操的区别，并保留既有 CAS／手动重播语义。若更改 shared 合同，同时核对 API、worker 与各客户端解析；不强迫 Android 在本轮实现对应界面。

具体笔记写入权限以服务端操作合同为准；`canManageNotes` 只代表部分管理能力，不可据它推断全部创建／改写权限。隔离演练对成员同样可用；真实创建或改写不允许时，提供用户可主动选择的可写书房入口。

### 12.4 进入真实操作后的返回

进入前保留真实页面栈、笔记版本、滚动位置与原有 composer 草稿。示例使用自己的草稿。用户选择“自己聊一句”或“用自己的笔记试试”时，明确交还真实操作状态并暂停引导；回来可继续原步骤。

这类真实操作已接受的任务可正常在后台完成，跳过引导不取消它、不重新发起它。真实素材不自动复制回示例包。

## 13. 视觉、动效与无障碍细则

清亮蓝用于当前行动和少量状态，候选保持低强调，不用多色卡片区分类型。正文、题目与解析直接可读，玻璃用于操作层；不把一整篇文章包成模糊背景。

候选和步骤切换从当前显示状态接续，按下立即反馈，动画期间不锁焦点。系统玻璃保留系统交互反馈，不再叠一套缩放。快进不播放被跨过页面的入场动画，路线跳转不排队飞越所有中间页面。

系统减少动态与应用减弱动效时，保留状态、文字与动作，移除空间飞行、缩放、装饰循环和逐星动画。键盘、大字号、横竖屏可用空间变化与原生可取消返回同时检查。引导操作不得抢走正文选区或强制把焦点移入输入器。

## 14. 实施批次与验收

### 14.1 完整批次

1. 先接真实追问字段、迟到事件和共用发送状态，一批完成四处正常、空、失败、历史、键盘与大字号。
2. 建立隔离的正式示例会话、版本化内容包、任意检查点进入和全程快进／跳过；先保证路线不依赖在线模型。
3. 接入名字、私下称呼与默认方言的真实设置回执，准备并听审方言资产，接自由对话出口。
4. 合并前台呈现、声音、返回位置和进度同步，检查整个页面族后集中增量构建与纠正。

每一批必须覆盖真实调用与可中断状态，不先把正常截图做完再把失败、导航和数据边界留空。日常构建遵守 [DEVELOPMENT](../../../apps/mobile-client/DEVELOPMENT.md)，初稿阶段仅交付文档；用户确认实施后按完整批次增量构建与验收。

### 14.2 必须验收的场景

| 检查组 | 行为判据 |
| --- | --- |
| 四处联想 | 同轮同内容、仅可见位置呈现；切换不重复请求；模型角色与正文有足够空间 |
| 迟到与重连 | 终稿之后到达、刷新先后顺序相反、重连重放、空数组和生成失败均不影响答案；快照可补回建议 |
| 草稿与来源 | 有文字、九张图片、文件、语音或其他引用时不误带；换笔记／版本后不串来源；失败只重试一次意图 |
| 逐步体验 | 从命名、方言、写成笔记、讲解、改写到四种学习能力与成果回找完整可走通 |
| 逐步快进 | 在每个步骤开头、旁白中、等待实操时各快进一次，均立即到下一可用检查点，无需补做 |
| 任意跳转 | 直接从开场进入脑图、拓展、答题和结果，再回到早前步骤；版本与预置说明准确 |
| 全程跳过 | 首次邀请及每个步骤均可退出；没有未经确认的设置、笔记、批注或试卷提交；下次启动不强制重播 |
| 练习边界 | 一题未答、答一题后退出、主动交含空题的卷、完整零分与完整高分分别正确；示意报告不冒充成绩 |
| 方言听感 | 对照预制试听与真实对话，口音、声线、字幕、切换与口型一致；临时体验不改默认，保存失败不说已记住 |
| 语音中断 | 快速换方言、快进、跳过、麦克风、耳机断开、系统中断与后台不叠播；迟到转写不填到别段 |
| 离线与权限 | 未签 AI、拒绝录音、模型不可用和断网仍可走预制路线；真实请求正确接授权，随时能离开 |
| 身份与恢复 | 切账号、切空间、两台设备竞争、应用重启、内容包更新与手动重播不覆盖终态、不混草稿 |
| 实际窗口 | 小屏、大字号、键盘、长文、深夜、减少透明度、两种减少动态、快速反向操作和可取消返回 |
| 数据隔离 | 示例不出现在真实 notes、inbox、星轨、日记、记忆、统计或真实成绩中；明确保存与真实聊天例外有可核对回执 |

单元测试聚焦事件合并、来源、步骤转换、跳过副作用和评分；集成测试验证设置、进度 CAS 和真实创建出口。人工走查验证首次理解、触控、声音和连续使用。截图、测试和源码提供不同证据，不能互相代替。

改变 shared 合同或跨包配置时，按各包的 `npm run typecheck` 检查 shared、api、desktop-client、ai-worker，并完成相应 iOS 增量构建。现存失败与本次引入问题分开记录；具体验收放在 `docs/testing/` 对应任务文档。

## 15. 实施记录与后续边界

2026-10-24 用户明确要求实施，并允许在有意义的反馈中使用适量镭射点阵等科幻动效。现已完成四处共享联想、11 站正式示例演练、账号称呼与引导进度接线，并随包携带四种声音各两句与示例讲解。示例通过独立 `AppStore(sample:)` 与封闭本地传输复用正式页面，不开放 Debug 夹具；快进、跳过和示意报告不产生真实学习事实。

真实保存设置仍需账号接口成功回执；试听不改变默认。当前首版提供普通话、河南话、四川话和广东话的两句预制对话，可在真实对话继续使用已保存的默认方言。示例内录音不申请权限；自有内容的录音由原有真实会话与授权链处理。保留示例只在明确点击后复制第 2 版正文，不复制演练成绩。

点阵只在局部交互短暂响应，系统／应用减少动态时静态呈现，后台停止。转场跟随前进和返回的方向，不延迟功能。具体调用链、测试、窗口观察与尚未确认的硬件／听感限制见 [实施记录](../../testing/ios-first-journey-59-2026-10-24.md)。
