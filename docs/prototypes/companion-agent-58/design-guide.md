# 拾星书房 · 伴星任务与对话手记

交互原型的操作导览与设计说明。  
文件：`shixing-study-prototype.html`（单文件，含全部样式、内容与交互脚本）  
标注：**交互原型 · 演示数据**。所有生成、保存、重试、停止、资料读取均为本地模拟，不发起真实模型或后端请求。

---

## 1. 原型概览

这是「边读边看」的历史笔记整理场景：

- 左侧是正在阅读的历史笔记，右侧是固定座位的伴星与本次任务。
- 伴星接下「整理三篇历史笔记」，先交付秦朝篇，再处理唐朝、宋朝。
- 用户可以在任务进行中随时**就地预览**，也可以打开正式笔记、回到对话手记，再准确返回刚才的位置。
- 任务允许部分失败、停止、重试、核对保存结果和需求变更；原型重点不是“全部成功”，而是**不丢阅读位置、不覆盖已保存成果、不假装完成**。

### 视觉与平台

- 桌面：暖奶油纸阅读面、宋体册页、薄荷绿伴星角、少量桃色与暖黄。
- 手机：切换为白灰原生表面，强调色改为系统蓝 `#007aff`，保留同一套任务语义。
- 支持桌面 `1440×810`、`1280×720`、`125% / 150% / 200%` 缩放，以及 `390px` 及更窄的手机宽度。
- 顶部黑色栏是**原型工具**，不属于产品界面；演示产品时可直接忽略或收起视线。

4. **导览**：重新打开操作方法。
5. **从头开始**：恢复初始秦朝阅读位置与默认场景。

## 3. 推荐演示路径（约 5 分钟）

1. 打开页面，停在秦朝笔记。右侧伴星显示三篇任务正在推进。
2. 点任务卡里的 **预览**，在阅读器上展开“本次任务”预览。
3. 点 **在手记中查看**，手记定位到当前任务条目。
4. 点 **打开笔记**，进入宋朝笔记的正式阅读页；点底部 **返回刚才位置**，应回到手记、预览与原来的滚动位置。
5. 在原型栏切到 **部分失败（主演示）**：
   - 秦朝已保存，唐朝失败，宋朝未开始。
   - 点 **只重试未完成部分**，观察只处理唐朝，不重新生成秦朝。
   - 重试过程中点 **预览唐朝草稿**，再关闭预览，任务不应停止。
6. 在原型栏切到 **核对保存**：保存回执未知，界面显示“正在核对保存结果”，并提供本地草稿，不引导重复创建。
7. 切到 **已停止**，演示“停止只作用于剩余工作”；再点 **继续未完成部分**。
8. 切到 **全部完成**，从手记打开任意一篇，再返回。
9. 切到 **回看旧记录**，演示历史记录不会被当前任务结果自动替换；有新成果时只提示“回到最新”。

## 4. 场景清单

| 场景 | 已保存 | 当前状态 | 关键演示点 |
|---|---|---|---|
| 从头开始 | 无 | 秦朝生成中 | 初始阅读、任务进度、预览草稿 |
| 正常 | 秦朝 | 唐朝生成中 | 边读边看、预览与手记 |
| 慢速 | 秦朝 | 唐朝生成中（较慢） | 等待中的可读性、不显示虚假百分比 |
| 待确认 | 秦朝 | 唐朝待确认 | 两种资料范围选择，不影响已保存成果 |
| 核对保存 | 秦朝 | 唐朝保存结果未知 | “正在核对保存结果”、本地草稿可读 |
| 已停止 | 秦朝 | 唐朝已停止 | 停止剩余工作、继续未完成部分 |
| 全部完成 | 三篇 | 已完成 | 手记回看、打开正式笔记 |
| 回看旧记录 | 当前任务独立 | 历史手记 | 旧记录不被自动替换、回到最新 |
| 部分失败（主演示） | 秦朝 | 唐朝失败 | 只重试未完成部分、草稿保留 |

补充分支：

- **需求更新**：在输入框发送“唐朝这篇改用《资治通鉴》为主，秦朝不要动”，会记录要求更新；已保存内容不被覆盖。
- **新版本到达**：在任务面板点“模拟新版本到达”，若正在看旧版预览或旧手记，只提示，不自动替换当前阅读。
- **保存回执延迟**：失败后重试，可能进入“正在核对保存结果”，用于演示“结果未知”而不是“失败”。

## 5. 关键操作与语义

### 预览 / 打开笔记 / 在手记中查看

| 操作 | 行为 | 不会发生什么 |
|---|---|---|
| **预览** | 在当前阅读面上方展开预览层，可看草稿、成果、资料关系 | 不会停止任务，不会自动打开正式笔记 |
| **打开笔记** | 进入正式笔记阅读页，保留来源与返回上下文 | 不会丢弃手记条目或预览快照 |
| **在手记中查看** | 打开手记并定位到对应条目，带焦点高亮 | 不会重置任务，不会替你打开另一篇 |
| **返回刚才位置** | 恢复滚动、锚点、手记模式、预览层和未发送草稿 | 不会把任务状态回滚 |

### 任务操作

- **只重试未完成部分**：只处理失败或未开始项；已保存的秦朝笔记不重新生成、不覆盖。
- **停止剩余工作**：停止尚未完成的部分；已保存成果仍可阅读，草稿保留。
- **继续未完成部分**：从停止处继续，不重新开始整批任务。
- **确认资料范围**：待确认时选择一种叙述主线；秦朝成果保持不变。
- **继续核对**：保存结果未知时继续核对，不重复创建。
- **修改要求**：记录“要求已更新”，只影响未完成部分。
- **模拟新版本到达**：演示旧预览 / 旧手记遇到新成果时的提示方式。

### 状态文案

- **已保存**：有版本号、保存时间、来源关系，可打开正式笔记。
- **生成中**：显示正在做什么，不用虚假百分比冒充进度。
- **未完成 / 保存失败**：明确说明已保存哪一篇、草稿在哪里、可以只重试未完成部分。
- **核对保存结果**：明确“暂时未知”，提供本地草稿，避免重复创建。
- **待确认**：任务暂停等待用户选择，不自动猜资料范围。
- **已停止**：说明停止只作用于剩余工作，已保存内容不受影响。
- **已完成**：三篇都可从手记打开，不自动把用户带离当前阅读。

## 6. 页面层级与进入 / 返回规则

从下到上：

1. 阅读器与伴星任务面板
2. 对话手记层
3. 预览层
4. 编辑要求层
5. 原型工具与导览层（工具层不参与产品层级）

### 进入规则

- 打开手记：先收起未固定预览；定位到请求、计划、当前任务、失败项、成果或完成条目。
- 打开预览：记录触发元素、滚动位置、预览快照和所在层（阅读 / 手记）。
- 打开正式笔记：先记录返回上下文，再收起预览与手记；从成果打开时定位到对应笔记。
- 打开资料原文：定位到笔记中的来源段落，并高亮来源标记。
- 打开历史记录：手记进入归档模式，保持 10 月 18 日的当时内容。

### 返回规则

- **关闭预览**只收起预览层，任务继续。
- **返回刚才位置**恢复：阅读滚动、手记模式与锚点、手记滚动、预览层与预览滚动、未发送草稿。
- **从手记打开笔记再返回**：回到原手记条目，不回到顶部。
- **从预览打开笔记再返回**：恢复预览快照，不自动换成最新版本。
- **归档手记返回最新**：回到当前任务手记，并定位到对应成果；新旧版本不混写。

## 7. 关键动效

### 动效令牌

| 令牌 | 时长 / 曲线 | 用途 |
|---|---|---|
| `--dur-press` | `120ms` / `cubic-bezier(.25,.46,.45,.94)` | 按钮按压回弹 |
| `--dur-fast` | `160ms` / `ease` | 颜色、描边、轻量状态变化 |
| `--dur-ui` | `220ms` / `ease` | 蒙层、提示、普通显隐 |
| `--dur-panel` | `300ms` / `cubic-bezier(.22,1,.36,1)` | 预览、编辑面板进入；收束感接近轻弹簧 |
| `--dur-journal` | `340ms` / `cubic-bezier(.22,1,.36,1)` | 手记从右侧推入 |
| 抽屉曲线 | `cubic-bezier(.32,.72,0,1)` | 移动端底部面板 |

### 动效行为

- **手记进入**：从右侧轻推进入，透明度同步过渡；不是整页翻转。
- **预览进入**：从触发按钮附近缩放展开，关闭时回收；背景轻微模糊，不改变阅读排版。
- **流式文字**：逐段增长，只让当前段落内部高度变化，避免整页跳动；光标独立闪烁。
- **新成果到达**：成果条目短暂高亮；若正在看旧预览，只出现“新版已到 · 查看”的轻提示。
- **定位反馈**：来源段落用 1.8s 暖色渐隐高亮；手记条目用 1.5s 薄荷色渐隐高亮。
- **伴星眨眼**：8.5s 长周期、低幅度，避免持续吸引注意。
- **按压**：按钮只做 1px 级位移，不夸张缩放。

### 中断规则

- 任务进行中打开预览、手记、正式笔记，**一律不停止任务**。
- 关闭预览 / 手记只收起界面层，不取消生成、不清空草稿。
- 停止只取消剩余工作；已经开始的保存核对不被伪装成“已停止”。
- 新版本到达不自动替换正在阅读的旧预览或旧手记；用户主动“查看最新 / 回到最新”才切换。
- 切换场景会清理旧计时器与流式输出，避免前一个演示的异步回调污染新场景。
- 系统开启“减少动态效果”时，默认使用轻量；原型内仍可手动选择关闭。

### 降级

- **轻量**：过渡缩短到 `120ms`，面板不做位移缩放，保留透明度与焦点反馈。
- **关闭**：移除动画与过渡，保留即时状态变化、焦点描边和高亮结果（高亮不依赖动画）。
- **`prefers-reduced-motion`**：首次打开自动采用轻量；用户手动选择优先。

## 8. 响应式与平台差异

- 桌面 ≥ 861px：左阅读器 + 右伴星任务栏，手记/预览为覆盖层。
- 窄桌面或低高度（≤860px 宽 / ≤560px 高）：隐藏伴星侧栏，任务入口移到顶部状态条。
- 手机：隐藏册页装饰与侧栏，使用白色表面、系统蓝、底部输入栏；预览与手记变为底部面板。
- 手机任务条固定在阅读器底部、输入栏上方，点开为底部任务单，避免遮挡正文。
- 安全区：底部输入栏与移动面板使用 `env(safe-area-inset-bottom)`。
- 触控目标：主要按钮不低于 34–38px；文字链接保留足够内边距。

## 9. 落地实现注意事项

1. **任务与阅读分离**：任务状态、阅读位置、预览快照、手记锚点分别存储；关闭任一层不能改变任务状态。
2. **保存幂等**：重试与核对必须由后端提供幂等键或保存回执查询，前端不能仅凭超时判断失败。
3. **部分成功建模**：每篇笔记独立状态机（未开始 / 生成中 / 草稿 / 待确认 / 核对中 / 已保存 / 失败 / 已停止），不要用整批任务一个布尔值。
4. **版本不可变**：旧预览绑定快照版本；新版本到达只提示，不静默替换。
5. **返回上下文**：进入正式笔记前保存阅读滚动、手记模式/锚点/滚动、预览快照/滚动、草稿；返回时按层恢复。
6. **真实流式输出**：按段落增量渲染，避免每个 token 触发整页布局；对长文使用 `content-visibility` 或虚拟化。
7. **无障碍**：弹层使用 `aria-modal` / 焦点圈定 / `Esc` 关闭；状态变化用 `aria-live` 播报；不仅靠颜色区分失败与待确认。
8. **中文排版**：宋体仅用于阅读标题与册页气质，正文在移动端切回系统无衬线；行高不低于 1.7。
9. **文案原则**：说清“已保存什么、还剩什么、下一步做什么”；避免“已完成”覆盖部分失败，避免百分比造假。
10. **原型数据**：正式接入时替换 `NOTES`、`SOURCES`、`ARCHIVE_OUTPUT` 与 `makeTask`；交互层可保留。
