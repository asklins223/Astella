拾星书房 · 原型导览

交互原型使用本地演示数据，不发起真实模型或后端请求。

建议走一遍

  1. 在右侧伴星任务卡里预览“秦制与天下”。
  2. 打开完整手记，定位到当前任务与资料。
  3. 点击“只重试未完成部分”，观察唐朝与宋朝逐份到达。
  4. 从成果打开正式笔记，再“返回刚才位置”。
  5. 回看较早记录，等待/模拟新版到达，再回到最新。

状态演示

  • 顶部“状态”只属于原型工具，不会出现在产品界面中。
  • 可切换部分失败、慢速、待确认、核对、停止与完成。
  • “动效”可切换完整 / 轻量 / 关闭；所有状态仍可操作。
  • 平台切换会保留任务进度、选中成果、预览与草稿。

关键语义

预览叫出同一份材料或成果的就地层；打开笔记进入正式阅读；在手记中查看定位到对应条目；返回刚才位置恢复阅读滚动、手记锚点、展开预览与未发送草稿。关闭预览不会停止任务，停止只作用于剩余工作。
