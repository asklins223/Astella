# 笔记阅读与学习 · 静态提案 v1

一个单文件静态页，用来评审「笔记应该怎么被读、被懂、被记住、被往外延伸」。
**不是产品实现，不连接任何后端**；里面所有的笔记正文、AI 解释、AI 生成的 HTML 演示
与三篇拓展提案都是写死的样本。

打开方式：直接用浏览器打开 `index.html`（无需构建、无需服务器）。

## 它想说明的六件事

| # | 主张 | 在页面上怎么看 |
| --- | --- | --- |
| 1 | **正文是主角**，学习是长在正文上的 | 左边是册页正文；讲解在右边的「讲解台」，两者不互斥、不切页 |
| 2 | **四种来意各有各的入口** | 顶部四枚纸签：速览 / 唤回 / 这一段 / 往外走，选中才亮 |
| 3 | **选中哪一段，解释就长在哪一段下面** | 在正文里选中任意一句 → 浮出小印章 → 点它 → 批注条出现在那一段下面，带「依据 第 N 节」 |
| 4 | **AI 自己写 HTML，不是模板填空** | 第 4 节那张会动的小图：一段对话随四个步骤长出来，可单步可连播；外壳是 `sandbox="allow-scripts"` 的隔离 frame |
| 5 | **往外走要人点头** | 往外走：三篇提案标注「从第几节接出」；采纳后长成新笔记，在原段落留下「往这看」，新笔记之间互引 |
| 6 | **学过的东西不消失，且随时能溯源** | 底部「书房里留下的东西」常驻；每条都带「↩ 回到第 N 节」，点一下滚回原文并高亮 |

## 评审时可以试的

- 在正文里**选中一句**（比如第 5 节那句「接得越多越强」）→ 看印章和批注落在哪。
- 点第 4 节的「用动画讲这段」→ 在讲解台点「走一遍」，看四步怎么一步步长出来。
- 唤回里先别点「看看」，自己背一遍，再揭示，最后如实自评——自评会进底部足迹。
- 往外走把三篇都采纳 → 看原段落上的「往这看」和底部的新笔记条。
- 关掉动效（系统偏好）或把窗口拖窄，看伴星是否始终在座位上。
