# 伴星体验

中文 · [English](../en/companion-experience.md)

伴星是统一 Agent 面向学习者的交流与执行入口。她常驻书房，理解当前页面，在明确要求和权限范围内处理任务；学习结果与保存仍由对应领域服务管理。技术链路见 [Agent 运行时](agent-runtime.md)。

## 从哪里交流与查阅

| 入口 | 用途 |
| --- | --- |
| 身边轻聊 | 输入问题、引用当前材料、查看回复和动作确认；开启语音交流 |
| 手边的事 | 查看持续任务与成果，修改要求、暂停、继续、停止或留下合作方法 |
| 我们的对话手记 | 全部对话、伴星念想、交给我的事、待确认；回看过程、来源与成果，不提供新的输入框 |
| 伴星中心 | 近况、历史对话查询、日记、记忆、发现簿、动态、人格；中心对话页不承担实时发送或提案决策 |
| 伴星带路 | 房间控制岛里的主题目录，可跳过、暂停和重看；教学示例明确标识，不创建真实学习记录 |

轻聊、手记和中心历史使用同一份真实会话与来源记录。任务被受理、完成保存和最后一句回复成功是不同状态；回复失败时，实际已保存的成果仍应保留入口。

## 能做什么

能力从 `packages/shared/src/agent-capability-catalog.ts` 投影，工具是否可用还取决于账号设置、空间权限、AI 同意、识图／联网开关与服务配置。

| 任务 | 行为与结果 |
| --- | --- |
| 理解当前内容 | 读取页面、笔记、来源与历史；长文分页读取，未读完时返回覆盖范围 |
| 找与打开内容 | 搜库内笔记、打开笔记或卡片、定位星图；导航只支持已登记目标 |
| 学习与持续任务 | 发起或接续学习、提示、切换练习、延后复习；生成速看、互动演示、拓展草稿或待审核卡片 |
| 写新笔记 | 明确要求整理讨论后保存新笔记，并核对库内链接 |
| 改当前笔记 | 在光标处插入、末尾追加，或替换／删除选区与段落 |
| 查公开资料 | 开启联网后搜索网页；读取用户明确给出的公开 HTTPS 文档；保留来源与实际读取范围 |
| 计算与图示 | 核对有界表达式、读取图片、提供图示与可操作产物 |
| 陪伴与合作 | 提醒、记忆、人格调整、日记、收藏与有依据的合作方法 |

候选卡必须由用户审核收下，拓展草稿也需逐篇确认。普通问答不自动启动持续任务、创建笔记或改正文。

## 让伴星写或改笔记

讨论后可以明确说「把刚才讨论的内容整理成一篇笔记」。新笔记保存到当前空间，默认仅自己可见，之后继续使用已有编辑器。关联前必须实际检索并读取库内内容，保存时再核对可见性和版本；无相关内容时留为独立笔记。

修改当前正文时，在编辑器放好光标，或在阅读中选文并点「让伴星改这段」，再说明具体要求。选文按钮只附上原句与位置，不替你发送。发送前同步工作稿，执行时复核原文和版本；内容变化时停止覆盖。其他段落可继续写，当前处理段落用光带与动作文字表示状态，暂时禁止输入和格式调整。完成、失败或停止后解除锁定，关闭动效或系统减少动态时保留静态状态。

解释原句与写入正文是不同动作。解释可保存为批注；知识问答本身不修改正文。保存回执说明确实写入，不保证生成知识已经独立事实核验。实现与验证范围见 [笔记生成](../../testing/companion-note-authoring-2026-10-08.md) 和 [笔记编辑](../../testing/companion-note-editing-2026-10-08.md)。

## 联网与引用

在伴星设置开启「联网搜索」，默认关闭且随账号生效。服务端复用智谱平台凭据，不要求在客户端粘贴 Key；它仍受 AI 使用同意和数据外发策略约束。

回答中的编号角标连接真实来源。点击后可查看标题、网址和日期、复制链接或用系统浏览器打开；来源列表可折叠。来源标题、摘要和角标不进入朗读正文，轻聊与历史查阅使用同一来源身份。

额度不足时，当前轮继续回答并说明没有完成联网核实；当前 Worker 对同一凭据冷却 30 分钟。冷却不改用户开关，不能从没有引用推断已经联网。每轮搜索次数有上限，网页内容只作为资料，不能增加执行授权。见 [联网验证](../../testing/agent-web-search-2026-10-08.md)。

## 权限、在场与安静

账号助理权限有只读、引导、完全三档。引导档允许可逆低影响动作，其他动作需确认；完全档减少确认，但六个经提案执行的学习工具仍需用户决定。只读档禁止所有写操作，完全档也不绕过 Member 的只读空间权限。

座位、取景与交互模式由 `components/hud/hud-pages.ts` 登记。全屏笔记将伴星安置在右下临时座位，退出后沿用原摆位偏好。正式作答采用安静策略，禁止主动提示和语音干扰。

总静音、专注／隐藏与静默时段分别控制声音或呈现。用户主动约定的提醒与任务完成消息不进入日常主动消息的频率限制。真实任务、提醒和到达事件驱动时刻动画；Live2D 不可用时隐藏形象并给可关闭说明。

## 声音

输出使用 Qwen 或 Edge-TTS。Qwen 合成或网络失败可降级 Edge；治理拒绝不触发降级。语气、轻笑和叹息由回复模型按语境标注，支持的 Qwen 模型使用这些标记，显示和历史正文保持干净；人格页「声音表达」可关闭。Live2D 表情跟随实际播放段，口型跟随解码音频振幅。

输入使用本机 SenseVoice。模型不进安装包，由用户在设置中下载或删除；音频通过本机 IPC 进入 utility process 解码，不发送云端 ASR。语音模式按停顿切段、按说话顺序展示字幕，整轮识别完成后直接发送；要修正就继续说。回复播放中可用插话停止朗读。

识别进程空闲后释放内存，长停顿后可能需重新加载。真实麦克风、插话阈值、人工听感和跨设备表现仍需单独验证；引擎与合成测试不能证明完整听说体验已验收。云端 `POST /voice/transcribe` 保留在后端，桌面不调用它。

## 身份、记忆与日记

人格、名字、说话风格和账号设置随账号；具体材料、对话、日记、经历与学习目标按空间隔离。允许跨空间的一般合作偏好不能携带具体空间事实，拿不准时按空间内处理。

记忆需要用户原话出处、准入判据与置信度；易变事实和被否决来源不得直接复用。常驻、活跃、归档各有预算，满额时整理建议不等于已经替用户迁移。记忆页提供确认、固定、归档、恢复、忽略、移除与回收区；星图展示服务端筛选后的已确认关系。记忆整理与基于来源的语义判断仍有待验证／补齐项，不能用「有出处」推导内容必然被出处支持。

日记只在开启期间积累素材，按本地日生成；隐藏保留正文，删除清理派生内容。「聊聊这篇」带日期与版本进入输入，不自动发送。日记与她自己的判断属于主观作品，不能作为用户事实或掌握证据。

## 合作方法与当前限制

合作方法记录适用条件、步骤、例外、理由、版本与来源。用户可确认采用、停用、修订、恢复，并在真实使用后反馈是否有帮助。成长应体现在接续更顺和重复解释更少，不以经验值、签到或关系等级替代效果。

历史可通过 `companion_read_history` 找回；压缩只折叠有效摘要覆盖的完整消息，并记录覆盖范围。摘要可能遗漏语义，后续调用也不保证取回全部需要的信息，因此不能承诺「压缩不失忆」。方案 44 已有实库、模型对照和部分窗口证据，剩余限制见 [方案 44](../../plans/learning-companion/44-unified-context-window-and-compaction-2026-10-05.md)；自然度与等待稳定性见 [方案 46](../../plans/learning-companion/46-companion-natural-conversation-research-and-design-2026-10-07.md)。

跨天记忆、合作方法的长期效果、带路的新账号全程、真实麦克风和安装包更新仍需按各自记录确认。当前不提供个人模型配置或独立桌宠窗口。验证入口见 [测试与质量](testing-and-quality.md) 与 [方案索引](../../plans/learning-companion/README.md)。
