# 拾星笔记产品总览

中文 · [English](../en/overview.md)

拾星笔记是面向个人学习的 Electron 书房。材料、笔记、原文旁的讲解与练习、可选的长期复习组成学习主线；Live2D 伴星提供交流、查阅与执行入口。本页说明现有能力与边界，运行步骤见 [开发环境](development.md)。

## 当前学习路径

**来源 → 笔记 → 按需速看／回想／往外学／学习记录 → 需要时制卡和复习。**

来源是保留原始内容的材料，学习笔记可以编辑。四个学习入口分别使用，没有固定先后顺序；选中原句还能写批注、解读或交给伴星。拓展结果先保存为草稿，由用户逐篇编辑和收下。

另一条入口是对话：先讨论知识点，再明确要求整理成新笔记。伴星会查找库内相关内容，核对可见性和版本后附真实链接；没有关联时保存为独立笔记。普通提问不自动创建笔记。

笔记的工作稿自动同步，按「保存」留下可回看的不可变版本。学习记录保留当时的版本与原文位置，不将旧记录自动迁移到新版。回想自评、正式作答和系统评估分别记录；无法可靠检验时保留「练过、未证明」。

## 功能清单

| 领域 | 当前能力 | 使用边界 |
| --- | --- | --- |
| 来源 | 文本、Markdown、代码、URL 采集、解析与原文回看 | URL 抓取受公开网络与内容上限约束 |
| 笔记 | 阅读／编辑／源码、自动保存、版本、全屏、公式、表格、Mermaid、库内链接 | 工作稿同步与存成版本是不同动作 |
| 原文学习 | 速看、回想、拓展、记录、批注、解释与互动演示 | 生成按需启动；拓展草稿需用户收下 |
| 伴星编辑 | 光标插入、末尾追加、选区／段落替换和删除 | 必须有明确要求、权限与原文／版本核对；锁定处理段落 |
| 对话生成笔记 | 讨论整理、保存新笔记、库内关联与打开入口 | 默认仅自己可见；保存成功不等于知识正确率已验收 |
| 学习卡 | 生成候选、审核、收下、练习、到期复习与更正 | 候选生成不等于学习卡已激活或已经掌握 |
| 检索与星图 | 全文查找、来源追踪、笔记关系与理解状态 | 展示真实数据；空图需核对内容与投影 |
| 伴星 | 轻聊、任务、手记、中心、语音、日记、记忆、发现簿、人格与提醒 | 长对话自然度、跨天与长期效果仍在验证 |
| 联网引用 | 按需搜索公开网页、编号引用、查看／复制／打开来源 | 默认关闭，账号级开关；仍需 AI 同意与外发许可 |
| 空间与数据 | 个人／协作空间、成员、邀请、账号同意、导出与维护 | 工作区权限与 Agent 权限共同约束操作 |

## 运行形态

用户界面是 Electron 桌面客户端，没有浏览器学习产品。打包支持 macOS、Windows、Linux，当前自动安装包发布覆盖 macOS 与 Windows。

- **本机开发**：`docker-compose.dev.yml` 启动 API、PostgreSQL、Worker、edge-tts 和本地 MinIO，客户端连接回环 API。
- **远程 HTTPS**：安装包可以连接服务器 API；正式部署叠加 `docker-compose.deploy.yml`，由 Nginx 提供 HTTPS，对象使用远程私有 S3。
- **Alpha 验证**：基础生产 Compose 加 Alpha 叠加层，使用本地 MinIO、监控与备份工具。

后端支持多个账号与空间，以事务上下文和 RLS 隔离数据；单机部署不等于已经提供自动扩缩容或完整 SaaS 运维。凭据留在客户端主进程，渲染层不直接访问业务 API。

## 工作区与权限

| 角色 | 工作区内容 | 私有学习操作 |
| --- | --- | --- |
| 个人空间创建者／协作空间 Owner | 读写与管理 | 可用 |
| 协作空间 Member | 只读 | 可作答、复习与查看自己的理解状态 |

伴星「完全」权限不提高成员的工作区权限。只读档禁止写操作；部分学习工具在完全档仍需确认。AI 同意属于账号，Owner 不能替他人签署；切空间不重签。联网搜索也是账号级开关，不能代替 AI 同意。

## 产品边界与验证状态

源码采用 [MIT](../../../LICENSE)，第三方 SDK、模型与素材按 [第三方声明](../../../THIRD_PARTY_NOTICES.md) 分别处理。产品版本由 [release/version.json](../../../release/version.json) 统一维护，具体下载资产以发布页为准。

现有入口和业务链路已有代码、测试及部分窗口／真实模型证据。验收应逐项阅读：笔记编辑与写作见 [编辑记录](../../testing/companion-note-editing-2026-10-08.md) 和 [生成记录](../../testing/companion-note-authoring-2026-10-08.md)；上下文治理的实库、模型对照与剩余限制见 [方案 44](../../plans/learning-companion/44-unified-context-window-and-compaction-2026-10-05.md)；长对话自然度与等待稳定性见 [方案 46](../../plans/learning-companion/46-companion-natural-conversation-research-and-design-2026-10-07.md)。这些记录不构成全产品或长期效果已经通过的结论。

当前不提供个人模型／供应商配置界面、独立透明置顶桌宠窗口、自由相机与鼠标视差漫游、邮件自助找回密码。Live2D 加载失败时隐藏形象并说明，文字和已有记录继续可用。
